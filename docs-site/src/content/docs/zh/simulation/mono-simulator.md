单色监控模拟器是一个七页的向导，在镀膜机内的单波长光学监控下沉积设计。它与[宽带监控模拟器](/zh/simulation/bbm-simulator/)共用设置和回放；不同之处在于每层都在一个监控波长上，按三种终止策略之一切断。第 1 到 5 页设定条件和逐层计划，第 6 页运行一次实验，第 7 页给出结果。

## 计算的量

- **沉积仿真**（第 6 页）：时间轴、当前膜层的**估计 / 实际 / 目标**厚度，以及光谱与参考曲线的对比，与宽带向导相同。
- **结果性能**（第 7 页）：制造光谱与理论光谱的对比，每层的**相对**和**绝对**厚度误差，以及实际厚度和折射率的表格。

误差大的膜层，说明其波长或策略不适合它：试用**自动 λ（全部）**或换一种策略再运行，并多运行几次以看到结果的分散。

## 控件与设置

| 页 | 设定 |
|---|---|
| 1 **沉积速率** | 每种材料的**平均速率, Å/s**、**RMS, Å/s** 和**相关时间, s**；**随机并更新**重新抽取预览曲线。 |
| 2 **参数偏差** | 每种材料的系统与随机折射率偏差以及**系统不均匀性 (%)**，不均匀性会列在结果中，但不作用于膜层；**排除**出监控的膜层及其额外的相对厚度误差；快门延迟的均值和 RMS。 |
| 3 **监控系统** | 物理量和偏振、**入射角, °**、**扫描间隔, s**、切断所需的**确认扫描**次数，以及**监控片玻璃**。预览画出所选膜层的理想信号随沉积厚度的变化，并标出切断点。 |
| 4 **监控波长** | 每层的**监控 λ, nm**、**策略**和**阶次**（[见下文](#终止策略)）；**自动 λ（全部）**、**全部设为**和**全部策略设为…**。单击某一行即预览该层的信号。 |
| 5 **信号误差** | 读数的**随机误差, %**、满量程的**绝对噪声, %**（不随信号减小）以及**漂移, %**。 |
| 6 **沉积仿真** | **开始**运行实验并回放。 |

沉积的镀膜面以及结果的评价方式取决于[设计编辑器](/zh/design/design-editor/)中的表面模式。信号按整块监控片读取，镀膜与裸露的背面按非相干方式叠加，镀膜上方为空气：n = 1.52 的裸监控片读数为 91.8 %，而不是单个镀膜表面的 95.7 %。

## 终止策略

- **转折点**：在信号的极值处切断；**阶次**选择第几个极值。信号足够干净、能看出其曲率时，监控仪根据最近的读数预测极值，并在该处关闭快门，必要时在两次扫描之间关闭；信号有噪声时，它等到信号回转，切断会稍微越过极值。
- **水平**：在信号沿预期方向穿过目标水平处切断，只在包含目标的分支上、即目标之前最后一个极值之后才启用，因此比四分之一波更厚的膜层不会在信号第一次经过该水平时被切断。**阶次**为 N ≥ 2 时在第 N − 1 个极值之后启用；为 1 时由模型决定分支。监控仪等待平滑后的信号达到模型给出的、提前确认扫描次数的值，在两次扫描之间求出穿越时刻，并按定时器关闭快门，因此确认不消耗厚度，无噪声的运行正好停在目标上。分支太短、容不下确认扫描时，切断会按容不下的部分推迟。
- **按时间**：在目标厚度除以第 1 页平均速率的时间后切断，没有信号反馈，因此膜层会按速率误差偏厚或偏薄。

计划初始取参考波长。厚度在整数个四分之一波 6 % 以内的膜层，若其在监控片上（叠在设计各层之上）的信号在距该层结束四分之一波的 6 % 以内回转，则用转折点切断；其他膜层用水平切断，几乎不改变信号的膜层则按时间切断。**自动 λ（全部）**为每层选择切断最准的波长和策略：四分之一波膜层在其回转仍可检测时保留参考波长的转折点及其自补偿；一旦截止带使信号饱和，其膜层改在带外监控，任何波长都无法胜任的膜层则按时间切断。

转折点适合在监控波长处接近四分之一波倍数的膜层，它精确且与方向无关；对其他厚度，在切断点处信号陡峭的水平切断最准。

## 理论

速率模型和监控片与[宽带模拟器](/zh/simulation/bbm-simulator/#理论)相同。在单一波长 λ_m 下，折射率为 n 的生长膜层的信号 S(d) 在膜层为整数个四分之一波时取极值：

```
n d = m λ_m / 4,     m = 1, 2, …       turning points
t_cut = d_target / r̄                   by time
```

在转折点附近 dS/dd = 0，因此时间误差几乎不改变 S，但厚度误差在 S 中也几乎看不出来；在自身波长上监控的四分之一波膜堆受益于一层的误差被下一层的切断所吸收。
