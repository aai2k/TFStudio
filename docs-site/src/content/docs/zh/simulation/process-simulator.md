工艺导出器逐层回放镀膜：第 1 层完成后的光谱、第 2 层完成后的光谱，直到完整的设计，让你看到镀膜机内的分光光度计在膜堆生长过程中将读到什么。它把每层结束时的目标光谱导出为监控软件使用的 `.res` 沉积文件，每层一个，或导出为 CSV 或文本表格。光谱使用标称材料，不含噪声；要预测实际镀出的结果，请使用[宽带](/zh/simulation/bbm-simulator/)或[单色](/zh/simulation/mono-simulator/)监控模拟器。

## 计算的量

- 图：裸基底基线（点线）、时间轴所在膜层完成后的光谱，以及当前位置的实时曲线（粗线）。**显示所有膜层**以浅灰色加入其余每层完成后的曲线；当前膜层保持全色，因为极值点只有相对于之前的曲线才有意义。悬停读数始终对应三条主要曲线。
- 序列表：每层的厚度和时间，当前层以竖条标出。

几乎不改变光谱的膜层难以监控；使光谱剧烈摆动的膜层则容易。工件按整体计算，即正面、非相干基底和背面，无论设计处于何种介质中，两侧都是空气，与分光光度计在镀膜机中所见相同。

## 控件与设置

| 控件 | 设定 |
|---|---|
| **当前面** | 正在沉积的镀膜，正面或背面。 |
| **沉积对象** | 工件或监控片。在工件上，每层都镀在同一块上，相对面为**裸**或**已镀膜**。在监控片上，每片只带有自己的膜层，从裸监控片玻璃开始，按正面镀膜生长，并在背面裸露的状态下读取。 |
| **T / R** | 监控仪读取的量。 |
| **显示所有膜层** | 默认关闭；见上文。 |
| **入射角**、**偏振** | 在设置中，s、p 或平均。 |
| **光谱范围** | 在设置中，图的起点、终点和步长；较粗的步长使拖动更流畅。超出某材料实测数据的范围会在工具栏徽标中指出，并可将范围收回到数据之内。 |
| **导出步长 (nm)** | 写入文件的步长，默认 0.5 nm；请与分光光度计的网格一致，固定阵列仪器常为 0.4375 nm 这样的数。小数点或逗号均可。 |
| **文件格式** | `.res`（固定格式）、CSV 或文本（即以 `.txt` 命名的 CSV）。 |

在监控片上，监控片方案、**监控片玻璃**和**监控片系数**与[监控工作表](/zh/simulation/monitor-worksheet/)相同：在任一窗口中输入的片号会在另一窗口中显示，序列表增加可编辑的监控片列，侧栏中有**每片层数**。

对 CSV 和文本，设置中还有：

- **文件**：**每步一个**，编号与 `.res` 文件相同，或**一张表**，每步一列（监控片模式下每片一张）。
- **表头**：**膜层表**，即带膜层表的 `.res` 表头；**条件**，以 `#` 行写出设计、步骤、入射角、入射面和偏振，[实测光谱](/zh/data-exchange/measured-spectra/)导入时会读回；或**无**，只有数字。所写的入射面是光入射的一面，每次都是正面；正在镀膜的一面或监控片上的设计膜层写在同一行。
- **分隔符**：逗号、分号、制表符或空格；设为小数逗号的电子表格可直接打开分号文件，无需导入向导。
- **Y 刻度**、**小数位数**、**小数点**：百分比或小数、每个值的小数位数、点或逗号；波长始终完整写出。

侧栏中每种材料的**沉积速率**（nm/s）只决定时间轴，不改变光谱。单击某层即把时间轴移到该层沉积完成处，然后可用方向键逐层移动；再次单击、按播放或移动时间轴即可释放。设置和速率在两次使用之间保留。

**保存**写入一个文件夹：`.res` 格式时，每个完成的步骤一个文件（`01.res`、`02.res`……），带表头和每层物理厚度与光学厚度的表格，膜层按沉积顺序从基底起编号。在监控片上，每片有一个文件夹，`chip-1`、`chip-2` 等，其中文件从 01 编号，膜层表按监控片所得的厚度列出，每个文件的注释行写明其对应的设计膜层。每步一个的 CSV 和文本文件命名方式相同；一张表则以设计名称保存，监控片模式下加上 `_chip-1` 等。较长的运行会在工具栏下方显示进度。

## 理论

第 j 层之后，工件为基底上已沉积的第 1 到 j 层，相对面为裸或已镀膜，基底中的多次穿行按强度合成（[表面与评估模式](/zh/design/evaluation-modes/#理论)）。在监控片上，沉积厚度为设计膜层厚度乘以监控片系数。时间轴为已沉积各层的 Σ d_i / r_i，r_i 为第 i 层材料的速率。
