宽带监控模拟器是一个六页的向导，在镀膜机内的宽带分光光度计监控下沉积设计：逐层沉积，带有速率抖动、折射率漂移和信号噪声，并由模拟的监控仪决定何时切断每一层。最后给出与设计并列的实际镀出光谱，让你看到设计在生产中能保持得多好。第 1 到 4 页设定条件，第 5 页运行一次实验并回放，第 6 页给出结果。

## 计算的量

- **沉积仿真**（第 5 页）：带播放、暂停、速度、拖动和膜层刻度的时间轴；当前膜层的**估计**、**实际**和**目标**厚度以柱形显示，光谱与该层 80 %、90 % 和结束时的参考曲线对比。某层切断后，其估计柱即监控仪认为已沉积的厚度，除非切断延迟，否则等于目标。
- **结果性能**（第 6 页）：制造光谱与理论光谱的对比，每层的**相对**和**绝对**厚度误差，以及实际厚度和折射率的表格。

制造曲线与理论曲线重合且误差柱很小，说明设计在这些条件下经得起生产。某一层误差很大，说明该层在这一波段难以监控，可考虑换波段、更严格的速率控制或更宽容的设计。每次运行都重新抽取误差，因此请多运行几次以看到结果的分散。

## 控件与设置

| 页 | 设定 |
|---|---|
| 1 **沉积速率** | 每种材料的**平均速率, Å/s**、**RMS, Å/s** 和**相关时间, s**。预览画出一条速率曲线；**随机化并更新**重新抽取一条。速率在层内按扫描间隔变化，并延续到同一材料的下一层。 |
| 2 **参数偏差** | 每种材料的 **Re(n) 系统偏差**、**Re(n) 随机偏差**和**系统不均匀性 (%)**；不均匀性会列在结果中，但不改变沉积的膜层。每层可**排除**出监控，并给出**相对厚度误差, %**：被排除的层停在目标厚度加上该误差处，与速率无关。**平均快门延迟**和**快门延迟 RMS**（s）为切断决定与快门实际关闭之间的延迟，加到每一层上。 |
| 3 **宽带监控系统** | 物理量和偏振（T 或 R；平均、s 或 p）、**入射角**、**扫描间隔**、波段（**波长最小**、**最大**、**点数**）以及**监控片玻璃**，即监控仪所看的监控片，初始为设计的基底。预览显示标签条中所选膜层的理想信号。 |
| 4 **信号误差** | 信号的**随机误差, %**和缓慢的**漂移, %/1000 s**，并预览带噪声的信号。 |
| 5 **沉积仿真** | **开始**运行实验；**重新开始**、**停止**和**时间倍率**。 |

沉积的镀膜面以及结果的评价方式取决于[设计编辑器](/zh/design/design-editor/)中的表面模式，以徽标显示。

## 监控仪如何切断膜层

- 从一层计划时间的 60 % 起，每次扫描时监控仪都拟合正在生长的膜层厚度。每次拟合先以比波段干涉条纹更细的步长扫描 0 到 3 倍目标厚度，然后再细化，因此不需要初值，并落在拟合最好的条纹上，而不是最近的条纹上。
- 一个跟踪器根据这些拟合跟踪厚度和速率，按每次扫描对厚度的约束程度加权，快门在跟踪的厚度达到目标处关闭，必要时在两次扫描之间关闭。没有噪声时，无论扫描间隔多大，每层都正好停在目标上。
- 每次拟合使用监控仪自己对下方膜层的估计，而不是实际沉积的厚度，因此一层的误差会像真实镀膜机中一样带入后续膜层的拟合。被排除的层按其目标厚度计入该估计。
- 信号按整块监控片读取：正面正在生长的镀膜和裸露的背面按非相干方式叠加，无论设计处于何种介质中，镀膜上方都是空气。n = 1.52 的裸监控片读数为 91.8 %，而不是单个镀膜表面的 95.7 %。

## 理论

每种材料的速率是围绕其均值 r̄ 的 Ornstein–Uhlenbeck 过程，RMS 为 σ，相关时间为 τ，膜层按速率的积分生长：

```
dx = −x / τ · dt + σ √(2/τ) dW,      r = r̄ + x
d(t) = ∫ r dt
```

两者在每一步中联合抽取，因此膜层的厚度噪声与扫描间隔无关；τ = 0 时速率噪声在厚度中完全平均掉。膜层的折射率为 n + Δn_syst + Δn_rand，每种材料每次运行抽取一次。每次扫描时，监控仪在波段上拟合

```
d̂ = argmin_d  Σ_λ ( S_meas(λ) − S_model(λ; d) )²
```

S 为监控片的 T 或 R，下方膜层取其估计厚度；快门延迟在切断后再增加 r · t_delay。
