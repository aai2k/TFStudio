监控工作表回答镀膜之前要问的问题：**这个设计到底能不能监控**。它对每一层给出监控仪可用于停切的信号有多少、停切点位于前后两个极值点之间的什么位置，以及读数出错时厚度会偏多少。无法可靠停切的设计，无论光谱如何都无法稳定地重复制造。[单色监控模拟器](/zh/simulation/mono-simulator/)运行一次实验；本窗口报告的是方案本身的可控性。

## 计算的量

按沉积顺序，每个膜层一行。

| 列 | 含义 |
|---|---|
| **监控片** | 监控片及该层在片上的位置：`2-1` 是第 2 片上的第一层。 |
| **λ (nm)** | 监控波长；该层在此波长上无法足够精确地停切时显示为红色。 |
| **信号 (%)** | 操作者停切的水平。**初始水平 (%)**只出现在每片的第一层，是监控片的起始水平，也是设定增益之处。 |
| **极值点** | 该层经过的极值点个数。为零表示它以同一片上前一层的极值点为参照，或监控仪根本看不到它变化（没有幅值，Δd 为 ∞），例如在饱和的截止带深处。 |
| **幅值 (%)** | 停切点前后两个极值点之间的全部摆幅，通常大于该层实际经过的摆幅。 |
| **起始摆幅 (%)**、**停切摆幅 (%)** | 从该层的起始水平到那个极值点，以及从极值点到停切点。 |
| **停切比** | 停切摆幅除以幅值：接近 0 时停在平坦的转折处，水平说明不了多少；接近 0.5 时停在最陡的一侧，信息最多；接近 1 时接近下一个转折。 |
| **Δd (nm)** | 读数偏差为信号误差时留下的厚度误差，按该层的停切方式计算（[理论](#理论)）；按时间停切的层没有此值。 |
| **晶控 (kÅ)** | 石英晶控的厚度，以 kÅ 计。被标记的层即必须由晶控承担的层，完整显示；其余变暗。 |

表格下方的图是监控仪所见的整炉：信号随累计光学厚度的变化，每个停切点都有标记和编号，每条曲线在停切后以虚线延续，以显示决定其幅值的极值点。各监控片以交替的色带区分，超出预算的膜层以标记颜色绘制。图下方的条带显示整炉，并框出可见部分：拖动方框或其两端，或在图上滚动滚轮；工具栏的重置回到初始视图。

## 控件与设置

**每片层数**按沉积顺序把整炉分配到各监控片，数值不理想时首先调整它。**自动 λ**为每片选择一个波长，即该片上最差的一层停切最准的波长；在任何波长上都没有信号的膜层（折射率与监控片相同）不参与选择，交给晶控。**全部设为**把一个波长用于每一层。**重置方案**放弃手动输入的片号和波长。**监控片**和 **λ** 单元格可以编辑；波长属于监控片，因此在一行中输入会改变整片，片号相同的膜层即使不是连续沉积，也在同一片上。

| 设置 | 含义 |
|---|---|
| **测量量**、**偏振**、**入射角** | 监控仪读取的量，通常为正入射下的 T。 |
| **监控片玻璃** | 监控片的玻璃，初始为设计的基底；吸收基底上的设计需在此选择透明的监控片。 |
| **监控片系数** | 监控片得到的厚度与工件得到的厚度之比；监控片与工件位置相同时为 1。 |
| **信号误差** | 读数可能的偏差，以读数的 % 计，与模拟器中的随机信号误差相同。 |
| **绝对噪声** | 光度噪声底，以满量程的 % 计。它不随读数减小，因此截止带深处已经消失的信号被判为不可用，而不是无噪声，这使自动 λ 避开反射镜自身的截止带。整个摆幅小于此值加信号误差的膜层没有可用信号。 |
| **最大 Δd** | 允许的停切误差，以该层厚度的 % 计；超过的膜层会被标记。 |
| **曲线窗口** | 图初始显示的层数。 |

**导出**复制表格，或保存表格、图中的信号曲线（每层从开始到停切：层内厚度、图上位置和信号）或图片，无论界面主题如何都使用浅色。设置面板底部设定整炉一个文件还是每片一个文件、表头（# 行写出条件、只写列名或只有数字）、分隔符、小数位数和小数点，对所有设计相同。

## 监控片

- 整炉在监控片上而不是在工件上监控，每片只带有分配给它的膜层，从裸玻璃开始。一片上层数太多，最后几层几乎没有摆幅；太少则需要的监控片多于夹具能容纳的数量。通常每片两到四层。
- 同一片上的每一层都在同一波长上监控，因为太薄、没有自身极值点的膜层要以前一层的极值点为参照，而那只存在于同一条曲线上。
- 信号按整块监控片读取，镀膜与裸露的背面按非相干方式叠加，与模拟器相同：n = 1.52 的裸监控片读数为 91.8 %，增益即按此设定。监控片悬挂在镀膜机中，镀膜上方是空气，因此设计在两块玻璃之间的滤光片仍从裸片水平开始，而不是 100 %。
- 曲线在整炉末尾趋于平坦的膜层就是需要处理的：给它们单独的监控片、换一个波长，或交给晶控。

## 理论

停切处的信号误差是读数的相对误差加上噪声底，两者都以满量程的分数表示：

```
δS = e_rel · |S| + e_abs
level cut:     Δd = δS / |dS/dd|
turning cut:   Δd = √(2 δS / |S″|)
cutoff ratio = swing out / amplitude
```

水平停切沿信号走到一个计算出的值，因此其误差是信号误差除以该处的斜率。极值点停切检测的是回转本身：在极值附近 S ≈ S_ext + ½ S″ (d − d_ext)²，因此信号必须偏离 δS 才能看出回转。两种方式由此处于同一尺度上。
