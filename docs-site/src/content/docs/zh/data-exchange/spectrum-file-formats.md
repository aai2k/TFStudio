本页回答一个问题：**TFStudio 能读取我的仪器写出的文件吗？** 对几乎所有紫外/可见/近红外分光光度计，答案都是能，因为导入器读取的是真实仪器实际产生的排布，而不是某一种理想的整齐格式。导入在[实测光谱](/zh/data-exchange/measured-spectra/)窗口中进行。

## 分隔文本

任何 `λ, value` 表格，扩展名不限：`.csv`、`.txt`、`.asc`、`.dat`、`.dpt`、`.ttt` 等等。

| 自动识别 | 支持的取值 |
| --- | --- |
| 分隔符 | 逗号、分号、制表符，或连续空格 |
| 小数分隔符 | 小数点或逗号。`400,5;88,51` 可正确读取 |
| 波长单位 | 纳米、微米，或以 cm⁻¹ 表示的波数 |
| 量 | 透射率、反射率、吸收率 |
| Y 比例 | 分数、百分比，或吸光度 |

所有自动识别的结果都可以在添加曲线之前覆盖，因此即使文件本身什么都没声明，也只需两次点击即可导入。

### 表头

仪器很少在数值上方只写一行整齐的列名。以下排布都会按其本意读取：

- **数据前的设置块。** 像 PerkinElmer 那样写在表头中、看起来像数值的行，不会成为光谱的一部分。
- **标记行。** `#DATA`、`>>>>>Begin Spectral Data<<<<<` 之类的行标明表头到此为止，数据从其后开始读取。
- **列名一行、单位另一行。** `Wave ; Sample ; Reflectance` 位于 `[nm] ; [counts] ; [%]` 上方时，每一列都能得到自己的名称并读取自己的单位，因此某一列的百分比不会决定相邻各列的比例。
- **被注释掉的表头。** 行首的 `;`、`#` 或 `//` 是注释标记，不是一列。
- **带引号的列名。** `"Wavelength nm.","R%"` 会作为反射率导入。
- **百分号的两种写法。** `%T` 与 `T%` 同样表示透射率。

### 数据行

- **每行开头的标签**（反射计常这样写）会被识别并去除：`uR 402.5238 0.0 0.237728 0.01` 是一行数据。
- **没有数值的行**会被舍去并计数，因此当文件把一次读数与一个空行交替写出时，它会告诉你丢弃了多少行，而不是悄悄地把测量减半。
- **波长降序**的文件会在导入时重新排为升序。
- 数据之后**末尾的统计块**会被忽略。

### 一个文件中的多个样品

批量测量的软件会为每个样品各写一列波长：

```
AR_front,,AR_back,
Wavelength (nm),%T,Wavelength (nm),%T
400.00,88.51,400.00,87.90
```

重复出现的波长列会被识别为样品的分界，而不是作为曲线提供，并且每条测量都以它所属的样品命名。用 **Add to design（添加到设计）** 导入其中一列，或用 **Add all curves（添加全部曲线）** 导入全部。

## JCAMP-DX

IUPAC 光谱学标准，`.dx` 与 `.jdx`，可读可写。它自带单位和量，因此无需配置即可导入。复合 `LINK` 文件会把每一个数据块导入为一条独立曲线。定长格式的 `XYDATA` 压缩与 `XYPOINTS` 数对列表都受支持。

导出时写出的 JCAMP-DX 使用你为 CSV 选择的同一波长单位和 Y 比例，因此 TFStudio 的曲线可以在任何光谱学软件中加载。

## 已验证过的仪器

以下仪器的真实导出文件已完整读取通过：PerkinElmer（PEDS ASCII 格式与 JCAMP-DX 两者）、Shimadzu UV-Probe、Agilent Cary、Filmetrics、Avantes AvaSoft、Ocean Optics，以及反射计和椭偏仪的文本格式。

如果你的仪器不在此列，它多半仍可导入，因为这份清单列出的是已经测试过的仪器，而不是仅有这些仪器可用。若某个文件无法导入，或导入成了错误的量，欢迎附上该文件[反馈](https://github.com/aai2k/TFStudio/issues)。

## 不能读取的内容

- **二进制仪器文件。** PerkinElmer `.sp`、Cary `.BSW`、Galactic `.SPC`、Bruker OPUS，以及 Avantes 的 `.TRM` 与 `.ROH` 系列。这些格式在各自的软件中都有 ASCII 或 JCAMP-DX 导出，请使用那些导出。
- **椭偏数据。** Ψ 与 Δ 文件可以作为表格解析，但这一对量尚未作为椭偏测量来读取。
- **探测器计数。** 一列原始计数会作为光谱导入，并按百分比缩放。请选择仪器报告为 R 或 T 的那一列，而不是原始信号、暗背景或参考列。
