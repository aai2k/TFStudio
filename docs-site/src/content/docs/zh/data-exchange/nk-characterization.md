**n,k 表征（n,k Characterization）** 把一次样片测量变成一种材料。给它一对来自分光光度计的透射率与反射率，或一对来自椭偏仪的 Ψ 与 Δ，它会返回薄膜的 n(λ)、k(λ) 与厚度，可直接保存进材料库并用于设计。

请先导入测量数据：R 与 T 在[实测光谱](/zh/data-exchange/measured-spectra/)中，Ψ 与 Δ 在[实测椭偏](/zh/data-exchange/measured-ellipsometry/)中。工具栏左侧的 **T / R** 与 **Ψ / Δ** 按钮选择本次运行使用哪一类测量，每种模式只提供属于它的曲线。

:::caution[单层膜，单一基底]
模型是基底上的单层薄膜。若样品在薄膜之下还有一层，例如有意加入的过渡层或较厚的热氧化层，就不是本窗口所求解的对象；把它当作单层膜来拟合，得回的是一层并不存在的膜。判据是残差：模型无法描述的样品会在 Δ 上留下以度计的残差，而不是百分之几度。
:::

## 设置

| 设置 | 作用 |
| --- | --- |
| **折射率模型** | 介质膜用 Cauchy 或 Sellmeier，金属膜用 Drude 或 Drude-Lorentz。项数由数据决定。 |
| **样品** | 测量是否看到了基底的背面（`slab`），还是半无限基底上的膜层。仅用于光度测量；椭偏仪只看到镀膜的那一个表面。 |
| **基底**及其厚度 | 薄膜所在的基底。它必须正确：这里的误差会直接进入 k。 |
| **Δ 约定** | 仅椭偏模式。必须与导入文件所携带的约定一致。 |
| **λ 范围** | 参与拟合的那一段测量。 |
| **薄膜** | 求解厚度，或固定厚度。 |

### “薄膜”一项

**固定**表示厚度严格取输入值，只拟合 n 与 k。当厚度已由台阶仪或石英晶控给出时使用。

**求解**表示厚度也参与拟合，而输入框中的数值**仍被使用**。它的用途取决于测量本身：

- 带有干涉条纹的透射率，其条纹间距本身携带厚度。厚度先由条纹读出，输入的数值不被使用。
- 其他情况，包括**每一次椭偏拟合**以及单独的反射率，都没有可读的条纹间距。此时输入的数值是厚度搜索的中心，搜索范围为该值的一半到一点五倍。

因此在求解模式下，一次 Ψ/Δ 拟合需要一个偏差不超过约三分之一的起始厚度。若给一层 100 nm 的膜填入 500 nm，正确答案就落在搜索范围之外：拟合仍会收敛，但收敛到另一层膜上，残差很小且不会报警。窗口旁边打开的设计会用其自身的单层厚度来预填此框，多数情况下这正合适，偶尔则不然。

## 得到的结果

### 图

工具栏可切换三种视图。

**n 与 k** 以两条曲线显示拟合模型，并以两组散点显示逐波长求解的结果。散点回答的是另一个问题：在每一个实测波长上，固定拟合得到的厚度，直接由两个实测值解出 n 与 k，不施加任何色散模型。对一对 R 与 T 而言，这就是经典的成对反演。它是对模型的独立校验：散点落在曲线上，说明平滑模型确实在描述这次测量；散点偏离曲线，则说明它没有。

关于散点有两点值得知道。只有求解确实到达的波长才会绘出，结果表中会计数。另外，在给定厚度下，同一波长自身的一对实测值有不止一组 (n, k) 能够重现它，因此求解从拟合模型出发，以选中它旁边的那个根。这并不会把散点拉向模型：它们仍必须精确重现测量，因此错误的模型会被留在散点之外。

**拟合**把测量与拟合薄膜的计算结果画在一起。**残差**画出两者之差，系统性误差在这里表现为结构而非噪声。

### 表

除厚度与模型之外，表中按通道给出残差，并使用该通道自身的单位：T 与 R 用绝对值，Ψ 与 Δ 用度。这是最先要读的数字。它说明模型究竟能否重现这次测量，没有任何警告可以替代它。

其余各行用来说明这次测量究竟确定了答案的多少：

- **本次测量可分辨的最小 k。** 单程吸收率为 4πkd/λ，因此仪器自身的精度给 k 设下一道下限。低于这条线的 k 描述的是仪器，而不是薄膜。
- **已求解的波长数。** 逐波长求解到达了多少个点。
- **参数间最强相关。** 厚度与折射率在测量中主要以乘积 n·d 的形式出现。当可用结构不足以把两者分开时，残差依然很小，误差范围变大，而这一项趋近于 1。相关系数接近 1 而残差很小，意味着这次测量并未确定答案，无论残差多好看。

### 警告

警告只用于命名有文献判定为错误的情形。凡属程度问题的，一律以数字形式出现在表中。

- **求得的 k 向长波方向上升。** 薄膜在其带边吸收，即在紫外，因此 k 应随波长上升而下降。Macleod 给出了产生相反情形的两条途径：把不均匀薄膜当作均匀薄膜拟合，以及光度标定存在比例误差；两者都能完美重现输入，而描述的却是错误的薄膜。请按 Macleod 的态度对待它：高度怀疑。
- **拟合得到的 n 向长波方向上升**，而该膜在整个范围内均无吸收。这通常出现在范围的端部，那里干涉条纹已经消失，测量不再约束折射率。
- **拟合得到的 n 或 k 超出真实薄膜可能的取值。** 对 k 而言这是吸收模型发散，而非薄膜异常；不要保存这样的材料。
- **实测 R 与 T 之和大于一**，这是标定问题。
- **k 仅由反射率拟合得出。** 反射率对吸收几乎不敏感，因此该数值并非测得。

## 保存结果

**保存为材料**把拟合结果写入材料库，其存储方式与拟合得到的表格材料相同：解析模型，其后附一张采样表。下游无需知道它来自一次测量。

**保存并打开设计**还会另外建立一个设计，其中包含这层膜、它所依附的基底与表征时所用的评价模式，并携带拟合所用的实测曲线。该设计能重现这次测量，因此是把拟合结果与软件中其他工具相互印证的自然场所。

**导出**把模型与逐波长的点并排写成 CSV，并附一列说明哪些点已求解。

## 方法

四个步骤，顺序如此，因为每一步都为下一步提供所需。

1. 透射率的条纹包络给出第一个折射率，并由条纹位置给出厚度。闭式求解，无需初值。若没有可读的条纹，则由恒定折射率扫描代替，厚度取自“薄膜”一项。
2. 在每一个试探厚度下，于每一个实测波长上直接解出 n 与 k。
3. 保留使求得的折射率起伏最小的那个厚度，并对其 n 与 k 拟合色散模型。薄膜的折射率是波长的光滑函数；在错误的厚度下反演，它就不是光滑的，而会带上一个以条纹周期变化的振荡。所要极小化的正是这个信号。
4. 通过精确的传输矩阵计算，把模型与厚度一起对测量做精修；这是唯一看到样品几何、入射角与偏振的一步。

第 1 到第 3 步的存在是为了把第 4 步放到正确的位置上。带条纹的光谱每一个干涉级次都有一个解，而残差无法把它们区分开，因此从任意位置出发是行不通的。

全篇参考：H. A. Macleod，《Thin-Film Optical Filters》第 5 版，“Measurement of the Optical Properties”。
