n,k 表征从实测数据求出**已知基底上单层薄膜**的光学常数：分光光度计测得的 R 和 T，或椭偏仪测得的 Ψ 和 Δ。膜厚可固定在已知值上，也可与光学常数一起拟合。结果是一个可用于设计的材料，它描述的是**你的工艺沉积出的薄膜**，与同一化学名称的手册材料不是一回事。

## 计算的量

| 标签页或行 | 显示 |
|---|---|
| **n 与 k** | 左轴为 n，右轴为 k；吸收低于测量可分辨的程度时，k 及其坐标轴不显示。线为平滑模型，即**保存为材料**写入的内容；点为在厚度固定于拟合值时逐个波长求解的 n 和 k。 |
| **拟合** | 实测曲线与由模型计算的曲线：R 和 T 以百分比表示，或左轴 Ψ、右轴 Δ，以度表示。 |
| **残差** | 计算值减实测值：R 和 T 以百分点计（90.2 % 对 90.0 % 为 +0.2），Ψ 和 Δ 以度计，Δ 取短路径。 |
| **均方根**、**最大** | 每个通道一个；此处 R 和 T 以小数表示，因此 1e-3 是十分之一个百分点。R 或 T 超过 0.003 时给出提示，这是精细测量所能达到的 0.1 % 绝对精度的三倍；Ψ 和 Δ 没有公认的指标，因此没有提示。 |
| **已求解的波长数** | 求出结果的点数。 |
| **参数间最强相关** | 接近 1 时，两个参数相互抵换，残差小也确定不了其中任何一个。 |
| 厚度离散 | 只来自拟合，不是你的实验不确定度；固定厚度时没有。 |
| **本次测量可分辨的最小 k** | 假定 R 和 T 的绝对精度为 0.001，并非读自你的仪器，也不适用于椭偏。 |

点落在线上说明模型适合该薄膜；点按某种规律偏离说明不适合；点缺失或分散说明该处测量较弱或噪声较大。这些点从模型出发求解，因此它们与模型一致只是自洽检验，不能证明答案唯一。在拟合页上，T 吻合而 R 不吻合，或 Ψ 吻合而 Δ 不吻合，都不算拟合好；残差页上应当又小又无形状，偏移、起伏或局部隆起都指向基底、厚度、入射角、偏振、Δ 约定或模型有误。

## 控件与设置

**T / R** 或 **Ψ / Δ** 选择测量类型及其两条曲线，取自[实测光谱](/zh/data-exchange/measured-spectra/)或[实测椭偏](/zh/data-exchange/measured-ellipsometry/)。**设置**中有基底及其厚度，椭偏时还有 **Δ 约定**。每条曲线的入射角和偏振取自其卡片；请在那里检查，因为导入时没有入射角的曲线按 0° 处理，而正入射下的 Ψ 和 Δ 会被拒绝。

| 设置 | 适用情形 |
|---|---|
| **柯西** | 在不吸收的范围内的介质；任何氧化物或氟化物都从这里开始。 |
| **塞尔迈耶尔** | 柯西在残差中留下形状，且色散由范围外的一个吸收带决定时。风险较大：对用 R/T 测量的高折射率氧化物，它可能停在错误的折射率上而看起来仍很平滑。 |
| **德鲁德-洛伦兹（金属）** | 所有金属；振子数由数据决定。金在可见区需要几个，铝一个也不需要，此时模型一行显示 Drude。 |
| **λ 范围** | 两条曲线都覆盖且可信的部分，并在基底数据和模型适用的范围之内。 |

运行完成、曲线平滑都不能证明模型合适：请看拟合页和残差页。拟合无法收敛时，先换模型。在 TFStudio 自己导出的光谱上比较模型时请注意，SiO2（Malitson）、MgF2（Dodge）和 BK7（Schott）本身就是塞尔迈耶尔公式，因此塞尔迈耶尔能精确拟合它们，但这对真实薄膜没有任何说明。

**薄膜 → 固定**在输入的厚度下只拟合 n 和 k。**薄膜 → 求解**同时拟合厚度：透射率中的干涉条纹给出起点和范围；没有条纹时，范围为输入值的一半到一点五倍，因此输入值的误差不得超过约三分之一。不透明金属请固定厚度，因为再厚的金属反射也相同；这样保留的厚度标为假定值。

**提取**需要一秒到一分钟，金属在细网格上求解厚度时最久；控制行显示当前阶段和用时，**停止**可结束。**保存为材料**把平滑模型存入目录；**保存并打开设计**还会建立拟合所得的样品并带上实测曲线。**导出**写出 CSV，包括平滑模型、逐点 n 和 k，以及标出已求解点的标志；逐点值只在标志为 1 处使用，模型只在拟合范围内使用。

## 准备样品

**R/T**：在两面都抛光的已知基底的一面镀膜，另一面裸露，镀膜面朝向光束。后表面是计算的一部分，没有设置可以去掉它。在重叠的波长上测量绝对 R 和 T，T 是穿过整个样品的光；相对裸玻璃的比值、光密度或已扣除后表面损失的数据都不是这里需要的 T。只有一层膜：第二层镀膜、光学上不可忽略的附着层或有散射的样品都超出模型。

![One film on the front face of a glass slab polished on both faces. Light enters from the film side, R leaves off the coating, T leaves after the uncoated rear face, and the reflections bouncing inside the glass are part of what is calculated.](/diagrams/nk-photometry.svg)

- 每条曲线带有自己相对法线的入射角和偏振；0° 的 T 与 8° 的 R 可以一起拟合。非正入射时设定 **s**、**p** 或**平均**，即两种强度各半。
- 磨砂背面散射而不吸收：在积分球的全反射模式下模型仍然成立；直通式探测器会丢失大部分 T。从积分球端口漏掉的光与吸收完全无法区分：丢失 1 % 的 T 会使 550 nm 处 500 nm 厚的透明薄膜得到 k ≈ 9e-4，是可分辨 k 的十倍，并向长波方向上升。**n 和厚度经得起磨砂背面，k 则不行。**小楔角没有影响。
- 抑制了后表面反射的测量（用折射率匹配液贴黑玻璃）无法拟合：后表面在玻璃上约占四个百分点的 R，是光度精度的四十倍，窗口会指出这一点，而不是给出错误的薄膜。挡掉部分后表面反射的光阑也是如此。
- 要用已知薄膜试用本窗口，可把它建成设计，并用整块平板（整体）的计算模式导出其光谱。“正面”导出没有后表面，任何仪器都测不到，窗口会停止并提示**“这些曲线只对应镀膜表面，不含背面”**。

![Polarized light hits the coated face at an angle from the normal, and the detector reads the change in polarization of the reflected beam.](/diagrams/nk-ellipsometry.svg)

**Ψ/Δ**：已知基底上的一层均匀薄膜，从镀膜一侧读取，且**后表面没有光返回**；透明玻璃会把后表面反射送入任何探测器，请用仪器提供的办法消除它。混入的后表面反射、退偏数据、粗糙层和额外的表面层都超出模型。

**厚度**：在测量范围中部，光学厚度低于约四分之一波时，可供拟合读取的信息很少；折射率接近基底时更少。在 BK7 上、厚度参与拟合时：

| 薄膜 | n | R/T 可求出的最薄厚度 | Ψ/Δ 可求出的最薄厚度 |
|---|---|---|---|
| MgF2 | 1.38 | 160 nm | 60 nm |
| SiO2 | 1.46 | 100 nm | 130 nm |
| Ta2O5 | 2.10 | 80 nm | 100 nm |
| TiO2 | 2.45 | 80 nm | 60 nm |

椭偏能测到更薄的薄膜，而玻璃上的低折射率薄膜最难：MgF2 在 BK7 上几乎不改变 R。低于这些厚度时，多种薄膜都能重现该光谱，固定厚度也无济于事，因为透明薄膜的 R 在 n = √n_s 处有极小值，两侧的折射率给出相同的 R。

## 理论

折射率是复数，N = n + ik。在薄膜内部强度按下式衰减

```
I(z) = I₀ exp(−4π k z / λ)
```

因此 k 不是样品吸收的份额，后者还取决于反射和干涉。透明介质镀膜材料的 n 约为 1.35 到 2.6；金属的 n 可以远小于 1。

对 R/T，样品是有限厚基底上的薄膜加裸露的后表面，玻璃中的多次穿行按强度合成，与[表面与评估模式](/zh/design/evaluation-modes/#理论)相同。对 Ψ/Δ，样品是半无限基底上的薄膜，ρ = r_p / r_s = tan Ψ exp(iΔ)。模型参数和厚度按各波长残差的最小二乘拟合；逐点的 n 和 k 则在厚度固定时，在每个波长上由两个实测通道解出两个未知数。

不是吸收造成的透射光损失 ΔT 会被读成约

```
k ≈ ΔT · λ / (4π d)
```

的消光系数，R 和 T 的 0.001 精度所对应的可分辨最小 k 也由此得出。
