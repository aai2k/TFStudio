**n,k 表征**从实测数据求出**已知基底上单层薄膜**的光学常数。输入分光光度计测得的反射率和透射率，或椭偏仪测得的一对 Ψ 和 Δ。膜厚既可以固定在已知值上，也可以和光学常数一起拟合。

结果是一个可以保存并用于设计的材料。它描述的是**你的工艺沉积出来的薄膜**，与同名材料的手册值不是一回事。

## n 和 k 是什么

折射率是复数 **n + ik**。两部分都随波长变化，都没有量纲。

| | 作用 | 怎么看 |
| --- | --- | --- |
| **n**，折射率 | 决定光穿过薄膜积累的相位。与厚度一起决定干涉条纹的位置。 | 介质镀膜材料大致在 1.35 到 2.6 之间。金属的 n 可以远小于 1，这是真实的，不是出错。 |
| **k**，消光系数 | 决定光在膜内被吸收的快慢。 | k = 0 表示模型把该膜当作透明。k 越大，该波长处吸收越强。 |

k 不是样品吸收掉的光的比例。在材料内部强度按 `exp(-4πkz/λ)` 衰减，其中传播距离 z 与波长 λ 取相同单位。样品实际吸收多少还取决于反射和干涉。

## R/T 测量的装置

![单层膜镀在两面抛光玻璃平板的前表面。光以接近法线的方向从膜面入射，R 是从镀膜面反射的光，T 是穿过裸露抛光背面之后出射的光，玻璃内部往返的反射也计入计算。](/diagrams/nk-photometry.svg)

在**已知基底、两面均抛光**的一个面上镀膜，另一面保持裸露。通常用镀了膜的玻璃见证片。这是本窗口建模的唯一一种样品：背面属于计算的一部分，而不是需要设法去掉的麻烦，也没有任何设置可以把它去掉。

计算涵盖薄膜、玻璃中的传播，以及裸露背面的反射，玻璃内部多次往返按强度叠加。

本窗口只建模一层膜。第二层镀膜、光学上不可忽略的粘附层，或者有散射的样品，都超出它能描述的范围。

测量要求是**波长范围重叠的绝对 R 和 T**。这里的 T 必须是从整个样品（含玻璃）出射的光。相对裸玻璃的比值、光密度，或者已经扣除背面损失的数据，都不是这里需要的 T。若仪器输出百分比，导入时请确认标度。

在[实测光谱](/data-exchange/measured-spectra/)中导入曲线，选择 **T / R**，两条都选上。在**设置**中填写基底材料和基底厚度。

### 用已有设计检验本窗口

想弄清本窗口在做什么，一个好办法是喂给它一段你自己生成的光谱：把薄膜建成设计、导出其光谱、再导入回来做表征，薄膜应当能被还原出来。

导出时请使用**整块平板的计算模式**，而不是 FRONT 或 BACK。FRONT 导出的是孤立的镀膜表面，不含基底背面，这不是仪器能测到的东西，也不是本窗口所拟合的对象。导入这种曲线会提示**“这些曲线只对应镀膜表面”**并停止，因为在玻璃上背面约占四个百分点的反射率，两者解不出同一层膜。

### 斜入射测量

每条曲线带有**自己的角度、偏振和受照面**，拟合会直接使用。角度从法线量起，0° 即正入射。0° 的 T 与 8° 的 R 可以一起拟合，两者不必相同。

请在实测光谱的曲线卡片上核对这些属性。它们描述的是测量条件，而不是当前打开的设计；没有角度信息的曲线按 0° 导入。斜入射时要选择实际的 **s**、**p** 或**平均**偏振，平均是指两种偏振强度各占一半。

**前表面**指光从膜面入射。若测量是从裸面入射的，请把该曲线设为**背面**，模型会把样品翻转过来。前后两面的 R 一般不相等。

### 如果背面不是抛光面

**请把两面都抛光。**本窗口只建模一种样品：镀在两面抛光基底上的单层膜，没有任何设置可以改变它。见证片很便宜，它存在的意义正在于此。

如果不得不测量磨砂背面的样品，需要知道的关键一点是：**磨砂只散射光，并不吸收。**总 R 与总 T 与抛光片相差无几，磨砂面破坏的是**镜面**光束。因此请用积分球在总量模式下测量，计算模型依然成立。直通式探测器会丢失大部分透射光束，那样的 T 没有意义。

真正的代价在于那些离开后再也没回来的光：散射到积分球端口之外，或被玻璃内部俘获。**这部分缺失的光与膜层吸收无法区分。**丢失百分之一的 T，会让一层透明膜给出约 `(丢失比例) x λ/(4πd)` 的 k，对 550 nm 处 500 nm 厚的膜约为 9e-4，是该测量所能分辨的最小 k 的十倍。它表现为 k 随波长上升，并触发 k 上升提示。**磨砂背面能保住 n 和厚度，保不住 k。**

常见的小楔角使透射光束偏折远小于一度，对 T 毫无影响。

如果背面反射确实已被去除，例如用折射率匹配液贴合黑玻璃，本窗口无法拟合这种测量：在裸玻璃上背面约值四个百分点的反射率，是光度测量精度的四十倍。窗口会以很大的残差或无法求解来告知，而不会悄悄给你一个错误的薄膜。

模型假定背面返回的光被收集。光阑或某些附件会挡掉其中一部分，这会改变实测 R/T，而本样品模型并不知道。

## 椭偏测量的装置

![偏振光以已知角度斜入射到镀膜面。探测器读取反射光偏振态的变化。必须把从基底背面返回的光挡在探测器之外。](/diagrams/nk-ellipsometry.svg)

椭偏仪测量反射如何改变偏振态。**Ψ** 比较 p 与 s 反射振幅，**Δ** 是两者的相位差。两者合起来无需任何透射光即可确定 n 和 k。

在[实测椭偏数据](/data-exchange/measured-ellipsometry/)中导入这一对曲线，选择 **Ψ / Δ**，两条都选上。核对两条曲线的角度，并在设置中选择 **Δ 约定**，选错会改变 Δ 的含义。正入射的 Ψ/Δ 不包含镀膜信息，窗口会拒绝这类数据。

模型是已知基底上的一层均匀薄膜，从镀膜面测量，并假定**背面没有光返回**。透明玻璃无论用什么仪器都会把背面反射送进探测器，请使用仪器自带的抑制手段。混入背面反射的数据、退偏数据、粗糙层和额外的表面层，都不在本模型范围内。

## 薄膜要多厚才测得出来

只有测量"看得见"薄膜，薄膜才会交代自己的折射率。当光学厚度低于测量波段中心波长的四分之一波左右时，可供拟合读取的信息就很少；若薄膜折射率又接近基底，信息就更少。

以 BK7 为基底、厚度参与拟合时：

| 薄膜 | n | R/T 能测出的最小厚度 | Ψ/Δ 能测出的最小厚度 |
| --- | --- | --- | --- |
| MgF2 | 1.38 | 160 nm | 60 nm |
| SiO2 | 1.46 | 100 nm | 130 nm |
| Ta2O5 | 2.10 | 80 nm | 100 nm |
| TiO2 | 2.45 | 80 nm | 60 nm |

由此有两点。**椭偏能测的薄膜比 R/T 更薄**，这正是选用椭偏的常见理由。以及**玻璃上的低折射率膜最难测**：MgF2 在 BK7 上几乎不改变 R，所以 R/T 需要它比四分之一波再厚一半，结果才稳定。

低于这些厚度时，拟合仍会给出与测量吻合的光谱，因为不止一种薄膜能复现它。固定厚度也救不了：把膜当作透明时，R 在 n = √n<sub>基底</sub> 处取极小值，该极小值两侧的折射率给出相同的 R。请看提示和残差，薄膜请交给椭偏仪。

## 选择模型和厚度

| 设置 | 何时使用 |
| --- | --- |
| **柯西（Cauchy）** | 在不吸收的波段内的介质膜。任何氧化物或氟化物都先用它。 |
| **塞尔迈耶尔（Sellmeier）** | 当柯西在残差里留下明显形状时可以试。它是共振形式而非多项式，适合色散确实由波段外某条吸收带决定的薄膜。它比柯西更冒险：用 R/T 测高折射率氧化物时，它可能落到错误的折射率上，曲线看上去却依旧光滑。 |
| **德鲁德-洛伦兹（Drude-Lorentz，金属）** | 所有金属都用它。它同时涵盖自由电子和叠加其上的吸收，并从数据中读出振子个数。可见光波段的金需要好几个振子；铝一个都不需要，此时模型一行会显示 Drude，因为拟合出来的正是它。 |
| **λ 范围** | 两条曲线都覆盖且你信得过的部分，且在基底数据和模型都成立的范围内。 |

模型要同时匹配**材料**和**你测量的波段**。曲线光滑、运行结束，都不能证明模型合适。保存之前一定要看拟合和残差。

如果拟合定不下来，先换模型，再动别的。错误的模型不一定留下明显残差：它可能落在一个看似合理、却离真实薄膜很远的折射率上。

用 TFStudio 自己导出的光谱试模型时有一个陷阱。若干内置材料**本身就是色散公式**，而不是实测数据表：SiO2 用 Malitson，MgF2 用 Dodge，BK7 用 Schott，三者都是塞尔迈耶尔形式。用塞尔迈耶尔去拟合由它们生成的光谱，当然精确复现，因为那是拿公式去拟合公式本身。这说明不了哪种模型适合真实薄膜。模型的取舍要用真实测量来判断。

## 三个标签页

### n 和 k

横轴是波长，**n 用左轴，k 用右轴**。当吸收低于测量所能分辨的水平时，k 曲线及其坐标轴会隐藏。

- **曲线**是光滑的色散模型，**保存为材料**保存的就是它。
- **散点**是在每个波长上单独求解的 n 和 k，厚度固定在拟合值上。只画出求解成功的点。它们来自同一次测量，而不是另一次测量。

散点落在曲线上，说明模型适合这层膜；成规律地偏离，说明不适合。散点缺失或散乱，说明该处测量信息弱、噪声大，或不易求解。

散点是从拟合模型出发求解的，可能落在与模型相同的分支上。两者一致是一种自洽性检验，**不能证明解唯一，也不能证明样品模型正确**。

### 拟合

把**实测曲线**和**由拟合模型算出的曲线**叠在一起。R 和 T 以百分比绘制。椭偏时 Ψ 用左轴、Δ 用右轴，均为度。

要在整个波段内同时看两个通道。T 对上而 R 对不上，或 Ψ 对上而 Δ 对不上，都不算拟合成功。基底、厚度、角度、偏振、Δ 约定或模型选错，都会在这里显现。

### 残差

**计算值减实测值**，对波长作图。零表示吻合，正值表示计算偏高。

R 和 T 用**百分点**：计算 90.2%、实测 90.0% 即 +0.2，而不是 0.2% 的相对误差。Ψ 和 Δ 用度，且 Δ 取圆周上的最短差，所以 359° 与 1° 相差 2°，而不是 358°。

理想情况是残差小而无形状，量级与你的测量误差相当。整体偏移、周期性起伏，或某处的局部凸起，都是系统性问题。残差的形状能缩小排查范围，但不能直接指认原因。当两条曲线在"拟合"页上看起来完全重合时，正是这一页能看出差别。

## 读结果表

表中给出每个通道的 **RMS** 和**最大值**。**这里的 R 和 T 是小数**，与图上的百分点不同，所以 RMS 为 `1e-3` 相当于 0.1 个百分点。Ψ 和 Δ 两处都是度。

当 R 或 T 的 RMS 超过 0.003 时，光度测量会给出提示，这是仔细测量所能达到的 0.1% 绝对精度的三倍。Ψ 和 Δ 没有对应提示：没有公认的数值可供比较，在此自行设定阈值会误报合理的拟合；请直接看数值和残差图。

**已求解波长数**是成功求出的点数。**最强参数相关性**接近 1 时，说明两个参数可以互相补偿，此时残差再小也无法单独确定其中任何一个。厚度的离散度只来自拟合本身，不是你的实验不确定度。固定的厚度没有离散度可报。

**本次测量可分辨的最小 k** 假定 R 和 T 的绝对精度为 0.001。它不是从你的仪器读来的，也不适用于椭偏。不要因为返回了数字就把极小的 k 当作真实吸收。

## 保存结果

装置、拟合和残差都确认无误后，**保存为材料**会把光滑模型写入材料库。**保存并打开设计**还会建立拟合所用的样品，并把实测曲线一起带过去。R/T 结果按整块平板求值。

**导出**会写出 CSV 列：光滑模型、逐波长的 n 和 k，以及标记哪些点求解成功的标志位。只在标志位为 1 处使用逐波长数值。保存的材料是光滑模型，而不是逐波长那一列。未经进一步测量，不要把它外推到拟合范围之外使用。
