Zemax 镀膜读写 OpticStudio 的 `COATING.DAT` 文件：一个由 `MATE`（材料）和 `COAT`（膜层堆栈）记录组成的文本数据库，另有 `IDEAL`、`IDEAL2`、`TABLE`、`TAPR` 和 `ENCRYPTED` 镀膜模型。它把膜层堆栈及其材料导入设计或[镀膜库](/zh/design/coating-library/)，并把当前设计导出为 `COAT` 堆栈及其 `MATE` 记录。**镀膜**、**材料**和**导出**是与参考波长同在一行的标签页；上一次操作的结果显示在该行右端。

## 计算的量

**镀膜**列出每条镀膜记录及其类型和层数，以及所选堆栈的各膜层及其材料和物理厚度。**材料**列出每条 `MATE` 记录。**导出**在保存之前预览 `COAT` 和 `MATE` 文本。

## 控件与设置

镀膜或材料标签页面板中的**载入 COATING.DAT…**读取文件；切换窗口时，其内容和你的选择保持不变。**参考 λ₀ (nm)**在导入和导出时把以波数计的相对厚度换算为 nm。

**镀膜**：只有 `COAT` 堆栈可以导入；其他记录带锁列出，因为 `IDEAL`、`IDEAL2` 和 `TABLE` 以 R 和 T 而非膜层描述表面，`ENCRYPTED` 无法解码。

- **导入 → 正面镀膜**把堆栈放到当前设计的正面，其 `MATE` 材料放入 `Zemax <文件>` 目录。在只镀背面且勾选了[**忽略另一面**](/zh/design/evaluation-modes/)的设计上它不可用。
- **保存到镀膜库…**通过镀膜库的对话框把堆栈保存到“我的镀膜”。`COAT` 记录不指定介质，因此镀膜采用当前设计的介质，没有打开设计时为空气与 BK7。其厚度按 λ₀ 换算，λ₀ 随之保存，材料随镀膜一起携带，因此不会向你的目录添加任何内容。

**材料**：勾选记录后按**导入所选 →**，或按**导入全部 →**，把它们加入目录而不改动设计。

**导出**，取自当前设计的正面：

- **膜层厚度**：**绝对 (µm)**或以 λ₀ 波数计的**相对（波）**。绝对厚度不需要 λ₀，也没有损失。
- **包含材料**：**设计所用**或**全部目录材料**。
- **镀膜名称**：`COAT` 记录的名称。
- **材料采样网格 (nm)**：把每种材料的 n、k 制表写入其 `MATE` 记录时所用的范围和步长。

## 格式约定

| 量 | Zemax | TFStudio |
|---|---|---|
| 波长 | µm | nm |
| 消光 | 保存 −k | k > 0，双向翻转符号 |
| 膜层厚度 | 以波数计的相对 T，或以 µm 计的绝对值 | 以 nm 计的物理厚度 d |
| 膜层顺序 | 从最外层到基底 | 与正面镀膜的存储顺序相同 |

- 不需要反转：Zemax 的顺序就是 TFStudio 存储正面镀膜的顺序；设计编辑器只是从基底起显示。导出后再读回的设计保持其厚度和 k 的符号。
- 导入的材料按行间直线读取其 `MATE` 表格，并在表格之外保持端点行的值，与 Zemax 相同。早期版本由该文件生成的目录按平滑曲线读取表格：在材料标签页再次导入时，这些材料被列为已更改，替换前会询问，而镀膜导入会保留它们。
- 在多条 `MATE` 记录中定义的同一名称（不区分大小写）在材料标签页标为 **2 / 2** 等，并在提示中列出。每条记录单独导入，后面的记录在名称后加 (2)、(3)；引用该名称的镀膜膜层使用该名称的最后一条记录。若各记录不同，请确认文件原意是哪一条。

## 理论

相对厚度 T 是以透镜主波长 λ₀ 处波数表示的光学厚度：

```
d = T · λ₀ / n(λ₀)
```

n 为该层在 λ₀ 处折射率的实部。λ₀ 属于透镜而非文件，因此相对厚度的镀膜需要给出它。帮助中的算例：n = 1.4、T = 0.25、λ₀ = 0.550 µm 时 d = 0.0982 µm。
