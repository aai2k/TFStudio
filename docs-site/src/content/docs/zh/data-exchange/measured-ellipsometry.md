**实测椭偏（Measured Ellipsometry）** 窗口把光谱椭偏仪测得的 Ψ 与 Δ 引入设计。**Import（导入）** 从仪器文件读取这一对曲线并存入设计；**Export（导出）** 则把你导入的曲线，或设计自身计算出的 Ψ/Δ，写入 CSV。

椭偏曲线与[实测光谱](/zh/data-exchange/measured-spectra/)中的光度曲线分开存放，理由很实在：它们没有百分比刻度，没有偏振可选，离开入射角就毫无意义，而且其 Δ 带有因仪器而异的符号约定。在此导入的 Ψ/Δ 曲线对，正是 [n,k 表征](/zh/data-exchange/nk-characterization/)用来求出薄膜光学常数的输入。

## 本窗口接受何种测量

**各向同性样品上的反射式椭偏测量。** 这里的 Ψ 与 Δ 由反射幅值比定义：

```
ρ = r_p / r_s = tan(Ψ) · exp(i Δ)
```

这与[椭偏仪](/zh/analysis/ellipsometry/)计算设计自身曲线所用的定义相同。因此，只要测量是以角度为单位、随波长变化、在给定角度下反射测得的 Ψ 或 Δ，就可以导入并拟合。层厚拟合可以单独使用其中任一条曲线；[n,k 表征](/zh/data-exchange/nk-characterization/)则需要同一次测量的两半，因为它在每个波长上求解两个未知量。

以下几类不在此范围内，都不会被读取：

| 不支持 | 应当如何处理 |
| --- | --- |
| **透射式椭偏。** 模型是反射的那一对量；透过样品测得的是另一个量。 | 对同一样品改用反射方式测量。 |
| **广义椭偏或 Mueller 矩阵椭偏**，以及任何各向异性或退偏样品。 | 本软件不涉及。薄膜按各向同性处理。 |
| **Is、Ic 与 Ic′**，相位调制式椭偏仪的原生量。 | 在仪器自带软件中导出为 Ψ 与 Δ。 |
| **tan Ψ 与 cos Δ** 而非角度。某些导出会把它们写在标着 `PSI` 与 `DELTA` 的标题之下。 | 导入前先换算为角度。窗口会识别出这样的 Δ 列并给出提示，而不会拿它去拟合。 |
| **单一波长下的角度扫描。** | 这里的曲线是波长的函数。请用[椭偏仪](/zh/analysis/ellipsometry/)的角度模式与设计对比。 |

哪些仪器的导出文件已完整读取通过、哪些没有，见[椭偏文件](/zh/data-exchange/spectrum-file-formats/#椭偏文件)。

## 导入

点击 **Open file…（打开文件）** 并选择文件。导入器读取哪些内容，见上面链接的格式页面。

打开的文件属于项目浏览器中当前选中的设计。切换到另一个设计时，窗口只显示那个设计的曲线，不会带上这个文件；切回来时文件仍在原处。未选择设计时没有可导入的对象，按钮不可用。

### 配置各列

面板会显示解析结果，并允许你在添加之前改正：波长单位、取哪一列、该列是 Ψ 还是 Δ，以及曲线名称。旁边的预览会绘出你正在配置的那一列；点击设计中的某条曲线后，预览随之切换到该曲线。拖动面板与图之间的分隔条，可以给任一侧腾出更多空间。

名称下方是文件可能未写明的几项。它们在添加时随曲线一同保存，之后仍可在曲线的卡片上修改。

- **入射角**，仅当文件有列未给出角度时才会询问，并对所有这类列生效，因为 **Add all typed columns（添加全部已定量的列）** 也会添加它们。它是一对 Ψ/Δ 离开它就无法解读的唯一设置：在正入射下 p 与 s 之间不再有可测的区别，因此任何薄膜都给出 Ψ = 45°、Δ = 180°，这一对量对膜层一无所述。以 0° 到达的曲线会被拟合拒绝。该字段以 70° 起始，这是多数定角仪器所处的角度，接近硅的主角。

- **Δ 约定**，文件中一旦含有 Δ 列即询问，因为没有文件会写明它。提供两种：

  | 设置 | 含义 |
  | --- | --- |
  | **Azzam–Bashara** | 测量文件所携带的约定。这是默认值，除非另有把握，请保持不变。 |
  | **360° − Δ** | 符号相反的 Δ，用于按另一种时间约定写出的数据。Ψ 在两种约定下相同。 |

  [椭偏仪](/zh/analysis/ellipsometry/)中对计算曲线也有同一项选择，两者必须一致，否则对比毫无意义。若导入的 Δ 看上去像设计曲线的镜像，首先应改的就是这一项。

- **入射面**，仅当设计两面都有镀膜时询问：这次测量属于哪一面的膜层。背面的曲线会绘在[椭偏仪](/zh/analysis/ellipsometry/)的背面一侧，目前还不能拟合。已标为背面的曲线，其卡片会一直保留该设置，无论设计此后是什么样子，因此总能把它改回正面。

**Ψ 与 Δ 由数值区分，而非由列序区分。** Ψ 是幅值比的反正切，不可能超出 0 到 90 度，而 Δ 走完整整一圈。因此超过 90 度或小于零的那一列必为 Δ，不可能是 Ψ。若由此仍无法判定，则沿用文件中的顺序，一次点击即可对调。文件中已命名为 `Psi` 或 `Delta` 的列按其名称采信。

**Add this column（添加此列）** 添加你刚配置的那一列。**Add all typed columns（添加全部已定量的列）** 添加每一列有量的曲线，两列的 Ψ/Δ 文件正合适。

### 设计中已有的曲线

每条曲线是一张卡片：第一行是是否绘制、颜色、它是哪一半以及名称；其下是测量所用的角度、设计两面都有镀膜时它所属的面、Δ 写入时所用的符号，以及点数与范围。所有这些都可以修改。点击卡片即可在预览中查看该曲线。

始终不超出 −1 到 1 的 Δ 列会被标出。至少有一家仪器在写着 `PSI` 与 `DELTA` 的标题下给出的是 tan Ψ 与 cos Δ；若按角度解读，这些数值合法而错误不可见，因此窗口会明确指出，而不是让拟合在其上运行。请先把这样的文件换算为角度再导入。

## 把设计拟合到测量

在某条曲线上点击 **Fit…（拟合）**，即可把它变成评价函数目标，供[优化](/zh/synthesis/refinement/)调整设计的层厚，直到计算出的 Ψ 或 Δ 与测量相符。这与[实测光谱](/zh/data-exchange/measured-spectra/)对反射率或透射率曲线提供的是同一步骤：同样的网格选项、范围、权重与厚度约束。它是对配方已知的膜系做表征，不是从头恢复未知膜系；让折射率随层厚一起浮动的是 [n,k 表征](/zh/data-exchange/nk-characterization/)。

曲线逐条拟合，每条在[评价函数编辑器](/zh/design/merit-function-editor/)中成为一行，各自保存一份采样点副本。单独一条 Ψ 就是正当的目标：在一段光谱范围内它足以确定已知膜系的层厚。单独一条 Δ 同样如此，而在另一角度下测得的 Δ 只是又一个目标。要拟合同一次测量的两半，在两条曲线上各点击一次 **Fit…**，两行会一起计入评价函数。

与光度拟合不同之处：

- **Δ 约定随目标一起保存。** 该行记录文件所用的符号，在进入评价函数时换算，因此按 Azzam–Bashara 导入的曲线对与设计的 Δ 以同一符号比较。约定选错会差几十度，而不是零点几度。
- **Δ 按短弧计分。** 设计在 359° 而目标在 1° 时相差两度而不是 358 度，因此靠近 0°/360° 边界的目标不会把优化器拖着绕远路。
- **Ψ 与 Δ 各有自己的尺度**，与同一表中的反射率目标相比时按光谱椭偏仪的分辨能力设定，而不是按 90° 与 360° 的量程。见[操作数参考](/zh/design/operands/)。
- **Δ 的等步长重采样**对展开后的角度插值，因此当测量跨过 360° 时，重采样网格不会臆造出经过 180° 的目标。
- **Ψ 与 Δ 一起采样。** 两半使用相同的网格设置；若两条曲线覆盖的波长不同，目标会被裁到两者共有的波长，因此两行的点数相同、权重相同。没有共同波长的曲线对会被拒绝。

正入射时 Ψ 与 Δ 不含薄膜信息，拟合会被拒绝；背面测得的曲线对同样被拒绝，因为 Ψ 与 Δ 只按正面膜系计算，设计也必须按正面评价。

无论设计是否仍保有目标背后的曲线，[椭偏仪](/zh/analysis/ellipsometry/)窗口都会按当前显示的 Δ 约定绘出这些目标；导入标签页可以从目标恢复曲线，与实测光谱窗口相同。

## 导出

**Measured（实测）** 写出设计中已有的曲线，每条曲线各有一个复选框。

**Calculated from the design（由设计计算）** 在你选定的波长范围、步长与角度下，写出设计自身的 Ψ 与 Δ。可用来把目标交给仪器自带软件，或生成一份参考文件。Δ 按按钮旁所选的约定写出；仪器软件读取的是 Azzam–Bashara。该选择只属于导出，不会改变导入标签页上读取文件所用的约定。

两种导出的 X 轴都可以是纳米、微米，或以 eV 表示的光子能量。

## 值得做一次的往返检验

把设计计算出的 Ψ/Δ 导出，再直接导入回来，是确认两侧约定是否一致的最快办法。在 [n,k 表征](/zh/data-exchange/nk-characterization/)中拟合它，应当得回你出发时的那层膜，残差接近于零。一层 500 nm 的 TiO₂ 经此往返回来是 499.9 nm，Ψ 残差 0.008°、Δ 残差 0.05°。若你自己的往返闭合不上，首先要核对的就是 Δ 约定与入射角。
