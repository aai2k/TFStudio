实测光谱把设计与分光光度计联系起来。从仪器文件**导入**实测的 R、T 或 A 曲线，在[光学评价](/zh/analysis/optical-evaluation/)上与设计比较，并把设计的膜层厚度**拟合**到它；**导出**把计算的设计光谱或导入的曲线写入文件。典型用途是检查一次镀膜：实测曲线偏离预测曲线之处表明镀膜与设计的差别，拟合则把这一差别换算为镀膜机实际镀出的厚度。

## 计算的量

- 在光学评价上，每条曲线显示为带空心圆的点线，按 R、T 或 A 着色。
- 导入时，预览把导入的曲线画在设计于该曲线入射角下的光谱上，因此位置不对的测量在添加之前就能看出。
- 拟合目标报告设计与测量之间的 RMS 差值，单位与曲线相同；以 dB 拟合时为 dB。

## 控件与设置

曲线属于项目浏览器中所选的设计，并随项目保存；另一个设计显示它自己的曲线，已打开的文件会等你回来。未选择设计时，窗口会要求选择一个。

### 导入曲线

**导入光谱…**读取文件；支持的格式见[光谱文件格式](/zh/data-exchange/spectrum-file-formats/)。对文本表格，面板显示检测到的内容并允许更改：波长单位、列、物理量、Y 刻度和名称。然后是文件未说明的条件，每一项都值得检查，因为错误的条件会悄悄破坏拟合：

- **入射角**，任一列没有入射角时询问，并应用于所有列。近正入射附件通常为 6° 或 8°，而不是 0。
- **偏振**：**平均**、s 或 p。吸收率没有偏振，因此不询问；列标题为 Rs 或 Tp 的列保留其自身偏振。

测量时镀膜面朝向光束。**添加到设计**添加设置好的列；**添加所有曲线**用于含多个数据列的文件，一次添加全部，适合 T 与 R 并列的文件，不适合含原始信号列的文件。

每条曲线有一张卡片：名称、**曲线颜色**、物理量、**源数据刻度**、入射角和偏振、**裁剪范围**和**可见**。裁剪改变各处使用的范围但保留数据点，因此可以再放宽。

### 输入曲线或修改其数据点

**新建曲线**在空表格上打开曲线编辑器，卡片上的**编辑**则在该曲线上打开它：左侧是表格，右侧是绘在设计于该曲线入射角和偏振下的光谱之上的图。

- **列**：波长以 nm、µm、cm⁻¹ 或 eV 计；每个数值列有一个物理量 T、R 或 A，以及单位：%、0-1、dB，T 和 R 还可用 **dB 损耗**（以正的 dB 数表示的损耗，损耗曲线或回波损耗通常这样写），T 还可用光密度。单位说明数值是什么；更改单位不会换算数值。**+ 列**添加数值列，垃圾桶图标删除一列；每个数值列成为一条曲线，因此 T 与 R、s 与 p 可以并列输入。
- **单元格**：单击、Shift、拖动和 Ctrl 选择；输入即替换，小数逗号按小数点读取；Ctrl+C 与 Ctrl+V 复制粘贴，从电子表格粘贴的整块按文件导入的方式读取；Delete 删除行，Backspace 清空单元格，Ctrl+Z 撤销。拖动选区右下角的小方块可延续它：一个数会被复制，按住 Ctrl 时每次加减 1，两个或更多数则沿其最佳直线延续，因此 400、410 之后是 420、430。
- **填充…**写入一个值、等步长序列，或在对数或波数上等距的一段。**变换…**按百分比缩放或把 V 变为 a·V + b。**平滑…**在两侧各取你设定的点数，按你设定的阶数拟合多项式（Savitzky-Golay），从不作用于波长列。**重采样…**按拟合所用的插值方式把每一列放到新的步长上。各工具的面板在打开时跟随选区。
- 高于 100 % 或低于 0 的值显示为红色。打开**拖动点**后，在图上拖动的点取其放下处的值。**Y** 设定图的纵轴范围，或用**自动**适配。

**应用**按波长排序，并添加或修改曲线。若有拟合目标由被编辑的曲线生成，它会提出按新数据点重建这些目标，并保留其网格、范围、权重和刻度。以 dB、dB 损耗或 OD 输入的曲线保持其单位，其卡片在**源数据刻度**下显示**以 dB 输入**等，而不是百分比与小数的选项。[脉冲分析](/zh/analysis/pulse-analysis/)在脉冲光谱上打开同一编辑器，带有强度和光谱相位两列；平滑和重采样会先展开包裹的相位。

### 导出

**导出内容**：**设计光谱**，即当前设计计算出的 T、R 和 A，按范围和步长、一组入射角和所选通道，可按需分为 s 和 p，采用当前表面模式，且无需打开光学评价；或**实测曲线**，即勾选的曲线。两者都可写为 CSV 或 JCAMP-DX。实测曲线还可选择 **X 单位**（nm、µm 或 cm⁻¹）以及小数或百分比；设计光谱始终以 nm 和百分比写出。

## 将设计拟合到测量

卡片上的**拟合…**把测量变为评价函数目标，使[精炼](/zh/synthesis/refinement/)移动设计的膜层厚度，直到光谱与之吻合。它用于表征已知配方的镀膜；仅凭强度恢复未知的膜系是无解的。

- **网格**：**实测点**使用每个数据点，不做任何插值，适合密集而均匀的扫描，为默认值。**抽稀**保留每第 N 个点（**每第 N 个**）以及终点。**均匀**重采样到等步长。把粗扫描重采样到细网格不会增加信息；它使权重均匀，因为评价函数对各点求和，不均匀的扫描会使拟合偏向仪器读数较多的地方。重采样是保形的，因此在陡峭的边缘不会过冲到 100 % 以上。
- **拟合单位**：对透射率为 % 或 dB。以 dB 拟合时，0.1 dB 的偏差在 −20 dB 和 0 dB 处权重相同，适用于以 dB 给出的曲线，例如增益平坦目标；不高于 0 % 的点在 dB 下没有值，会被舍弃。
- **拟合范围**、**权重**，以及带最小和最大厚度的**添加厚度约束**。**裁剪到材料数据范围**舍弃材料没有数据的点，而不是用外推的 n 和 k 拟合。**评价函数**：**追加**到现有评价函数，或**替换**它。

**创建 MF 目标**写出一行，保存测量的副本，因此它随设计一起保存，曲线被修改或删除后仍然有效。只能编辑**启用**和**权重**，因为其余内容记录的是已经完成的测量。无论曲线是否还在，光学评价都会画出该目标，导入标签页会提出恢复曲线。以 dB 拟合的目标显示为 **MCURVE dB**，恢复为透射率曲线。

## 理论

目标在其 M 个点上的值，C 为设计的通道值，C_j 为 λ_j 处的实测值：

```
RMS = √( (1/M) Σ_j (C(λ_j) − C_j)² )
in dB:   C → 10 log₁₀ C
```

运行时该行展开为每点一个残差，使最小二乘看到偏差的形状而不只是一个数。**均匀**和**重采样…**使用 Fritsch 与 Carlson 的保形分段三次插值；**平滑…**为 Savitzky-Golay 最小二乘多项式。
