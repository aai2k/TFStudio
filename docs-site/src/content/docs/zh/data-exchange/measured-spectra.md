**实测光谱（Measured Spectra）** 窗口将你的设计与分光光度计连接起来。**导入**一条来自仪器文件的实测反射率、透射率或吸收率曲线，在[光学评估](/zh/analysis/optical-evaluation/)上与设计对比，并把设计的膜层厚度**拟合**到它。**导出**则把计算得到的设计光谱或你导入的曲线写入可移植文件。窗口分为 **Import（导入）** 和 **Export（导出）** 两个标签页。

## 导入

点击 **Import Spectrum（导入光谱）** 并选择文件。导入器接受哪些内容、以及它会自行处理的仪器格式怪癖，见[光谱文件格式](/zh/data-exchange/spectrum-file-formats/)页面。

打开的文件属于项目浏览器中当前选中的设计。切换到另一个设计时，窗口只显示那个设计的曲线，不会带上这个文件；切回来时文件仍在原处。未选择设计时没有可导入的对象，按钮不可用。

### 确认解析

对于文本表格，面板会显示自动识别的结果并允许覆盖：波长单位、取哪一列、量、Y 比例，以及曲线名称。旁边的预览会在该曲线自己的入射角下计算设计光谱，并把导入的曲线与之一同绘出，因此在提交之前你就能看出测量是否落在设计所在的位置。

名称下方是文件未写明的测量条件，而文件几乎从不写明它们。错误的取值会毁掉一次拟合，却看不出任何异常，因此添加曲线前请逐项核对：

- **入射角**，只要文件有任何一列未给出角度就会询问，并对所有这类列生效，因为 **Add all curves（添加全部曲线）** 也会添加它们。近正入射附件通常是 6 度或 8 度，而不是 0 度。
- **偏振**：平均、s 或 p。吸收率不询问偏振：它是样品对到达它的全部能量所吸收的部分，没有偏振可选。

每条导入的曲线都各自带有这些条件，之后也可以在曲线上修改。测量时镀膜面朝向光束；没有反过来测量的设置。

**Add to design（添加到设计）** 添加你刚配置的那一列。当文件含有多列数据时会出现 **Add all curves（添加全部曲线）**，它会添加其中每一列：对同时含有 T 与 R 的文件正合适，而对还带有原始信号列的文件则不合适。

### 编辑曲线

导入的曲线存储在设计上，并**随项目一起保存**。每条曲线在窗口中都有一张卡片，可以重命名、改颜色、改量、修正来源比例、修正测量条件，以及**裁剪**波长范围。裁剪是非破坏性的：它只移动别处所使用的边界，数据点仍保留在曲线中，因此你可以再把范围放宽。

在光学评估中，这些曲线显示为带空心圆标记的虚线，按 R / T / A 着色。卡片上的复选框可以隐藏某条曲线而不将其移除。

### 输入曲线或修改其数据点

**Import Spectrum（导入光谱）** 旁的 **New curve（新建曲线）** 以空表格打开曲线编辑器，曲线卡片上的 **Edit（编辑）** 则以该曲线的数据点打开它。数据点在左侧的表格中，右侧把它们绘出，背后是设计在该曲线入射角与偏振下自己的光谱。拖动两者之间的分隔条，可以给任一侧腾出更多空间。

- **列。** 每个数值列都有一个物理量（T、R 或 A）和一个单位：%、0-1 或 dB，T 另有光密度 OD。单位说明输入的数字是什么；更改单位不会换算这些数字。波长列可用 nm、µm、cm⁻¹ 或 eV。每个数值列各自成为一条曲线，因此 T 与 R，或 s 与 p，可以并排输入。
- **选择与输入。** 单击、Shift+单击或拖动以选择单元格，Ctrl+单击追加单元格。直接键入即可替换数值；小数逗号按小数点读取。Ctrl+C 与 Ctrl+V 复制与粘贴，粘贴的单个值或一行会在所选范围内重复填充；从电子表格或文本文件粘贴的数据块按导入文件的方式读取，表格会自动扩展以容纳它。Ctrl+Z 撤销。
- **Fill（填充）** 沿所选单元格向下写入常数、等步长、对数步长或波数等步长。**Change（变换）** 按百分比或 a·V + b 改变它们。
- **Smooth（平滑）** 对所选值做 Savitzky-Golay 平滑。**Resample（重采样）** 用拟合所用的插值把各列放到均匀步长上，并在步长小于数据点间距时给出提示。
- 高于 100 % 或低于 0 的值以红色标出。打开 **Drag points（拖动点）** 后，在图上上下拖动一个点，它就取松开处的值。

**Apply（应用）** 把各行按波长排序，添加新曲线或修改所编辑的曲线；此后它们与任何导入的曲线一样。新曲线的入射角与偏振在其卡片上设置。如果评价函数中有由所编辑曲线生成的拟合目标，应用时会提供按新数据点重建它们的选项，并保留各自的网格、范围、权重与刻度。

## 将设计拟合到测量

曲线卡片上的 **Fit…（拟合…）** 会把这条测量变成一个评价函数目标，于是[精炼](/zh/synthesis/refinement/)可以调整设计的膜层厚度，直到计算光谱与你测得的结果相符。这是对一个你已知配方的镀膜所做的表征；它不是从任意光谱反推未知膜系，那仅凭强度是无法求解的。

### 拟合哪些点

- **As measured（按实测点）** 直接使用实测点，不臆造任何数据。当扫描足够密集且间隔均匀时正确，也是默认选项。
- **Every Nth point（每隔 N 点）** 仍只用实测点，但做抽稀。当非常密集的扫描拖慢运行而并无收益时使用。
- **Even step（等步长）** 按你指定的波长步长插值。

把稀疏的扫描插值到密集网格上**并不会增加任何信息**。重采样的理由是均匀性而不是密度：评价函数是对其各点求和，因此采样不均的扫描会悄悄把拟合偏向仪器恰好多取了读数的地方。插值采用保形算法，因此不会在陡峭的带边过冲，也就不会要求优化器去追逐超过 100 % 的反射率。

对于透射率曲线，**Fit in（拟合单位）** 可选 % 或 dB。选 dB 时，目标以 dB 保存各点并以 dB 计量拟合，因此 0.1 dB 的偏差在 −20 dB 与 0 dB 处权重相同。适用于以 dB 给出的曲线，例如增益平坦目标。不高于 0 % 的点在 dB 下没有值，会被舍弃；对话框会说明舍弃了多少个。

你还可以在同一步中缩小波长范围、设置这次拟合在整个评价函数中所占的权重，并加入膜层厚度的最小值与最大值约束。**Append（追加）** 把目标加到你已有的评价函数之后；**replace（替换）** 则先清空它。

### 生成的目标

拟合会在[评价函数编辑器](/zh/design/merit-function-editor/)中生成一行，其中自带一份测量数据的副本，因此它随设计一同保存，即使之后曲线被修改或删除也仍然有效。该行只有 **Enabled（启用）** 开关与 **Weight（权重）** 可以编辑：其余部分描述的是一次已经完成的测量，而不是由你选择的目标。它报告的数值是设计与测量之间的均方根差，单位与曲线相同。

如果曲线超出了你的材料具有数据的波长范围，目标会被裁剪到可以计算的范围，并由对话框说明这一点。

无论设计是否仍保有其背后的曲线，光学评估都会绘出这个目标。因此把保存的评价函数载入另一个设计时，你能看到它在拟合什么；如果你希望把这次测量作为可编辑的曲线取回，导入标签页会提供恢复它的按钮。

以 dB 拟合生成的目标在表格中显示为 **MCURVE dB**，以 dB 报告均方根差，恢复时得到的是透射率曲线。

## 导出

**What to export（导出内容）** 选择器用于选择来源：

- **Design spectrum（设计光谱）**：活动设计的*计算* T / R / A。设置波长起点、终点与步长、入射角列表、通道，以及是否拆分 s 与 p（吸收率没有 s/p 之分）。它遵循活动表面模式，且无需打开光学评估即可工作。
- **Measured curves（实测曲线）**：你导入的曲线。勾选要写出的那些。

对任一来源，都可以选择**格式**（CSV 或 JCAMP-DX）、**波长单位**（nm、µm 或 cm⁻¹），以及 Y 写为**分数还是百分比**。

## 如何解读

典型用途是验证一次沉积运行：导入分光光度计轨迹，并与预测曲线比较。两者出现分歧的地方，告诉你制备出的镀膜偏离设计的程度；而拟合则把这一差异转换为真正从镀膜室里出来的那组膜层厚度。
