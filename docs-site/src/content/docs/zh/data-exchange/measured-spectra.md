**实测光谱（Measured Spectra）** 窗口将你的设计与分光光度计连接起来。**导入**一条来自仪器文件的实测反射率、透射率或吸收率曲线，并将其叠加在[光学评估](/zh/analysis/optical-evaluation/)上，以比较预测与测量；**导出**计算得到的设计光谱或你导入的曲线到可移植文件。窗口分为 **Import（导入）** 和 **Export（导出）** 两个标签页。

## 设置

### 导入

支持两类文件：

- **通用 CSV / TXT / ASCII**（`.csv`、`.txt`、`.asc`）：纯 `λ, value` 表格。分隔符（逗号、分号、制表符或空白）、表头行以及小数点为逗号的地区格式都会被自动识别。
- **JCAMP-DX**（`.dx`、`.jdx`）：自描述的 IUPAC 光谱学标准。它自带单位和量，因此可直接导入。复合 `LINK` 文件会导入每一个数据块。

对于通用表格，你在添加前需要确认解析结果：

- **分隔符 / 列**：哪一列是波长，哪一列是数值。
- **X 单位**：nm、µm 或 cm⁻¹（自动检测；若有误可覆盖）。
- **Quantity（量）**：T、R 或 A。
- **Y 比例**：百分比或分数；吸光度会被转换为透射率。
- **预览**：提交前对解析曲线的简要绘图。

导入的曲线存储在设计上，并**随项目一起保存**。在光学评估中，它们显示为带空心圆标记的虚线，按 R / T / A 着色。可在导入标签页中显示、隐藏或移除它们。

### 导出

一个 **"What to export（导出内容）"** 选择器用于选择来源：

- **Design spectrum（设计光谱）**：活动设计的*计算* T / R / A。设置波长起点 / 终点 / 步长、入射角列表、通道（T / R / A）以及 s / p（吸收率没有 s/p 之分）。它遵循活动表面模式（前 / 后 / 总计），且无需打开光学评估即可工作。
- **Measured curves（实测曲线）**：重新导出你导入的叠加层。

一个 **Format（格式）** 开关可将任一来源写为 **CSV** 或 **JCAMP-DX**。

## 如何解读

典型用途是验证一次沉积运行：导入分光光度计轨迹，并在光学评估上直接与预测的设计曲线比较。实测曲线与计算曲线出现分歧的地方，告诉你制备出的镀膜偏离设计的程度。对于不直接支持的仪器，从其自带软件导出 CSV（通用表格导入器可读取普通的 `λ, value` 导出），而 JCAMP-DX 导出则使 TFStudio 曲线可在任何光谱学工具中加载。
