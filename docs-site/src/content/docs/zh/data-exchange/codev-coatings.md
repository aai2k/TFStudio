**CODE V 镀膜** 窗口在 TFStudio 与 CODE V 之间传递镀膜。它读取 CODE V MULTILAYER（`MUL`）镀膜，可以是输入膜层堆栈的 `.seq` 命令文件，也可以是 CODE V 由其保存的 `.mul` 文件；它还把活动设计的一个面写成 `.seq` 文件，CODE V 运行该文件即生成 `.mul`。导入和导出是同一行中的两个标签页。上一次操作的结果显示在这一行的右端，旁边是警告标记：在导入标签页上列出读取文件时的提示，在导出标签页上列出导出时对预览的提示。

## 设置

**打开 .seq 或 .mul**（导入标签页，左侧面板中）：读取镀膜文件。随后面板显示文件中的入射介质和基底、波长、入射角和参考波长。旁边显示文件的标题，以及从入射介质到基底的各层，含以 nm 计的厚度，CODE V 中固定的层（代码 100）带锁形标记。

**导入 → 正面镀膜** 和 **导入 → 背面镀膜**（导入标签页）：文件中的膜层替换活动设计的正面或背面镀膜，设计保留自己的入射介质、出射介质和基底；文件中的 `INC` 和 `SUB` 只显示，不应用。这些膜层所用的材料放入一个以 `CODE V` 加文件名命名的用户目录。未选择设计时没有可导入的对象，这两个按钮不可用，而 **保存到镀膜库…** 仍可使用。

**保存到镀膜库…**（导入标签页）：把该堆栈保存到“我的镀膜”，使用的对话框与[镀膜库](/zh/design/coating-library/)中的 **保存当前镀膜…** 相同。保存的镀膜位于文件的 `INC` 与 `SUB` 之间：n 为 1 且没有 k 的折射率保存为空气，其他折射率或 `MIC` 材料保存为导入时由它生成的材料。其各层与 **导入 → 正面镀膜** 放到设计上的各层相同。波段初始为文件分析波长的范围，文件只有一个波长时为[光学评估](/zh/analysis/optical-evaluation/)所设的波段；入射角初始为其第一个 `ANG`。材料随镀膜一起保存，因此在从未打开该文件的计算机上也能使用，保存也不会向你的材料目录添加任何内容。

**面**（导出标签页）：**正面** 写出设计的入射介质、正面镀膜和基底。**背面** 把出射介质作为入射介质写出，然后是从出射侧到基底的背面镀膜，最后是基底，因为无论元件的哪一面，CODE V 都要求以空气为入射介质、以玻璃为基底。

**标题 (TIT)**：镀膜标题，最多 80 个字符。初始值为设计名称。

**文件名 (SAV)**：`.seq` 最后一条命令写出的 `.mul` 文件名。**保存 .seq** 以同一名称保存 `.seq`。

**REF (nm)**：写入 `REF` 的参考波长。初始值为设计的参考波长。

**分析波长，WL**：以 nm 计的起点、终点和步长，旁边显示波长个数。CODE V 最多接受 100 个，超过时在写出任何内容之前即被拒绝。

**入射角，ANG**：最多五个角度，在入射介质中，每个从 0 起、小于 90 度，可以带小数。超出此范围的输入会恢复为输入框原来的角度。加号按钮添加一个，叉号删除一个。

**生成预览** 构建文件并完整显示；**保存 .seq** 将其写出。若设计中有材料在本机上找不到，则在替换该材料之前无法导出。

## 如何解读

从 `.seq` 文件中，导入读取在 `MDA` 子选项中输入的膜层堆栈：`PHT`、`TIT`、`WL`、`WLG`、`REF`、`ANG`、`INC`、`COA`、`GRO` 与 `END` 组、`SUB` 以及 `MIC` 目录。分析、绘图和优化选项以及文件命令被略过；其他命令会被跳过，并由警告标记列出。CODE V 从一条 `WL`、`MWL` 或 `EXT` 命令或一行 `MIC` 材料中最多读取 21 个值，其余的值被忽略；导入时同样保留前 21 个，并给出警告。`.mul` 文件按 CODE V 保存的内容读取，CODE V 自带的示例镀膜和 CODE V 11.2 保存的文件都可以读取。

以逗号作小数点写数字（`403,03`）的文件导入时会给出警告。导入把两个数字之间的逗号读作小数点，但 CODE V 不读取这样的数字，因此该文件原样无法在 CODE V 中运行。

`WLG` 按 CODE V 的方式以单精度生成波长，因此某个波长可能略微偏离整数值。窗口显示波长和 `REF` 时只保留该精度所含的位数：`WLG 400 800 10` 显示为 400 到 799.9997 nm，文件中没有 `REF` 时参考波长显示为 599.9998 nm。

以波数输入的厚度（`PHT N`）用该层在 `REF` 处的 n 换算为 nm；文件中没有 `REF` 时，按 CODE V 的做法取中间的分析波长。导入的 `MIC` 材料在其 `MWL` 点、分析波长和 `REF` 所覆盖的范围内制表，n 和 k 遵循 CODE V 11.2 对其表的插值，包括 `MWL` 点之间和点以外的值。当以波数输入的层所用的 `MIC` 表不包含 `REF` 时，会有警告指出该材料。

正面镀膜按文件列出的顺序接收各层。背面镀膜接收时，文件的第一层位于出射侧，最后一层贴着基底，与导出背面镀膜时写出的顺序相同。勾选 [**对称（背面 = 正面）**](/zh/design/evaluation-modes/) 时，背面镀膜是正面的镜像，因此只能使用 **导入 → 正面镀膜**。

CODE V 中固定的层（代码 100）导入后为锁定。与其他层耦合的层（代码 1 到 99）以自由层导入，因为 TFStudio 没有耦合层，报告中会给出这类层的数量。

再次导入同一文件时使用它的目录，目录中已有的材料保持原样，包括你做过的编辑。撤销会把镀膜恢复为导入前的样子；目录以及加入其中的材料保留。

CODE V 接受的范围（摘自其帮助的 MUL 章节），以及导出时对每项限制的处理：

| 项目 | CODE V | 导出时 |
| --- | --- | --- |
| 层数 | 最多 1000 | 超过 1000 时拒绝 |
| 分析波长，`WL` | 最多 100 | 超过 100 时拒绝；每条 `WL` 命令最多写 21 个，这是 CODE V 从一条命令读取的上限 |
| 角度，`ANG` | 最多 5 | 输入框最多容纳五个 |
| 每种 `MIC` 材料的点数，`MWL` | 最多 21 | 材料在分析波长上取样；超过 21 个点时，逐个保留 CODE V 自身插值偏离材料最大处的点，直到所有波长在写出的 6 位小数内一致或已满 21 个，并有警告指出该材料 |
| 材料标签 | 6 个字符 | 由材料名称生成，两个标签相同时加数字区分 |
| 入射介质和基底 | 只有 n | 吸收介质的 k 被舍去，并给出警告 |
| 厚度 | 物理厚度 nm（`PHT Y`）或 `REF` 处的波数（`PHT N`） | 物理厚度 nm，`PHT Y` |
| 固定层 | 代码 100 | 锁定的层写为 100，其余写为 0 |

在分析波长范围内 n 和 k 不变的材料，直接以数字写在其 `COA` 行上，而不作为 `MIC` 条目。k 以正数写出。CODE V 从入射介质到基底输入各层，而设计编辑器从基底开始编号，因此设计编辑器中的第 1 层是文件中最后一条 `COA` 行。

文件以 `SAV` 结尾，因此在 CODE V 中运行即写出 `.mul`，由 `MLT` 将其附加到透镜表面。镀膜一旦附加到透镜表面，CODE V 就从透镜取基底折射率，因此 `SUB` 只在 `MUL` 内部起作用。
