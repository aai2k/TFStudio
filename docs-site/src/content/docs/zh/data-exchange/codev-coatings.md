**CODE V 镀膜** 窗口在 TFStudio 与 CODE V 之间传递镀膜。它读取 CODE V MULTILAYER（`MUL`）镀膜，可以是输入膜层堆栈的 `.seq` 命令文件，也可以是 CODE V 由其保存的 `.mul` 文件；它还把活动设计的一个面写成 `.seq` 文件，CODE V 运行该文件即生成 `.mul`。导入和导出位于不同的标签页，上方共用一行状态栏。

## 设置

**打开 .seq 或 .mul**（导入标签页）：读取镀膜文件。从 `.seq` 文件中读取在 `MDA` 子选项中输入的膜层堆栈：`PHT`、`TIT`、`WL`、`WLG`、`REF`、`ANG`、`INC`、`COA`、`GRO` 与 `END` 组、`SUB` 以及 `MIC` 目录。分析、绘图和优化选项以及文件命令被略过；其他命令会被跳过，并在警告中列出。CODE V 从一条 `WL` 命令最多读取 21 个值，其余的值被忽略；导入时同样如此，并给出警告。`.mul` 文件按 CODE V 保存的内容读取。随后标签页显示标题、入射介质、基底、波长、入射角和参考波长，以及从入射介质到基底的各层，含以 nm 计的厚度，CODE V 中固定的层（代码 100）带锁形标记。

**导入 → 正面镀膜**（导入标签页）：用该堆栈替换活动设计的正面镀膜，并把设计的入射介质和基底设为文件中的值。以波数输入的厚度（`PHT N`）用该层在 `REF` 处的 n 换算为 nm；文件中没有 `REF` 时，按 CODE V 的做法取中间的分析波长。文件中的每种材料，无论是 `MIC` 条目，还是写在 `COA`、`INC` 或 `SUB` 行上的折射率，都放入一个以 `CODE V` 加文件名命名的用户目录。再次导入同一文件时使用该目录，其中已有的材料保持原样，包括你做过的编辑。撤销一步即可撤回整个导入。

**面**（导出标签页）：**正面** 写出设计的入射介质、正面镀膜和基底。**背面** 把出射介质作为入射介质写出，然后是从出射侧到基底的背面镀膜，最后是基底，因为无论元件的哪一面，CODE V 都要求以空气为入射介质、以玻璃为基底。

**标题 (TIT)**：镀膜标题，最多 80 个字符。初始值为设计名称。

**文件名 (SAV)**：`.seq` 最后一条命令写出的 `.mul` 文件名。**保存 .seq** 以同一名称保存 `.seq`。

**REF (nm)**：写入 `REF` 的参考波长。初始值为设计的参考波长。

**分析波长，WL**：以 nm 计的起点、终点和步长。旁边显示波长个数。CODE V 最多接受 100 个，超过时在写出任何内容之前即被拒绝。

**入射角，ANG**：最多五个角度，单位为度，在入射介质中。加号按钮添加一个，叉号删除一个。

**生成预览** 构建文件并完整显示；**保存 .seq** 将其写出。若设计中有材料在本机上找不到，则在替换该材料之前无法导出。

## 如何解读

CODE V 接受的范围（摘自其帮助的 MUL 章节），以及导出时对每项限制的处理：

| 项目 | CODE V | 导出时 |
| --- | --- | --- |
| 层数 | 最多 1000 | 超过 1000 时拒绝 |
| 分析波长，`WL` | 最多 100 | 超过 100 时拒绝 |
| 角度，`ANG` | 最多 5 | 输入框最多容纳五个 |
| 每种 `MIC` 材料的点数，`MWL` | 最多 21 | 材料在分析波长上取样；超过 21 个点时减为 21 个，保留 n 和 k 弯曲最大的点，并有警告指出该材料 |
| 材料标签 | 6 个字符 | 由材料名称生成，两个标签相同时加数字区分 |
| 入射介质和基底 | 只有 n | 吸收介质的 k 被舍去，并给出警告 |
| 厚度 | 物理厚度 nm（`PHT Y`）或 `REF` 处的波数（`PHT N`） | 物理厚度 nm，`PHT Y` |
| 固定层 | 代码 100 | 锁定的层写为 100，其余写为 0 |

在分析波长范围内 n 和 k 不变的材料，直接以数字写在其 `COA` 行上，而不作为 `MIC` 条目。k 以正数写出。CODE V 从入射介质到基底输入各层，而设计编辑器从基底开始编号，因此设计编辑器中的第 1 层是文件中最后一条 `COA` 行。

文件以 `SAV` 结尾，因此在 CODE V 中运行即写出 `.mul`，由 `MLT` 将其附加到透镜表面。镀膜一旦附加到透镜表面，CODE V 就从透镜取基底折射率，因此 `SUB` 只在 `MUL` 内部起作用。
