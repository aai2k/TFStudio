报告窗口生成你交付给客户或与设计一起归档的文档：左侧是区块列表，右侧是页面，页面随你编辑设计而更新。每个数字都来自与分析窗口相同的计算，因此报告显示的就是应用显示的内容。它从功能区**生产**选项卡上的**报告**打开。

## 计算的量

一份报告是一个有序的区块列表，每个区块是一张表格，可附带一张图。

- 每份报告都有：标题、带膜系示意图的设计概况、膜层表、材料和备注。模板可以关闭它们，但不能移除。
- 来自分析窗口：光谱、颜色、积分值、群延迟（含 GDD 与 TOD）、椭偏、电场、折射率分布、技术规格判定、评价函数操作数和签署栏。
- **蒙特卡洛**打印[蒙特卡洛](/zh/analysis/error-analysis/)窗口为该设计所做的最近一次计算，包括其曲线、逐波长统计和合格率；它不会重新计算。
- **监控工作表**打印[监控工作表](/zh/simulation/monitor-worksheet/)的监控片表格，每层一行，采用该窗口为该设计设定的监控片计划、波长、监控片玻璃和设置。

膜层表列出编号、材料、厚度和 QWOT，两面都以紧贴基底的一层为第 1 层。长膜系会分成并排的几栏，一页约可容纳 150 层。

## 控件与设置

列表底部的**添加区块**添加一个区块，采用其来源窗口当前显示的设置；若该窗口尚未打开，则采用其保存的默认值。勾选区块即包含它，拖动可排序；其齿轮设定范围与步长、角度、曲线、图的尺寸以及表格对曲线的采样间隔，也可移动或移除区块。光谱区块带有光学评价自身的控件：角度标签、带 s 和 p 的曲线、光谱单位，以及纵轴刻度（百分比、0-1、dB 或光密度）及其范围。

膜层表：**n、OT、FWOT 列**加入光学厚度一族，以栏数换取宽度。**合并相同周期**把重复的周期（例如 (H L) × 24）合为一行；只有在打印精度下相同的行才会合并，因此精炼后的膜系会逐层打印。

**模板**：默认的**设计记录**，包含配方在内的全部内容；**客户报告**，规格在前，无配方，带签署栏；以及**对比**。**另存为模板**保存你自己的区块列表。

**文件信息**：每份报告都会改变的字段，即标题、客户、文件编号、版本、日期和设计者。**品牌**：不变的内容，即公司、强调色、页脚文字、默认设计者和标志，保存一次即用于所有报告。模板和品牌配置保存在你的 TFStudio 数据文件夹中。

**设计**：选择多个设计时报告变为对比。各设计以 A、B、C 标记，其全名列在报头下方的图例中，因此长名称不会撑宽表格列。概况、判定、积分值和颜色合成一张表，每个设计一列，每表最多六个设计；光谱区块把所有设计画在一张图上，配方并排排列。没有对比形式的区块对每个设计各出现一次。没有打开设计时，报告只包含所选的设计。

**导出**，位于右下角：带页眉、页脚和页码的 PDF；一个自包含的 HTML 文件；或把每张表格复制为制表符分隔的文本，用于电子表格。纸张尺寸（A4 或 Letter）和文档语言与应用的设置分开，默认值位于首选项、分析、报告。
