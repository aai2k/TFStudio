**报告生成器（Report Generator）** 生成一份生产级质量的文档，汇集你所选择的分析内容，这正是镀膜工程师交付给客户或归入设计包的那类成果。输出是一个自包含的 **HTML 或 PDF** 文件，提供 **English（英语）或 Russian（俄语）** 版本，并且它复用与分析窗口相同的经过验证的计算引擎，因此报告中的每个数字都与你在应用中看到的一致。

从信息功能区组的 **Report（报告）** 按钮，或 **File → Export Report（文件 → 导出报告）** 打开它。它以 6 步向导形式运行。

## 设置

**第 1 步：范围（Scope）。** 针对当前设计生成报告，或将多个设计作为**对比（comparison）** 报告生成。此步还包含封面字段：标题、客户、项目、设计者、日期，以及可选的徽标。

**第 2 步：章节（Sections）。** 勾选要包含的章节，并用 ▲ / ▼ 按钮重新排序。可用章节包括封面、设计摘要（层表格与合计）、光学评估、颜色、折射率剖面、|E|² 场剖面、椭偏（Ψ/Δ）、积分值、合格判定、评价操作数，以及自由文本备注。

**第 3 步：选项（Options）。** 逐章节设置：波长和入射角范围、要包含哪些曲线（T / R / A）和数据表格、颜色光源、可选的 `n / OT / QWOT / FWOT` 层列，以及制表形式的材料 n,k。无需选项的章节在此跳过。

**第 4 步：语言（Language）。** 以英语或俄语生成报告；这会设置所有标题、坐标轴标签和表头。

**第 5 步：输出（Output）。** 选择单个自包含的 **HTML** 文件或打印质量的 **PDF**。此步还管理 **presets（预设）**：将当前报告配置以名称保存，稍后重新加载。

**第 6 步：预览与生成（Preview & Generate）。** 已完成报告的实时预览；按生成按钮将其导出。

图表以内联矢量图形绘制，因此报告在预览、保存的 HTML 和 PDF 中看起来完全一致。预设和可选的封面徽标存储在你的 `Documents\TFStudio` 文件夹中。

## 如何解读

生成的报告是交付成果，而非分析工具，因此要像你的客户那样去阅读它。当你希望用一份文档将多个候选设计并排呈现时，使用对比范围。由于报告中的数字直接取自与[光学评估](/zh/analysis/optical-evaluation/)、[颜色评估](/zh/analysis/color-evaluation/)和[积分值](/zh/analysis/integral-values/)窗口相同的引擎，这些值正是那些窗口所显示的值；如果看起来有异常，请检查逐章节选项（波长范围、角度、光源），而不是期望报告与应用有所不同。
