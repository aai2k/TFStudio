**报告（Report）** 窗口生成你交付给客户或与设计一起归档的文档。它与分析窗口一样是停靠窗口：左侧是区块列表，右侧是页面，页面随你编辑设计而实时更新。每个数字都来自与分析窗口相同的计算引擎，因此报告显示的就是应用显示的内容。

从 **Production（生产）** 功能区选项卡的 **Report（报告）** 按钮打开它。

## 区块

一份报告是一个有序的区块列表。每个区块首先是一张表格，可选附带一张图。每份新报告都包含五个区块：标题、带膜系示意图的设计概况、膜层表、材料和备注。模板可以关闭它们，但不能移除它们。

其他区块来自分析窗口：光谱、颜色、积分值、群延迟（含 GDD 与 TOD）、椭偏、电场和折射率分布，以及技术规格判定、评价函数操作数和签署栏。通过侧栏底部的 **添加区块** 添加。新区块复制其来源窗口当前显示的设置；若该窗口尚未打开，则复制其已保存的默认值。这样在光学评价中设置过一次的波长范围就不必再输入一遍。

另有两个面向生产的区块。**蒙特卡洛** 打印蒙特卡洛窗口为该设计所做的最近一次计算：设计曲线、试验均值、走廊带、逐波长统计以及技术规格合格率。它不会重新计算；要刷新，请在该窗口重新运行。**监控工作表** 打印监控工作表窗口的监控片表格：每个镀膜层一行，显示窗口中的全部列。监控片计划、波长、监控片玻璃和监控仪设置取自该设计的监控工作表窗口；在那里修改，报告随之更新。

勾选区块以包含它，拖动以排序，打开齿轮可修改其设置：范围与步长、角度、曲线、图的尺寸，以及表格对曲线的采样间隔。光谱区块使用光学评价窗口自身的控件：角度标签、带 s 和 p 分量的曲线开关、光谱单位，以及纵轴刻度（百分比、0-1、dB 或光密度）及其范围。齿轮还可以移动或移除区块。

## 膜层表

膜层表列出序号、材料、厚度和 QWOT。第 1 层紧贴基底，两面均如此，并在表格下方注明。较长的膜系会分成并排的多栏，因此约 150 层可以放在一页内。开启 **n、OT、FWOT 列** 可显示完整的光学厚度族，但会以宽度换取栏数。**合并相同周期** 把重复的周期（例如 (H L) × 24）合并为一行。只有在打印精度下完全相同的行才会合并，因此经过优化、厚度在末位有差异的膜系会逐层打印。

## 模板、文件信息与品牌

**模板** 列表包含三个：设计记录（默认，包含配方在内的全部内容）；客户报告（技术规格在前，不含配方，带签署栏）；对比。用 **另存为模板** 保存你自己的区块列表。

**文件信息** 保存每份报告都会变化的字段：标题、客户、文件编号、版本、日期和设计者。**品牌** 保存不变的内容：公司行、强调色、页脚文字、默认设计者和标志。保存一次配置，所有报告通用。

## 多个设计

在 **设计** 下选择多个设计，报告就变为对比。各设计以 A、B、C 编号，并在报告头下方的图例中列出全名；表格、图例和配方标题都用字母指代，因此过长的名称不会撑宽表格列。概况、判定、积分值和颜色以每个设计一列的表格呈现，每张表最多六个设计；光谱区块把所有设计画在同一张图上，配方并排放置。没有对比形式的区块按设计逐个呈现。

## 导出

右下角的导出菜单可保存带页眉、页脚和页码的 PDF，保存单个自包含的 HTML 文件，或把所有表格复制为制表符分隔的文本以粘贴到电子表格。纸张为 A4 或 Letter，文档语言与应用语言独立选择。两者的默认值可在“设置 → 分析 → 报告”中设置。

已保存的模板和品牌配置均位于你的 TFStudio 数据文件夹中。
