---

**多环境优化**让一个膜系设计可以同时满足多个介质环境的目标——例如同一个膜系在产品一侧暴露于空气、另一侧嵌入光学胶，或者同一镀膜既要在真空环境中使用、也要在浸没液体中工作。与其分别对每个环境优化、再指望结果彼此吻合，不如一次性定义好所有环境，让 TFStudio 用**同一套膜层**在一次运行中同时满足全部环境的要求。

整个功能建立在三个概念之上：

- **环境（Environments）**——每个环境是一组介质（入射介质、出射介质、基底），膜系在这些介质中被评估。
- **每个环境独立的评价函数**——每个环境可以拥有自己的操作数（目标）集，类似 Zemax 的多重结构（configuration），也可以共用设计级操作数。
- **权重（Weights）**——每个环境一个权重，决定它在组合评价函数中的分量。

---

## 启用多环境模式

打开[评价函数编辑器](/zh/design/merit-function-editor/)，窗口顶部有一个 **Multi-environment（多环境）** 复选框，带 ON / OFF 状态徽标。

- **打开**时会根据设计当前的介质自动创建第一个环境（E1）——即[设计编辑器](/zh/design/design-editor/)里已经设置的入射介质、出射介质和基底。
- **关闭**时清空环境列表，设计恢复为普通的单环境行为。共享操作数不会受影响。

启用后，操作数表下方会出现一个 **环境（Environments）** 面板，每一行代表一个环境：

| 字段 | 含义 |
| ----- | ------- |
| **入射介质** | 光从哪种介质入射（如 `Air`、`cement`）。 |
| **出射介质** | 光从哪种介质出射。 |
| **基底** | 该环境使用的基底材料。 |
| **权重** | 该环境在组合评价函数中的分量（默认 1.0，详见下文[优化器如何处理多环境](#优化器如何处理多环境)）。 |
| **MF** | 该环境当前的评价函数值，编辑时实时重算。 |

用 **+ 添加** 追加环境，用 × 按钮删除。环境在程序的其余地方统一编号为 E1、E2、……

> 留空的介质字段会回退到设计级介质，所以只需要填写各环境之间真正不同的部分。

## 每个环境独立的评价函数

默认情况下，每个环境都用**共享的设计级操作数**来评分——也就是你在编辑器里看到的那些操作数。这通常正是你想要的：同样的目标，在各环境的介质下分别求值。

但有时某个环境需要自己的目标——不同的波段、不同的容差、额外的约束。它的用法与 Zemax 多重结构类似：

- 没有自己操作数的环境会显示 **使用设计级评价函数** 标签。点击 **自定义** 可以为它创建一份独立操作数集，初始内容复制自共享操作数；此后它就是一列可自由编辑的独立清单。
- 点击 **编辑** 进入该环境的操作数表。顶部有面包屑导航标明当前位置：`设计 > E1: air → cement`。点击 **返回** 回到设计级操作数。

该环境的 MF 值（显示在行内）在其拥有自己的操作数时总是用自己的操作数计算，否则用共享操作数。

## 优化器如何处理多环境

所有优化工具——SQP、DLS、共轭梯度（CG）、牛顿（Newton）、牛顿-共轭梯度（Newton-CG）、差分进化（DE）、模拟退火（SA）、*全部尝试保留最佳*，以及合成工具（[针式优化](/zh/synthesis/needle/)、[渐进演化](/zh/synthesis/gradual-evolution/)、[结构优化器](/zh/synthesis/structural-optimizer/)）——最小化的都是**同一个由所有环境组合而成的评价函数**。并不存在单独的"多环境方法"：多环境是评价函数本身的属性，因此每一种方法都会自动继承这一能力。

组合方式是对**各环境残差做加权汇总**：每个环境的操作数在其自身的介质下求值，残差平方和先乘以该环境的权重，再合并为一个总体评价值。只有单个环境时，它退化为与普通评价函数完全一致。

**权重决定优先级。** 权重为 2 的环境相当于权重为 1 的环境的两倍分量，优化资源会流向更重要的环境。建议先把所有权重设为 1.0，运行一次，查看[精炼](/zh/synthesis/refinement/)窗口中的分环境评价函数明细（见下文[按环境导出与监控](#按环境导出与监控)），再为落后于目标的环境调高权重。

> 当没有环境定义自己的操作数时，组合评价值与单环境评价函数数值完全相同。也就是说，只打开开关而不做任何其他改动，不会改变任何结果——只有当真正添加第二个环境后，多环境的价值才会显现。

## 在光学评价中对比环境

只要设计带有环境，[光学评价](/zh/analysis/optical-evaluation/)窗口的工具栏就会出现一个 **Environment（环境）** 下拉框，其中包含：

- **设计级（全部）**——使用设计级介质（即该功能出现之前你所看到的光谱）。
- **E1、E2、……**——每个环境一项，以介质命名，例如 `E1: air → cement`。

选择某个环境后，曲线图立即切换到该环境的光谱。选择会按设计记忆保存——回到某个设计时，窗口会重新打开在最后一次查看的环境上。

---

## 锁定窗口进行并排对比

环境下拉框旁边是 **锁定视图** 按钮，专为对比同一设计的两种状态而设计：

1. 先选好想保留在屏幕上的环境（或设计状态）。
2. 点击 **锁定视图**。该窗口随即*冻结*当前视图——此后切换下拉框对已锁定的窗口不再生效。
3. 从功能区再打开一个**第二个**光学评价窗口。
4. 在第二个窗口里选择另一个环境——或者运行一次优化，让第二个窗口显示更新后的设计，而第一个窗口保持旧设计不动。

由于被锁定的窗口不再跟随你的选择，你就能得到稳定的前后对照：优化后 vs. 优化前，或环境 A vs. 环境 B。点击 **解锁视图** 让窗口重新跟随下拉框。

下面的工具在计算时会解析每个环境的介质（入射 / 出射 / 基底），因此其结果会自动反映多环境设置：

## 按环境导出与监控

**光谱导出。** 光学评价窗口中的复制 / 保存 CSV 操作导出的正是当前屏幕上的光谱——因此当选中某个环境（或将窗口锁定到某个环境）时，导出的就是该环境的光谱。

**报告与工艺文件。** 报告与导出的模型层（[报告生成器](/zh/data-exchange/report-generator/)、工艺导出）会解析所请求环境的介质，因此可以从同一设计生成按环境区分的数据。

**精炼窗口的分环境明细。** 多环境模式下，[精炼](/zh/synthesis/refinement/)窗口会显示一条 **Env MF** 信息栏：每个环境当前设计状态下的评价函数值，旁边并排显示保存的优化前初值，例如 `E1 MF: 0.42（初值 0.91）`。一眼就能看出是哪个环境拖了后腿——就是 MF 始终居高不下的那一个。

## 一个完整的例子

假设某镀膜既要在空气中使用，也要嵌入光学胶中使用：

1. 在评价函数编辑器中启用 **Multi-environment（多环境）**。
2. **+ 添加** 环境 E2，把它的入射 / 出射介质设为光学胶。
3. 如果 E2 需要自己的目标，点击 **自定义**；否则保留共享操作数即可。
4. 运行[精炼](/zh/synthesis/refinement/)——组合评价函数现在同时覆盖两个环境。
5. 在光学评价中，把一个窗口**锁定**在 E1，打开第二个窗口显示 E2，确认两条光谱都达到目标。
6. 观察 **Env MF** 信息栏：如果 E2 的数值居高不下，就调高它的权重再精炼一次。

任何一组环境都适用同样的套路：定义环境 → 设置权重 → 优化 → 对比 → 导出。关于评价函数本身的更多内容，请参阅[评价函数编辑器](/zh/design/merit-function-editor/)与[优化方法](/zh/synthesis/optimization-methods/)页面。
