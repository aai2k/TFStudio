**精炼**用你选择的方法移动各层厚度，使评价函数降低。它从不增删层。移动哪些层由 [设计编辑器](/zh/design/design-editor/) 中设置的表面模式决定，窗口上的 **优化** 和 **评价** 徽章会显示出来；锁定的层保持不动。每种方法如何迈步，以及每种方法的图示，见 [优化方法](/zh/synthesis/optimization-methods/)。

## 计算量

- **MF**：屏幕上设计的评价函数；**最佳**，本次运行至今的最低值；**初始**，运行开始时的评价函数。**MF 趋势**条在对数轴上画出最佳评价函数随迭代的变化。
- **迭代**：本次运行的迭代数；“全部尝试”时为各方法迭代数之和。
- 运行结束时的标签：**已到达目标**、**已达最大迭代**、**无进一步改善**，或在“全部尝试”之后显示 **最佳：** 和效果最好的方法。DLS 多起点结束时不显示标签。

## 控件与设置

**运行 (F5)** 和 **停止**。**最佳** 把本次运行评价函数最低的设计放到设计上，停止之后也可以。**重置** 回到运行之前的厚度，一次撤销即可撤回整个运行。

**方法**：序列二次规划（默认）、阻尼最小二乘法、共轭梯度法、牛顿法、牛顿-CG 法、信赖域牛顿法、DLS 多起点、差分进化、模拟退火，或“全部尝试：保留最佳”。你的选择在不同设计之间保留。

**最大迭代**：单一方法运行最多的迭代数；初始值为该方法自身的预算，方法自身的判据满足时运行仍会提前结束。“全部尝试”时此项隐藏，每种方法使用各自的预算。

**重启次数** 和 **扰动 ±%**：用于 DLS 多起点和“全部尝试”，即扰动起点的个数和每个厚度被打散的幅度，默认为 20 和 30 %。

**随机种子**：用于差分进化、模拟退火、DLS 多起点和“全部尝试”。留空时，**运行** 会抽取一个种子并留在框中，因此相同的种子、设计和设置会再次得到相同的运行；清空该框即可重新抽取。

**自动更新**：开启时，其他已打开的窗口在运行期间跟随设计；关闭时，它们保持运行开始时的设计，运行停止后再更新。

**设计历史**：本次运行完成的每种方法占一行，每次按下运行有一个标题，最新的在最上方，同一次运行内按评价函数从低到高排列。随机方法的行会显示其种子。**绘图** 显示该行的 MF 趋势，**恢复** 把它的厚度放到设计上。

窗口中间的表格就是评价函数，与 [评价函数编辑器](/zh/design/merit-function-editor/) 中的行相同，也可以在这里编辑。每个设计保留自己最近一次的运行：切换设计时显示该设计的读数和趋势，**最佳** 应用的也是该设计的结果。

## 运行过程

按下 **运行** 时，每个波段行获得设计的条纹间距所需的采样波长数，波段中藏有窄特征的地方还会加密（见 [操作数参考](/zh/design/operands/#sampling-a-band)）。没有启用的行，或有行无法计算时，运行不会开始。随后最小化：

```
MF = √( Σ_i  w_i · (m_i / σ_i)²  /  W )        m_i：第 i 行与目标的差，w_i 其权重，σ_i 其尺度，W = Σ w_i

d_k ≥ 1 nm         所有方法；没有 MXT 行时无上限
MNT, MXT           SQP 中为硬限制，其他方法中为罚函数行

已到达目标             MF < 10⁻⁶
已达最大迭代           最大迭代使方法停止
无进一步改善           方法按自身的判据停止（见优化方法）
```

“全部尝试”依次运行共轭梯度法、阻尼最小二乘法、牛顿法、牛顿-CG 法、序列二次规划、信赖域牛顿法、差分进化、模拟退火和 DLS 多起点，每种都从同一起点出发，而不是从上一种的结果出发，并保留 MF 最低者。DLS 多起点同时运行多个重启，每个线程一个；有四个或更多可变层时，差分进化在多个线程上为每一代打分。两者都不改变结果。

针法自动不使用 `MNT` 和 `MXT` 行，因此之后运行一次精炼即可把它们带回来。
