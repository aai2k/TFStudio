**精炼（Refinement）** 通过移动你的层厚度来最小化评价函数。它绝不增删层；只有厚度发生变化。这是日常的主力工具：快速、稳健，也是任何合成运行或手动编辑之后自然的收尾步骤。

它最小化你在 [评价函数编辑器](/zh/design/merit-function-editor/) 中定义的操作数集合，使用你从下拉菜单中选择的方法。默认是 **SQP**，它将最小厚度视为硬限制，但你可以切换到其他几种局部和全局方法。移动的变量遵循 [设计编辑器](/zh/design/design-editor/) 中设置的表面模式（正面、背面、两侧或对称），并且每种方法在每种模式下都可用。

关于每种方法的说明以及何时选用的指导，请见 **[优化方法](/zh/synthesis/optimization-methods/)**。

## 设置

**方法**：要运行的优化器：SQP、阻尼最小二乘、共轭梯度、牛顿、牛顿-共轭梯度、DLS 多起点、差分进化、模拟退火，或**全部尝试，保留最佳**。你的选择会在不同设计间被记住。

**最大迭代次数（Max iter）**：优化器最多可采取的步数。当收敛时运行仍会提前停止，因此这只是一个上限。它默认为所选方法的一个合理预算。

**重启次数（N）**：仅用于 DLS 多起点：在保留最佳结果之前运行多少个随机扰动的起点（通常为 4–8，或在崎岖曲面上更多）。

**扰动（Perturbation）**：仅用于 DLS 多起点：每次重启开始时，对每层厚度抖动的幅度（以百分比计）。

表面模式和评价函数评估模式以徽章形式显示在窗口上。

## 如何解读

运行期间，你会看到光谱实时更新，以及一个运行的评价函数读数（当前值、迄今最佳值、起始值）。**评价函数趋势（MF trend）** 图在双对数轴上将找到的最佳评价函数对迭代次数作图。一条稳定下降并趋于平缓的曲线意味着方法已稳定在一个极小值中。

**重置（Reset）** 会回到运行前的厚度，单次撤销即可覆盖整个运行。**历史（History）** 面板保留每次运行的快照，以便你可以跳回任何更早的结果。

单次起点运行（N = 1）通常足以重新稳定一个手动编辑过的堆栈。在合成之后，多起点运行有助于确认你已到达真正的局部极小值，而非一个“有改进但未到底”的点。最小和最大厚度限制在此处被遵守（它们在针式和渐进演化合成期间被刻意放宽）。
