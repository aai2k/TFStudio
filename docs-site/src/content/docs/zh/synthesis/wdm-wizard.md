**滤光片设计（Filter Design）** 向导用六个步骤，由少量物理参数构建一个多腔带通滤光片（DWDM、LWDM 或窄陷波），并返回一个已填好评价函数行、可直接用于[精炼](/zh/synthesis/refinement/)的设计。它构建的膜系是由四分之一波反射镜块和法布里-珀罗间隔腔交替组成的：

```
Substrate | M₁ S₁ M₂ S₂ … Mq Sq M(q+1) | (optional AR)
```

每个 Mᵢ 是一个四分之一波反射镜块，每个 Sᵢ 是 k 个半波的间隔层。从基底数起，整个膜系 H 和 L 交替，因此层数为偶数的反射镜会结束在另一种材料上，使它两侧的间隔层材料不同。两个外侧反射镜比内侧的弱，内侧反射镜把相邻的腔耦合起来：正是这一点使通带顶部变平。

第 2 到第 5 步按**嵌入**情况设计滤光片，即假设入射介质的折射率与基底相同，这样前表面不反射；第 6 步才引入真实的介质。精炼之前，一个对称的 N 腔原型会显示 N 个跨在 λ₀ 两侧的小波纹：这是预期的切比雪夫响应，精炼会把它们合并为一个平顶。

## 计算量

- **形状因子**：阻带半宽与通带半宽之比。
- **腔数量**：由形状因子和两个水平求出的切比雪夫数 q；向导推荐大于 q 的腔数，并给出 q + 1。
- **原型规格**中的各行 (m, k)：一个反射镜强度 m，配上能给出所要求通带宽度的最小间隔层阶次 k，反射镜最强的在前。
- **全局整数搜索**的候选：搜索找到的设计，按评价函数排列，原型本身标为**种子**。

## 控件与设置

**材料选择**：高折射率（H）和低折射率（L）镀膜材料、基底和入射介质；**斜入射**可设定工作**角度**和**偏振**。设计波长处 k 超过 10⁻⁵ 时向导会警告，因为高 Q 腔中的损耗会降低峰值透射率。向导会记住这些选择供下次使用。

**滤光片参数**：**滤光片波长** λ₀、在**通带水平**（默认 89.13 %，0.5 dB）处的通带半宽，以及在**截止水平**（0.1 %，30 dB）处的阻带半宽。

**腔数量**：要构建的腔数；给出的值可以修改。

**原型规格**：选择作为起点的行；**间隔层材料**显示间隔层为 H、L 或**任意**的行。

**全局整数搜索**：**开始**在所选原型附近搜索反射镜的整数层数和间隔层阶次，寻找最低的评价函数；**重启次数**设定加入多少个扰动后的起点，默认 14。选中要构建的候选。

**对称反射镜**和**对称腔**：让膜系的两半保持相同。

**通带保持 ±θ 范围**：在比工作角度再倾斜 θ 的条件下对每个设计再评分一次，因此随角度彼此失谐的腔会被淘汰。

**启动时清除历史**：默认勾选；不勾选时，之前运行的候选会留在列表中。

**调整到入射介质**：在入射介质和滤光片之间选择**无减反镀膜**、**1 层镀膜**或**2 层"V"型镀膜**，并为设计命名。

**完成**生成一个新设计，带有该膜系，并在[评价函数编辑器](/zh/design/merit-function-editor/)中写入以下各行：在工作角度和偏振下，整个通带上透射率 100 %、每个阻带上 0 %，以及覆盖所有膜层的 `MNT` 7 nm 和 `MXT` 9999 nm。它的参考波长就是铺设其四分之一波所用的波长。

## 计算方法

### 腔数

```
ρ = 1/T_p − 1                         T_p、T_s：以小数表示的通带水平和截止水平
q = 使  T_q(SF) > √( (1/T_s − 1) / ρ )  成立的最小整数
T_0 = 1,  T_1 = SF,  T_j = 2·SF·T_(j−1) − T_(j−2)
```

T_q 是 q 阶切比雪夫多项式，SF 是形状因子。在默认水平下阈值约为 100，SF = 3 时 q = 3，因此向导给出四个腔。

### 原型

```
δ = round( ln(n_s / n_H) / ln(n_L / n_H) )
反射镜：   外侧 m 个四分之一波，内侧 2m + 2δ − 1 个，间隔层 2k 个四分之一波
Δλ/λ₀ = (4/π) · (n_L/n_H)^(m+δ) · (n_H − n_L) / ( k·(n_H − n_L) + n_L )
k = 使  Δλ/λ₀ ≤ 0.98 · r_q · 2Δλ_p / λ₀  成立的最小阶次，   r_q = cosh( acosh(√(1/ρ)) / q )
```

δ 是 Thelen 的耦合阶次，即让内侧反射镜与基底匹配所需的额外反射镜强度（对大多数材料组合为 1）。宽度公式是 Thelen 给出的多腔滤光片通带宽度（Macleod 式 8.59-8.61），r_q 把在通带水平处要求的宽度换算为 q 腔切比雪夫响应的半功率宽度；0.98 是一个拟合系数，使表格瞄准比要求略窄的宽度，因为搜索会把通带拓宽。表中各行从 m = 1 到第一个在 k = 1 时就达到该宽度的 m，并限制在搜索能处理的范围内，即反射镜层数 1 到 41、阶次 1 到 400。

### 搜索的评价函数

```
通带点：  17 个，均匀分布在 λ₀ ± Δλ_p 上；目标 100 %，最外两个为通带水平；σ = 1
阻带点：  λ₀ ± {1, 1.1, 1.2, 2}·Δλ_s；目标 0 %；σ = 0.2
残差：    通带  min(0, T − target)，  阻带  max(0, T)        （T 以 % 计）
MF = √( Σ (残差 / σ)² / N_points )
```

每个点都是单侧的：通带点只在 T 低于它时计入，阻带点只在 T 高于零时计入，因此设计可以在带边用掉通带水平所允许的余量。阻带点的权重是通带点的五倍，使截止边能与平顶相抗衡。在某个角度下，无论整数取什么，通带都会移向短波，因此先找到通带中心，再把各点移到它上面；评分的是通带的形状。开启**通带保持 ±θ 范围**时，在工作角度加 θ 的条件下再对同样的点评分一次，MF 是两组点的均方根。嵌入时，入射角换算为基底中的角度，n_inc sin θ_inc = n_s sin θ_s。

### 整数搜索

```
移动：     每个反射镜 ±1、±2；每个间隔层 ±1、±2；
           间隔层 i 变化 ±1 或 ±2，同时反射镜 i 和 i+1 反向变化 1 或 2；
           所有间隔层 ±1，同时所有内侧反射镜反向变化 1
下降：     保留每一个降低 MF 的移动；一整轮都没有降低时停止
重启：     反射镜 + round(6·(u − 0.5))，外侧反射镜再减 2；间隔层 + round(2·(u − 0.5))
```

u 在 [0, 1) 上均匀分布。之所以有成对的移动，是因为一个腔的宽度正比于反射镜项 (n_L/n_H)^2x 除以其阶次（Macleod 式 8.24-8.25）：单独提高间隔层阶次会使该腔变窄，几乎从任何起点出发都是上坡；而配合减弱反射镜的同一步能保持宽度，从而到达更高阶的设计。原型行始终保留在列表中，因此即使有波纹的设计评分更低，干净的原型仍然可选。

### 调整到入射介质

```
r_1 = (η_0 − η_1)/(η_0 + η_1),   r_2 = (η_1 − η_2)/(η_1 + η_2),   r_3 = (η_2 − Y)/(η_2 + Y)
Re( r_3 · e^(−2iδ_2) ) = [ r_2² + |r_3|² − r_1² − r_1² r_2² |r_3|² ] / [ 2 r_2 (r_1² − 1) ]
e^(−2iδ_1) = −r_1 (1 + r_2 r_3 e^(−2iδ_2)) / (r_2 + r_3 e^(−2iδ_2))
```

Y 是嵌入滤光片在 λ₀ 处呈现的导纳，η_0 是入射介质的导纳，η_1 和 η_2 是两层镀膜的导纳，都按工作角度和偏振取倾斜导纳（s 偏振 η = n cos θ，p 偏振 η = n / cos θ）。第一行方程在两侧各有一个根，对 H、L 的两种顺序各给出两个 V 型镀膜解。保留的镀膜是能使 λ₀ 处反射率低于 10⁻⁶ 的最薄者，否则取剩余反射率最小者；偏振取平均时，两个平面的根都按平均反射率评分。1 层镀膜取剩余反射率最小的相位厚度。当镀膜的内层与滤光片外层材料相同时，两者合并为一层。

在斜的工作角度下，通带位于铺设四分之一波所用的波长之下，因此向导把它们铺在一个更长的参考波长 λ_ref 上：测出加了镀膜的滤光片的通带落在哪里后，把参考波长乘以 λ₀ / λ_centre，做两次，并保留通带最接近 λ₀ 的那个参考波长。
