**滤光片设计（Filter Design）** 向导通过少量物理参数构建一个多腔带通原型滤光片（DWDM、LWDM 或窄陷波）。它引导你选择材料和目标形状，建议腔数与匹配的 prototype，并返回一个已填好评价函数操作数、可直接精炼的设计。

它生成的结构是一个由四分之一波高反镜块分隔以法布里-珀罗（Fabry-Perot）间隔腔的对称堆栈：

```
Substrate | M₁ S₁ M₂ S₂ … Mq Sq M(q+1) | (optional AR)
```

每个 Mᵢ 是一个四分之一波高反镜块，每个 Sᵢ 是一个半波间隔腔。外侧和内侧镜块使用略有不同的层数，以使任一间隔腔边界都不会塌缩成一个惰性的全波层。

## 步骤

该向导分六步运行：

1. **材料**：选择高折射率（H）和低折射率（L）镀膜材料，以及可选的基底、入射介质和斜入射角。两种材料在设计波长处都应基本无损耗（若吸收显著，向导会发出警告），因为高 Q 腔中的损耗会严重降低峰值透射率。

2. **参数**：设置中心波长 λ₀、通带半宽和阻带半宽。形状因子（两者之比）在你输入时实时显示，同时显示理想目标预览。

3. **腔数**：向导根据你的形状因子推荐一个腔数；你可以覆盖它。

4. **原型**：从一张候选原型表中选择，每个原型以其镜块和间隔腔阶数以及估计带宽标注，并挑选最接近你目标的行。

5. **精炼候选**：一个简短的整数搜索确定所选原型的层排布。

6. **增透**：设计从简化的嵌入式情况转移到真实的入射介质，添加一个增透膜，使成品滤光片在空气中也能正常工作。

## 如何解读

预览图在 λ₀ 周围精细采样的波长网格上绘制透射率，以便窄通带清晰呈现。精炼之前，一个对称的 N 腔原型会显示 N 个跨在 λ₀ 两侧的小波纹。这是预期的切比雪夫式（Chebyshev-style）响应，而非缺陷；精炼会将它们合并为一个平顶。

当你确认时，一个新设计会被提交，带有计算出的堆栈，并且评价函数操作数已在 [评价函数编辑器](/zh/design/merit-function-editor/) 中预填：通带中的平均透射率目标和阻带中的平均反射率目标。接下来运行 [精炼](/zh/synthesis/refinement/) 以完成设计。
