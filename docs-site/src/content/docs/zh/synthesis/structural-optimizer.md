**结构优化器（Structural Optimizer）** 搜索的是设计的*结构*，而不仅仅是其厚度。每一步它都会随机变异层堆栈：通过**增、删、拆、合**或**扰**一个层，对结果重新精炼，并使用模拟退火规则决定是否保留它。因为它能改变层的数量与排布，它可以达到固定结构的 [精炼](/zh/synthesis/refinement/) 乃至基于插入的 [针式](/zh/synthesis/needle/) 和 [渐进演化](/zh/synthesis/gradual-evolution/) 工具都无法达到的设计。

每一代，它会对当前设计提出若干改动，对每一个进行精炼，并取这批中最佳的一个。其中最多一半是 [针式](/zh/synthesis/needle/) 扫描评为最有用的插入，其余是已启用种类的随机变异。精炼后回到当前设计的候选会被排除，因此每一代都检验一个真正的改动。一个更差的设计仍可能被接受，其概率由温度决定，而温度随运行推进逐渐降低；正是这一点让搜索能够爬出局部极小值。实时设计始终跟踪所找到的最佳结果，因此停止、重置或切换标签页时，你始终停留在最佳设计上。波段目标采样所用的波长网格按设计确定大小，并在运行过程中随设计一起增长（见 [操作数参考](/zh/design/operands/#光学带平均单目标)）。

| 变异 | 效果 |
| -------- | ------ |
| **增（Add）**     | 在随机位置插入一个新层（材料来自材料池）。 |
| **删（Remove）**  | 删除一个层。 |
| **拆（Split）**   | 将一个层切成两个。 |
| **合（Merge）**   | 合并相邻层。 |
| **扰（Perturb）** | 抖动一个层的厚度。 |

被锁定的层永远不会被触碰，厚度边界始终被遵守。

## 设置

**候选池**：*增* 和 *拆* 算子可以使用的材料（**全部（All）/ 清空（Clear）**）。

**变异种类**：允许搜索使用的算子开关。

**最大迭代次数（Max iter）**：要运行的最多代数。

**目标评价函数（Target MF）**：一旦评价函数达到该值即停止。

**T₀（温度）**：起始退火温度。较高的值在初期接受更多上坡移动，从而拓宽搜索。

**抖动（Jitter）**：*扰* 算子的厚度扰动尺度。

**精炼迭代次数**：对每个提出的候选设计应用的精炼步数。

**dMin**：被添加或拆分的层的最小厚度。

**最大新增（Max added）**：随机添加或插入的层的最大起始厚度。针式插入会自行选择厚度。

**最大层数（Max layers）**：设计最多可增长到的层数。

**智能起始设计**：搜索开始前，用材料池构建四分之一波长和半波长增透设计并逐一精炼，从其中与你的设计相比最好的一个开始。它对增透目标有帮助；对其他目标，它会让搜索从增透设计所在的盆地开始，因此默认关闭。

**深度搜索**：一直搜索，直到点击 **停止** 或用完时间预算。当连续 **最大迭代次数** 的三分之一代（至少 15 代）没有找到更好的设计时，搜索从最佳设计重新开始：施加一到三个随机变异（抖动为平时的三倍），精炼后把温度恢复到 **T₀**。控制栏中的 **重新加热** 计数这些重新开始。

**时间预算（分钟）**：开启深度搜索时，达到该分钟数后结束搜索；0 表示一直运行到 **停止**。

**并行 K（Parallel K）**：每一代一起精炼的候选数量。

**内层精炼器**：精炼每个候选所用的方法。可选方法见 [优化方法](/zh/synthesis/optimization-methods/)。

**随机种子（Random seed）**：变异、接受判定和重新加热时的扰动都从这个数值抽取随机数。留空时，**运行（Run）** 会填入一个新的种子并保留在框中，因此用相同的种子、设计、设置和 **并行 K** 再次运行，会重复同一次运行。清空该字段即可重新抽取。历史记录会为每次运行标出其种子。

评价函数中的 `MNT` 和 `MXT` 行在搜索期间保持有效：最大的 `MNT` 目标值会抬高 **dMin**，最小的 `MXT` 目标值则为每一层设定上限，对候选及其精炼都适用。因此，只为少数几层写的限制在这里会作用于整个堆栈；最后请运行一次 [精炼](/zh/synthesis/refinement/) 和 [设计清理器](/zh/synthesis/design-cleaner/) 处理，使每个限制只作用于它自己的层。

## 如何解读

**评价函数趋势（MF trend）** 图将最佳评价函数和当前评价函数都对代数作图，而一个**已接受改进历史**列出了每一个新的最佳结果及其产生的变异。**帕累托 / 最佳设计（Pareto / Top-Designs）** 面板让你可以比较所找到的最佳设计。**最佳（Best）** 可随时恢复全局最佳。

该工具在有余地重构的设计上表现出色（例如多层增透膜）；在单层设计上没有任何结构可做，因此请改用精炼。一个好的模式是先运行它来发现更优的拓扑，然后在你的制造下限上用精炼收尾。
