**渐变演化（Gradual Evolution）** 以与[针法变异](/zh/synthesis/needle/)相同的方式扩展设计，并多做一件事：当没有针层再能起作用时，它有意改变膜系结构，然后继续。它的主要手段是**强制步骤**：在膜系的入射端或出射端加一层薄层；评价函数通常会暂时上升，随后的针层利用增加的厚度，把它降到比之前更低。正是这样，它才能跳出单靠针层无法离开的局部极小值。它记录见过的最好设计，并以它结束。

如果强制加入的层与它所落在的外层材料相同，它只会使该外层变厚，随后的精炼可能直接把这部分厚度收回。出现这种情况且没有得到新的最好设计时，在出现新的最好设计之前，不会在同一结构上再走同样的一步。腾出一层对它留下的每种结构，每次运行只尝试一次；深度搜索的重新开始会重新开放两者。**表面**设为**两面**时，两个面都会被扫描，膜层较少的一面在先。

## 计算量

- **MF** 和 **OMF**：与[针法](/zh/synthesis/needle/#计算量)中相同。渐变演化在其 MF 中保留 `MNT` 和 `MXT` 行，因此低于 `MNT` 行厚度的层会增加评价函数。
- **渐变演化步数**：目前已进行的结构步骤数，包括强制步骤、腾出的层和扰动。
- 已接受的改善中各行的**类型**：**起始**或**种子**，起始设计；**针法**，作为独立膜层留下的针层；**精炼**，并入了同材料相邻层、因而只改变了厚度的针层，当前一行是本次运行自己的针法或精炼行时并入该行，结束时的合并没有去掉任何层、但其精炼使 MF 更低时也记为精炼；**渐变演化**，强制步骤刚完成时的设计；**清理**，去掉停在下限上的层、腾出的一层或结束时的合并；**扰动**，深度搜索的重新开始。
- **ΔMF**、**总厚**和**最佳设计**：与针法中相同。评价函数趋势以三角形标出强制步骤。

## 控件与设置

**运行**、**停止**、**重置**、**最佳**、**清除历史**、**恢复**和**材料池**：与[针法](/zh/synthesis/needle/#控件与设置)中相同。

**最大膜层数**：设计最多可以包含的层数。达到它并不会结束运行：只接受放得下的针层，并且腾出一层先于强制步骤。默认 50。

**目标评价函数**：最好的 MF 低于此值即停止；设为 0 则运行到渐变演化步数用完或没有可尝试的步骤为止。

**最小厚度 (nm)**：每层都不会低于的下限、强制层的厚度、针层起始的最小厚度，以及拆分一层时每部分的最小厚度。它跟随最严格的 `MNT` 行，没有时为 15 nm，直到你为该设计输入一个值。

**智能起始设计**：从设计本身以及由材料池构建的四分之一波和半波减反设计中，取各自精炼后最好的一个作为起点。它只在**厚种子处理**为**精炼种子**时起作用；选择**保留厚体**时该复选框呈灰色。

**深度搜索**：没有可尝试的步骤时，从最好设计出发，扰动每个未锁定层的厚度后重新开始；新的最好设计之后扰动在 10 % 以内，每次没有找到更好设计幅度加倍，最大到 80 %。此时**最大渐变演化循环数**不再适用：运行只在达到**目标评价函数**或点击**停止**时结束。

**精炼迭代/代**：每次候选插入所做的精炼，分两遍进行，第二遍步数减半；选择保留厚体时每遍最多 15 步。默认 30。

**最大渐变演化循环数**：运行总共可以进行多少次结构步骤。默认 16。

**综合精炼器**：在步骤之间精炼所用的方法；渐变演化默认用**共轭梯度**。见[优化方法](/zh/synthesis/optimization-methods/)。

**候选搜索**、**针法灵敏度**和**线程数**：与针法中相同。

**厚种子处理**：**保留厚体 + 温和精炼**（默认）对起始设计只评分不精炼，并把每一遍限制在 15 步以内，让针层分割厚起始层的主体；**精炼种子**先精炼起始设计，并对每一步做完整的精炼。

**完成后合并**和**合并容差, %**：自行结束的运行是否清理最好设计，以及去掉一层时 MF 最多可以比其最低值高出多少（默认 5 %）。

`PPEF` 行以及读取它的数学行与针法中一样被略去；之后运行一次[精炼](/zh/synthesis/refinement/)即可把峰峰误差降下来。

## 计算方法

### 评价函数与 P 函数

$P$ 函数、它对偏振、角度和锥角的平均，以及针层起始厚度的线搜索，与[针法](/zh/synthesis/needle/#p-函数)中相同，探测针层为 0.5 nm。扫描和强制层的选择使用光学评价 OMF；精炼和所有比较使用 MF。

### 步骤与接受

$$
\begin{aligned}
& \text{接受针层：} && \text{MF}_\text{cand} < \text{MF}_\text{work} - 10^{-9} \\
& \text{精炼：} && \text{针层之后先 } N \text{ 步，再 } \lfloor N/2 \rfloor \text{ 步；}\ N = \text{精炼迭代/代}, \\
& && \text{选择保留厚体时 } N = \min(\text{精炼迭代/代},\ 15) \\
& \text{停在下限的层：} && d_j = d_\text{min},\ \partial\text{MF}/\partial d_j > 0,\ \text{未锁定；当 } \text{MF}_\text{without} < \text{MF}_\text{best} \text{ 时去掉} \\
& \text{强制步骤：} && \text{在位置 } 0 \text{ 或 } N_L \text{ 加一层厚 } d_\text{min} \text{、材料为 } a \text{ 的层；取 OMF 最低的组合} \\
& \text{腾出一层：} && \text{去掉层 } j \text{，使其余部分精炼后（} N \text{ 步）的 MF 最低} \\
& \text{扰动：} && d_j \to \max(d_\text{min},\ d_j \cdot (1 + s u)),\quad u \text{ 在 } [-1, 1] \text{ 上均匀分布，}\ s = 0.1, 0.2, 0.4, 0.8 \\
& \text{合并：} && \text{去掉使 } \text{MF}_\text{without} \text{ 最低的层 } j \text{，只要 } \text{MF}_\text{without} \le (1 + \text{tol}) \cdot \text{MF}_\text{lowest}
\end{aligned}
$$

$\text{MF}_\text{work}$ 是工作设计的 MF，强制步骤可能使它高于迄今最好设计的 $\text{MF}_\text{best}$；$d_\text{min}$ 为**最小厚度**，$N_L$ 为该面的层数。扰动后以完整的**精炼迭代/代**步数精炼，其随机数来自固定的种子，因此运行会以同样的方式重现。

Tikhonravov 等人在每次针法优化后用他们自己的算法增加总光学厚度，并在层数或厚度超过限值时停止。这里的强制步骤是 Sullivan 和 Dobrowolski 所描述的在入射端或出射端加一层，也就是渐变演化的基本形式（Macleod），而**最大膜层数**会让运行腾出一层而不是结束。他们的薄层去除和设计清理让被去除的层取相邻层的折射率，从而保持总光学厚度；这里腾出一层和合并会连同厚度一起去掉该层，由精炼恢复评价函数需要的厚度。深度搜索就是盆地跳跃（Wales 和 Doye）。
