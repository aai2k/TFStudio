**设计清理器（Design Cleaner）** 清理综合过程留下的东西：相邻的同材料层，以及薄到镀膜机做不出来的层。它合并这些相邻层，去掉薄层，并重复这一过程直到设计稳定，因为去掉中间一层后，两层同材料的膜层可能会相接。随后它可以精炼结果，找回结构改变损失的评价函数。

被锁定的层永远不会被合并或移除；对称设计会把清理后的正面镜像到背面。

## 计算量

- **待处理操作**：每一个将被去掉或合并到相邻层中的膜层。
- **之前**和**之后**：膜层数。
- **前评价函数**和**后评价函数**：[评价函数编辑器](/zh/design/merit-function-editor/)中的评价函数；**后评价函数**是清理后、任何精炼之前的设计的值。
- **薄膜层**：当前低于阈值的膜层。

## 控件与设置

**面**：在两面都有镀膜的设计上，选择清理哪一面。**正面**或**背面**让另一面完全保持原样，**两面**（默认）清理两面。只有一面镀膜的设计和对称设计没有这个选项。

**移除小于**：薄于这么多纳米的层会被去掉。默认 5 nm；最终一轮处理时，把它提高到你的制造下限。

**合并同材料膜层**：把相邻的同材料层合并为一层。默认开启。

**之后重新优化**：在**应用**写入之前精炼清理后的设计。默认开启。

**应用**旁边**设置**菜单中的**方法**和**最大迭代**：精炼方法，默认为序列二次规划，也可选阻尼最小二乘、共轭梯度、牛顿法或牛顿-共轭梯度，步数从 1 到 500（默认 80）。

**应用**和**停止**：应用把清理和精炼作为一个可撤销步骤写入。精炼在后台运行，控件下方的信息栏显示其步数和评价函数，**停止**以目前找到的最好厚度应用清理。若在运行期间切换到另一个设计，则不会应用任何更改。

## 计算方法

### 合并

合并在光学上不改变任何东西。两层相邻的同材料膜层导纳 η 相同，相位厚度相加，因此它们的矩阵（见[针法](/zh/synthesis/needle/#p-函数)）相乘就等于一层厚度为两者之和的膜层的矩阵：

```
M(d_1) · M(d_2) = M(d_1 + d_2)        δ = 2π ñ d cos θ / λ
```

因此合并前后 R、T 和 MF 都相同。只有去除操作会改变**后评价函数**。

### 去除与重新优化

```
去除：         未锁定且 d_j < 移除小于 的层 j
轮次：         合并、去除；只要一遍中有去除就再来一遍，最多 4 遍；最后合并
精炼：         所选方法，最多“最大迭代”步，d_j ≥ max(移除小于, 1 nm)
```

精炼使用评价函数的每一行，其波段行按精炼运行在启动时的方式采样，且任何层都不能低于阈值与 1 nm 中的较大者，因此清理器保留下来的层不会被精炼压回到阈值以下。

Tikhonravov 等人去除薄层时让它取相邻层的折射率，从而保持总光学厚度不变；他们的设计清理一次去掉一层，即去掉后评价函数上升最少的那一层，直到用完允许的上升量。设计清理器则把所有低于阈值的层连同厚度一起删除，不看评价函数，之后的精炼再恢复评价函数需要的厚度。[渐变演化](/zh/synthesis/gradual-evolution/)的**完成后合并**才是按评价函数逐层去除的做法。
