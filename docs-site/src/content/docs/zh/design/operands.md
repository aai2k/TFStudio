[评价函数编辑器](/zh/design/merit-function-editor/)表格中的每一行都是一个操作数。先在速查表中找到操作数，再阅读它所在的小节。**粗体**名称是该行获得焦点时表格显示的列标题。各行如何合成评价函数、最坏情况行与峰谷波长行如何搜索其波段、波段如何采样，在操作数之后说明。

## 列

| 列 | 内容 |
| -- | ---- |
| **类型** | 操作数代码。 |
| **λ / 膜层**、**终止 \*** | 定义该操作数的两个值。它们的标题随行而变：单波长为 **λ**，波段为 **λ 起** 与 **λ 止**，加权积分为 **积分**，膜层范围为 **膜层 1** 与 **膜层 2**，比较为 **比较**，引用其他行为 **操作数#**、**操作数#1** 与 **操作数#2**，`PPEF` 行为 **曲线**，注释为 **注释**。短横线表示该行不使用此单元格。 |
| **入射角 (°)** | 入射介质中的入射角。 |
| **偏振** | `s`、`p` 或 `avg`，即均值 (Cs + Cp)/2。 |
| **标志** | 供寻峰的行使用，此时标题为 **步长**，设定在波段上搜索的精细程度（[寻找峰或谷](#寻找峰或谷)）。其他行显示短横线。 |
| **目标** | 该行被驱向的值，或它必须保持在内的边界。T、R 与 A 以百分比输入。 |
| **权重** | 该行所占的分量。 |
| **当前** | 设计当前状态下该行的值。 |
| **占 MF² 的 %** | 该行在评价函数根号下平方和中所占的份额。评价函数不为零时，各份额之和为 100 %。 |

列标题跟随获得焦点的单元格所在的行；若无，则跟随唯一选中的行；再无，则跟随第一行。表格为空或焦点在 `DMFS` 行上时，标题为 **λ / 膜层**、**终止 \*** 与 **标志**。

将鼠标悬停在 **占 MF² 的 %** 单元格上，可看到该行以其自身单位距离目标多远：**当前 − 目标**，膜层约束为 **余量**，值本身就是偏差的行为 **RMS 偏差**。单边行已满足、不计分时，这个数值仍会显示。被禁用的行、没有值的行与权重无效的行，该单元格显示短横线；只要有任何启用的行显示 **错误**，所有 占 MF² 的 % 单元格都显示短横线。

## 单波长

| 名称 | 说明 |
| ---- | ---- |
| `T` | **λ** 处的透射率。**目标**以百分比表示。 |
| `R` | **λ** 处的反射率。**目标**以百分比表示。 |
| `A` | **λ** 处的吸收率。**目标**以百分比表示。 |
| `TDB` | **λ** 处以 dB 表示的透射率，10·log₁₀ T，因此损耗读数为负。**目标**以 dB 表示；新行从 0 dB 开始。 |

这四种都读取 **入射角 (°)** 与 **偏振**。较早的设计中可能有 `TS`、`TP`、`RS`、`RP`、`AS` 与 `AP`，偏振写在代码里；它们仍会被评估，**偏振**单元格变暗，但类型选择器不再提供它们。

## 波段平均

| 名称 | 说明 |
| ---- | ---- |
| `TAV` | 从 **λ 起** 到 **λ 止** 的透射率均值。**目标**以百分比表示。 |
| `RAV` | 波段上的反射率均值。 |
| `AAV` | 波段上的吸收率均值。 |

均值在[波段网格](#波段采样)上按梯形法则计算，因此两端的点各计一半，与对波段求积分一致。一个目标设定平均电平；若要在每个波长上设目标，请使用光谱目标。

## 光谱目标

| 名称 | 说明 |
| ---- | ---- |
| `TGT` | T 偏离一条从 **λ 起** 到 **λ 止** 的直线目标的 RMS 偏差。**目标**以百分比保存这条线的两端，写作 `start→end`，输入时可写 `start->end`：`50→50` 是平坦的 50 % 线，`0→100` 是斜坡。只输入一个数时，这条线是平的。 |
| `RGT` | 对 R 的同样计算。 |
| `AGT` | 对 A 的同样计算。 |

**当前**显示 RMS 偏差，残差就是这个值，因此优化器把它推向零。运行中，波段网格上的每个采样点各自作为一个残差。这些行适用于分束器与渐变滤光片。

## 加权积分

| 名称 | 说明 |
| ---- | ---- |
| `TIW` | 以 光源(λ)·探测器(λ) 为权重、在波段上平均的 T，Σ wᵢ·Tᵢ / Σ wᵢ。**积分**选择一个已保存的预设，例如 Tvis（D65 与明视觉）或 Tsol（AM1.5G），它设定光源、探测器、波段与通道：在 `TIW` 行上选择 Rvis 会把它变为 `RIW` 行。**目标**以百分比表示。 |
| `RIW` | 对 R 的同样计算。 |
| `AIW` | 对 A 的同样计算。 |

波段属于预设，因此 **终止** 显示短横线。新行从 400-700 nm、D65 与明视觉开始，未选择预设，此时单元格显示这一设置而不是预设名称。预设来自[积分值](/zh/analysis/integral-values/)工具。

## 波段内的最坏情况

| 名称 | 说明 |
| ---- | ---- |
| `TMN` | 从 **λ 起** 到 **λ 止** 的最低 T。保持 T ≥ **目标**，以百分比表示。 |
| `TMX` | 波段上的最高 T。保持 T ≤ **目标**。使用 **步长**。 |
| `RMN` | 波段上的最低 R。保持 R ≥ **目标**。使用 **步长**。 |
| `RMX` | 波段上的最高 R。保持 R ≤ **目标**。 |
| `AMN` | 波段上的最低 A。保持 A ≥ **目标**。 |
| `AMX` | 波段上的最高 A。保持 A ≤ **目标**。使用 **步长**。 |
| `TDBMN` | 波段上以 dB 表示的最低 T。保持 T ≥ 以 dB 表示的**目标**，即插入损耗；新行从 −0.5 dB 开始。 |
| `TDBMX` | 波段上以 dB 表示的最高 T。保持 T ≤ 以 dB 表示的**目标**，即隔离度或截止电平；新行从 −30 dB 开始。使用 **步长**。 |
| `RDBMX` | 波段上以 dB 表示的最高 R。保持 R ≤ 以 dB 表示的**目标**，即减反射膜的回波损耗；新行从 −30 dB 开始。 |
| `ODMN` | 波段上的最低光密度 D = −log₁₀ T，即 T 最高之处。保持 D ≥ **目标**；新行从 3 开始。使用 **步长**。 |

该值是波段上真正的最高点或最低点，无论它多窄，按[寻找峰或谷](#寻找峰或谷)中所述的方法找到。在最坏情况违反规格之前，该行不计分。在没有任何吸收的设计上，`AMN` 或 `AMX` 行读数为 0。

**为什么以 dB 计分。** 按线性 T 计算时，保持在 0.1 % 的阻带对最小二乘评价函数几乎没有贡献，因此 −30 dB 差了十倍，在通带纹波旁边也看不出来。使用 dB 与光密度行的[单位尺度](#单位尺度)后，每一行的得分是其偏差在 T 或 R 中所代表比值的自然对数。于是同样倍数的偏差在任何电平上代价相同。在 T = 1 附近，小偏差的代价与 `T` 行相同。20 dB 与 30 dB 在评价函数中的距离也与在规格中一样远。

**下限。** 低于 10⁻¹⁵ 的 T 或 R（−150 dB，OD 15）按 10⁻¹⁵ 计，低于它时该行不再引导优化。没有任何规格会接近这个下限。

在[光学评估](/zh/analysis/optical-evaluation/)中，dB 与光密度目标画在其所代表的电平上（−30 dB 即 0.1 %），任何纵轴单位均如此：`TDB` 为点标记，波段行为覆盖其波段的水平线。它们可以像其他目标一样拖动，拖动后的电平以 dB 或 OD 写回。`ODMN` 目标是 T 目标，因此会显示在 OD 轴上。

## 峰或谷的波长

| 名称 | 说明 |
| ---- | ---- |
| `MXWT` | 从 **λ 起** 到 **λ 止** 最高 T 所在的波长。**目标**以 nm 表示；新行从波段中点开始。使用 **步长**。 |
| `MXWR` | 波段上最高 R 所在的波长。 |
| `MXWA` | 波段上最高 A 所在的波长。使用 **步长**。 |
| `MNWT` | 波段上最低 T 所在的波长。 |
| `MNWR` | 波段上最低 R 所在的波长。使用 **步长**。 |
| `MNWA` | 波段上最低 A 所在的波长。 |

该值是一个波长，而不是 T、R 或 A。用这些行把峰或陷波固定在某个波长上。5 nm 的偏差与 `T` 行上 1 % 的偏差分量相当。

## 曲线

| 名称 | 说明 |
| ---- | ---- |
| `MCURVE` | 曲线块：设计相对一组实测点或目标点的 RMS 偏差，以曲线块自身的通道计，即以百分比表示的 T、R 或 A、以 dB 表示的 T、Ψ 或 Δ。由[实测光谱](/zh/data-exchange/measured-spectra/)或[实测椭偏](/zh/data-exchange/measured-ellipsometry/)中的 **拟合…** 以及向导的曲线目标写入；类型选择器不提供它。只有 **权重** 与启用勾选可以更改。 |
| `PPEF` | 相对 **曲线** 中所选曲线块的峰峰误差：在曲线块的每个点上 EF(λ) = C_target(λ) − C_design(λ)，两者都以 dB 表示，C 为曲线块的通道，该行的值是 max EF − min EF。保持该跨度 ≤ **目标**，以 dB 表示；新行从 0 dB 开始。 |

曲线块在 **λ 起**、**λ 止**、**入射角 (°)** 与 **偏振** 中显示其波段、角度与偏振，**目标** 显示短横线。水平自由的曲线块先去掉拟合最好的常数偏移，只评价形状。运行中，曲线块变为每个点一个残差，各点平分曲线块的权重。

增益平坦滤光片的规格是它相对目标损耗曲线的误差，而不是它自身的透射率，`PPEF` 衡量的正是这个误差。设计与目标处处相差同样的 dB 数时得分为零：这个常数是插入损耗，数据表上单列一行。[规格说明](/zh/design/specification/)窗口通过同一行把这个数值作为检查项给出。

该行读取曲线块的波长、角度与偏振，因此它的 **入射角 (°)** 与 **偏振** 显示短横线。曲线块可以是以百分比表示的 T、R 或 A 曲线，或以 dB 表示的 T 曲线；若只作对照用，可设权重为 0；Ψ 或 Δ 曲线块会被拒绝。删除曲线块会同时删除该行；曲线块缺失或被关闭时，该行显示 **错误**。综合工具不使用该行，因为它的斜率只来自最差的两个波长，会让搜索停滞，它们改为拟合曲线块。若曲线块的权重小于读取它的各行，综合工具按这些行的合计权重拟合它。

## 椭偏

| 名称 | 说明 |
| ---- | ---- |
| `PSI` | **λ** 与 **入射角 (°)** 处的椭偏 Ψ，来自 ρ = r_p / r_s = tan Ψ · e^{iΔ}，0° 到 90°。新行从 45° 开始。 |
| `DEL` | **λ** 与 **入射角 (°)** 处的椭偏 Δ，0° 到 360°。新行从 180° 开始。 |
| `TANPSI` | tan Ψ。新行从 1 开始。 |
| `COSDEL` | cos Δ，−1 到 1。新行从 0 开始。 |

Ψ 与 Δ 使用两种偏振，因此 **偏振** 不起作用。这些行始终对正面镀膜计分；在仅背面模式下，它们读取正面的现状，不引导任何优化。`DEL` 行不采用椭偏仪记录、[椭偏仪评估](/zh/analysis/ellipsometry/)窗口默认显示的 Azzam–Bashara 约定。把该窗口的 **Δ 约定** 设为 360° − Δ，即可读到与该行相同的数值。要拟合实测的 Ψ/Δ 曲线对，请在[实测椭偏](/zh/data-exchange/measured-ellipsometry/#把设计拟合到测量)中生成目标，每个通道作为一个曲线块保存，并带有自己的约定。

## 相位与色散

| 名称 | 说明 |
| ---- | ---- |
| `PR`, `PT` | **λ** 处反射或透射振幅的相位，以度表示。 |
| `DPR`, `DPT` | **λ** 处反射或透射的 p 减 s 相位差，以度表示。 |
| `GD`, `GDT` | **λ** 处反射或透射的群延迟，以 fs 表示。 |
| `GDD`, `GDDT` | **λ** 处反射或透射的群延迟色散，以 fs² 表示。 |
| `TOD`, `TODT` | **λ** 处反射或透射的三阶色散，以 fs³ 表示。 |
| `GDFLAT`, `GDTFLAT` | **λ 起** 与 **λ 止** 之间群延迟偏离 **目标** 的 RMS 偏差，以 fs 表示。 |
| `GDDFLAT`, `GDDTFLAT` | 波段上 GDD 偏离 **目标** 的 RMS 偏差，以 fs² 表示。 |
| `TODFLAT`, `TODTFLAT` | 波段上 TOD 偏离 **目标** 的 RMS 偏差，以 fs³ 表示。 |

**偏振**选择 s 或 p；`avg` 取二者的均值，p 减 s 的行除外。每个值都来自恰好在所请求波长处的复振幅，与[群延迟 / GDD](/zh/analysis/gd-gdd/) 窗口的计算相同。新行从目标 0 开始。相位偏差沿圆周按较短的方向计算。在 `*FLAT` 行上，**当前**显示波段达到的电平，即波段网格上的梯形加权均值，因此可以直接与目标对照；评价函数计分所用的 RMS 偏差在 占 MF² 的 % 单元格的提示中。

这些行对正面镀膜计分；设计的表面模式为仅背面时，对背面镀膜计分。没有针对整个元件的相位行：在总计评价模式下，R 与 T 行对完整元件计分，而同一表格中的相位行继续对那一层镀膜计分，评价函数编辑器与精炼窗口会在表格上方说明这一点。若某个相位行的波长超出任一材料模型标明的范围，该行没有值：**当前** 显示 **错误**，该行的提示指出是哪种材料，并且在每个启用的行都有值之前，评价函数与精炼都不可用。

## 电场

| 名称 | 说明 |
| ---- | ---- |
| `EFMX` | **λ** 与 **入射角 (°)** 处正面镀膜内任意位置归一化 \|E\|² 的峰值。**偏振**选择 s 或 p；`avg` 取两个峰值中较大的一个。新行从目标 0 开始，因此它降低峰值电场，这是提高激光损伤阈值的常见目标。 |

[电场评估](/zh/analysis/efield/)窗口把 `avg` 画成 s 与 p 分布的均值，因此在那里看到的峰值可能低于该行的值。`EFMX` 行会让每一步优化变慢：它的斜率用有限差分求得，只要它在评价函数中，其他各行的斜率也都改用有限差分。

## 对其他行的数学运算

| 名称 | 读取 | 值 | 保持 |
| ---- | ---- | -- | ---- |
| `OPGT` | **操作数#** | ref | ref ≥ **目标** |
| `OPLT` | **操作数#** | ref | ref ≤ **目标** |
| `OPVA` | **操作数#** | ref | ref = **目标** |
| `ABSO` | **操作数#** | \|ref\| | \|ref\| = **目标** |
| `ABGT` | **操作数#** | \|ref\| | \|ref\| ≥ **目标** |
| `ABLT` | **操作数#** | \|ref\| | \|ref\| ≤ **目标** |
| `DIFF` | **操作数#1**、**操作数#2** | ref1 − ref2 | 值 = **目标** |
| `SUMM` | **操作数#1**、**操作数#2** | ref1 + ref2 | 值 = **目标** |
| `PROD` | **操作数#1**、**操作数#2** | ref1 · ref2 | 值 = **目标** |

数学行读取另一行的值，而不是由镀膜计算出一个值。它的目标采用被读取行的单位；被读取的行全部是 T、R 或 A 行时，以百分比显示。**入射角 (°)** 与 **偏振** 显示短横线：读取的值是在另一行的角度与偏振下算出的。优化器由数学行所读取各行的斜率求得它的斜率。数学行若直接或经由另一数学行读取 `EFMX` 行，或读取水平不自由的曲线块，会让每一步优化变慢：它的斜率用有限差分求得，只要它在评价函数中，其他各行的斜率也都改用有限差分。

引用单元格按当前行号与类型列出各行，例如 `#4 TMN`。链接保存的是行本身，而不是它的编号，因此插入、删除或移动行都不会使其断开。删除一行时，读取它的数学行也一并删除。引用的行已不存在时（例如从别处加载的评价函数），显示红色的 **（已删除）**。读取被禁用、缺失或没有值的行，或处在引用环上的行，没有值：**当前** 显示 **错误**，修正之前评价函数无法计算。

[规格说明](/zh/design/specification/)窗口中的 **生成评价函数** 会为每个 ≥ 或 ≤ 规格写入一个权重为 0 的测量行（`TAV`、`TMN` 等），以及一个读取它的 `OPGT` 或 `OPLT` 行，因此表格读作“目标 99 %，值 99.5 %”。

## 厚度与应力

| 名称 | 说明 |
| ---- | ---- |
| `TT` | 被优化镀膜的膜层厚度之和，包括锁定的膜层，以 nm 表示。**比较** 设定 ≤、≥ 或 =；新行按 = 比较，从 1000 nm 开始。在对称模式下只对正面堆栈求和。 |
| `STR` | 镀膜施加于基底的单位宽度力，Σ σ_l·d_l，以 N/m 表示。**比较** 设定 ≤、≥ 或 =；新行从 = 0 N/m 开始，即平整的基底。 |
| `MNT` | 从 **膜层 1** 到 **膜层 2** 中最薄的膜层。保持它 ≥ **目标**，以 nm 表示。 |
| `MXT` | 从 **膜层 1** 到 **膜层 2** 中最厚的膜层。保持它 ≤ **目标**，以 nm 表示。 |

膜层的编号与设计编辑器相同，第 1 层紧贴基底。两面独立优化时，先数正面各层，再数背面各层，每一面都从基底向外计数。范围被限制在堆栈之内，新的 `MNT` 或 `MXT` 行覆盖第 1 到 1000 层，因此会持续覆盖综合所添加的膜层。不包含任何膜层的范围没有值，评价函数会跳过它。`MXT` 行是膜层厚度唯一的上限：没有它，优化器会让膜层按评价函数的需要一直加厚。

这四种行不计入 OMF，也不参与综合的搜索。针式（自动与手动）不使用 `MNT` 与 `MXT`，并让膜层保持在它自己的最小厚度之上；`TT` 或 `STR` 行保留在针式的精炼步骤中，但不参与它寻找插入位置的搜索。深度合成与结构优化器不使用 `MNT` 与 `MXT`，而是把其中最严格的各自作为每一层的下限与上限；结构优化器在判断是否接受改动时所用的评价函数中保留 `TT` 与 `STR`。渐进演化与精炼把这四种行都保留在评价函数中。

### 薄膜应力

镀膜会拉扯它所附着的基底，厚度不足以忽略这种拉力的基底就会弯曲。造成这种弯曲的单位宽度合力为

```
F = Σ σ_l · d_l      （N/m，即 MPa·µm）
```

对各膜层求和，背面镀膜取负号，因为它的拉力方向相反。`STR` 把这个合力纳入评价函数，使基底弯曲成为优化器可以控制的量，而不是第一批工件下机后才发现的问题。**目标为 0 即零挠度条件：**压应力膜与张应力膜相互平衡的镀膜会让基底保持平整。

每层膜的应力取自其材料记录，位于[材料编辑器](/zh/design/material-editor/)的「力学」选项卡，而不是该行本身。`STR` 唯一必需的数据是**以 MPa 表示的本征应力**（张应力为正），这正是晶圆弯曲测量所给出的量。未给出本征应力的材料不作贡献，评价函数表会把它列出来，因此空白记录绝不会被当作无应力薄膜。

如果材料还给出了杨氏模量、泊松比与膨胀系数，并且设计中带有在[应力](/zh/analysis/stress/)窗口中设定的应力温度（缺少的一个按 20 °C 计），就会加入两个热应力项。一项修正应力是在材料的参考温度而非沉积温度下测得这一点；未给出参考温度的材料按在沉积温度下测得处理。另一项是基底给出膨胀系数时，在沉积温度与评估温度之间与基底的膨胀失配。这里的沉积温度指薄膜生长时基底的温度。

哪些镀膜参与计算取决于设计的评估模式，与所有分析窗口一致：开启“忽略另一面”时只算当前面，否则两面都算。在对称模式下，镜像的背面镀膜与正面精确抵消，因此无论膜层如何变化该行都为零，评价函数表会给出提示。

残差是原始的 N/m，评价函数加上的是权重乘以其平方，因此权重为 10⁻⁵ 时 1 N/m 的偏差，与权重为 1 时 0.3 % 的反射率偏差分量大致相当。

## 各行如何合成评价函数

评价函数为

```
MF = √( Σ wᵢ · (rᵢ / σᵢ)²  /  W )
```

其中 wᵢ 是该行的权重，rᵢ 是其残差，σᵢ 是其[单位尺度](#单位尺度)。W 是所有有值的行的权重之和，`MNT`、`MXT`、`TT` 与 `STR` 除外；只有当其他有值的行权重合计为零时，这四种行的权重才计入。被禁用的行、注释行与没有值的行不计入任何部分。旁边的 OMF 是去掉 `MNT`、`MXT`、`TT` 与 `STR` 行之后的同一求和。

| 残差 | 行 | rᵢ |
| ---- | -- | -- |
| 等式 | `T` `R` `A` `TDB`、波段平均、积分、`MXW*` `MNW*`、`PSI` `TANPSI` `COSDEL`、`GD` `GDD` `TOD` 及其透射形式、`EFMX`、`OPVA` `ABSO` `DIFF` `SUMM` `PROD` | 值 − 目标 |
| 圆周上的等式 | `DEL` `PR` `PT` `DPR` `DPT` | 值 − 目标，沿圆周按较短方向取，−180° 到 180° |
| 下限 | `TMN` `RMN` `AMN` `TDBMN` `ODMN` `OPGT` `ABGT` `MNT` | 值低于目标时为 目标 − 值，否则为 0 |
| 上限 | `TMX` `RMX` `AMX` `TDBMX` `RDBMX` `OPLT` `ABLT` `MXT` `PPEF` | 值高于目标时为 值 − 目标，否则为 0 |
| 按 **比较** 单元格 | `TT` `STR` | ≤ 为上限，≥ 为下限，= 为等式 |
| 偏差 | `TGT` `RGT` `AGT`、各 `*FLAT` 行、`MCURVE` | RMS 偏差，即 **当前** 显示的值；`*FLAT` 行的 RMS 偏差在提示中 |

已满足的单边行残差为零，不牵引任何参数，但除 `MNT`、`MXT`、`TT` 与 `STR` 外，它的权重仍计入 W。因此它会降低 MF 读数：偏差 0.1 的 `T` 行单独计分为 0.1，旁边加上一个权重相同、已满足的 `TMN` 行后为 0.0707。

### 单位尺度

每个残差除以 σ，使不同单位的行处于同一尺度，权重因此只表示重要程度而不涉及单位。

| 行 | σ | 计分为 0.01 的偏差 |
| -- | - | ------------------ |
| 各种 T、R 与 A 行、`TANPSI`、`COSDEL`、`EFMX` | 1 | T、R 或 A 中的 1 % |
| `MXW*` `MNW*` | 500 nm | 5 nm |
| `TDB` `TDBMN` `TDBMX` `RDBMX` `PPEF` | 10/ln 10 ≈ 4.343 dB | 约 0.04 dB，即 T 或 R 变化 1 % |
| `ODMN` | 1/ln 10 ≈ 0.4343 | 约 0.004 |
| `PSI` | 10° | 0.1° |
| `DEL` | 20° | 0.2° |
| `PR` `PT` `DPR` `DPT` | 180° | 1.8° |
| `GD*` `GDD*` | 50 fs、50 fs² | 0.5 fs、0.5 fs² |
| `TOD*` | 500 fs³ | 5 fs³ |
| `MCURVE` | 其通道的 σ | |
| `TT` `STR` `MNT` `MXT` | 1，以 nm 或 N/m 计 | 0.01 nm 或 0.01 N/m |
| 数学行 | 所读取行的 σ | |

数学行采用所读取行的 σ，因此读取 `MXWT` 行的 `OPLT` 对偏差的计分，与该 `MXWT` 行在同一目标下完全相同。`DIFF` 与 `SUMM` 读取的两行 σ 相同时采用该 σ；两行 σ 不同时保持为 1。`PROD` 采用两个 σ 的乘积。厚度与应力行按原始值计分，因此被违反的制造边界会最先被修正。

## 寻找峰或谷

最坏情况行与 `MXW*` / `MNW*` 行报告波段上真正的最高或最低值，而不是一组采样点中最好的那个。一行要么寻找 T、1 − R 或 A 的峰（窄共振或漏光可能藏在那里），要么寻找谷：

| 寻峰 | 寻谷 |
| ---- | ---- |
| `TMX` `RMN` `AMX` `TDBMX` `ODMN` `MXWT` `MNWR` `MXWA` | `TMN` `RMX` `AMN` `TDBMN` `RDBMX` `MNWT` `MXWR` `MNWA` |

寻峰的行从一个均匀网格开始，其步长由 **步长** 标志设定；寻谷的行从 13 个点开始。在厚镀膜上，两种网格都会加密到每个干涉条纹三个点，并且与[波段网格](#波段采样)一样，在运行开始时按设计确定。网格显示出的每个峰或谷都会被尝试，决定该行取值的那一个随后被精确求出，波段两端也会被检查，因此结果与采样点落在何处无关。

| 步长 | 1 或空 | 2 | 3 | 4 |
| ---- | ------ | - | - | - |
| 网格步长 | 1 nm | 0.1 nm | 0.01 nm | 0.001 nm |

步长只决定能否把相距很近的两个峰区分开。相距不到约两个步长的两个峰，例如双腔滤光片分裂的顶部，可能被读作一个峰，而且不一定是较高的那个。若波段中有这样的一对峰，请提高步长。每提高一级，波段上的采样密度增加十倍，该行的耗时也相应增加。

[规格说明](/zh/design/specification/)窗口、报告的技术规格判定区块以及[镀膜库](/zh/design/coating-library/)中的指标以 0.01 nm 搜索。FWHM 或边缘 λ 检查沿同一步长的波段扫描从峰向外查找，先框定电平的每个交点，再用二分法求出交点，因此其值在任何步长下都是精确的；步长只决定找到哪个峰，以及能否看到峰与交点之间的谷。窗口在优化运行期间实时更新时以 1 nm 搜索，运行停止后恢复 0.01 nm。状态栏监控项以 0.1 nm 搜索和扫描。[蒙特卡洛](/zh/analysis/error-analysis/)良率要对每次试验评估规格，它与公差工具中的规格徽标都以 1 nm 搜索。

## 波段采样

波段平均、光谱目标、加权积分与各 `*FLAT` 行在波段上的均匀网格上采样。网格随镀膜而定：其步长为波段短波端条纹间距 λ²/(2G) 的八分之一，其中 G 是镀膜的光学厚度，按群折射率 n − λ·dn/dλ 计算（在 n 更大处取 n）；两面都有镀膜时，两层镀膜的厚度相加。网格至少 13 个点，且没有上限，因此优化器无法靠把干涉条纹移到采样点之间的空隙来降低评价函数。

评价函数编辑器与精炼窗口的评价函数表格、设计清理器、针法手动以及每次优化器运行，都按设计确定网格大小。精炼在整个运行中保持该网格不变；综合运行则随设计变大而扩大网格。其他报告波段平均的视图（例如规格说明窗口）保持 2 nm 步长，因此在厚镀膜上，它们给出的数值可能与评价函数表格中的略有不同。

每次运行开始时，会检查每个光谱目标行（`TGT`、`RGT`、`AGT`）中是否有高度至少 2 %、宽度小于其网格步长的峰或谷。若有，该行的采样会加密到能在最窄的此类特征上放下四个点，整个波段最多 2001 个点。评价函数表格不做这一步，因此运行中这样的行计分可能与表格略有不同。
