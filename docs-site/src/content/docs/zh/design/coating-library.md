镀膜库把镀膜与设计分开保存。一个镀膜包括膜层堆栈、设计时所用的基底和入射介质、所针对的波段、入射角和偏振，以及它所满足的规格；其中任何一个都可以放到打开的设计的前表面或后表面上。**内置**中是随 TFStudio 提供的起始设计，**我的镀膜**中是你自己保存的镀膜。

## 计算的量

选中一个镀膜后显示：

- **光谱**：镀膜单独位于其基底上、从其入射介质观察的结果，按条目自身的入射角和偏振计算，图中会注明。正入射时为 T、R 和 A；斜入射时 s 为实线、p 为虚线，这正是分束器或偏振片的规定方式。设计波段以阴影标出。
- **膜系**：从基底向外的膜层，编号与设计编辑器相同，厚度以 nm 计。
- **设计波段内的特性**，按条目的入射角计算，按其类别选取：减反射膜为平均和最大 R；反射镜为最小 R 和 A；边缘滤光片为通带和截止带 T 以及 T = 50 % 处的边缘 λ；带通滤光片为峰值、中心 λ 和 FWHM；陷波滤光片为 T = 50 % 处的陷波中心和宽度；偏振片为 Ts、Tp 和消光比 Tp / Ts。斜入射时 R 和 T 给出 s、p 及其平均，每个波段一列；最后是层数和总厚度。
- **规格**：条目给出的每项指标，按其入射角和偏振，附数值和合格或不合格标记，判定方式与[规格](/zh/design/specification/)窗口相同，各按其自身步长。
- **适用场合**、**局限**和**来源**。

每个内置镀膜都使用内置材料或自带材料，因此在每台电脑上计算结果都相同；取自书中理想折射率的设计已换成真实材料，并重新优化到满足其规格。请把条目当作起点，再由此精炼。

## 控件与设置

列表按类别分为文件夹，各带计数；每一行上的色条以材料的颜色显示膜系，基底在左。可以按类型、基底、必须落在某个设计波段内的**波段内 λ**、**最多层数**，以及名称、用途、标签、基底和材料中的文字进行筛选。**标签**展开其余条目的标签，每类一行，每个标签片显示选中后会保留的条目数；所选标签必须全部出现在条目上，面板折叠后仍留在栏中。悬停在标签上可查看其含义。

**应用到活动设计**：**前表面**或**后表面**，然后选择**替换膜系**或**叠加在膜系之上**，后者使镀膜的膜层成为最外层。作为一个撤销步骤。设计的基底和介质不会改变，因此在依赖条目的数值之前，请将它们与条目的基底和介质对比。

此处的**保存当前镀膜…**或设计编辑器“工具”菜单中的**将镀膜保存到库…**，把前表面或后表面膜系连同名称、类型、用途说明、波段、入射角和偏振保存到“我的镀膜”。[Zemax 镀膜](/zh/data-exchange/zemax-coatings/)和 [CODE V 镀膜](/zh/data-exchange/codev-coatings/)窗口通过同一对话框保存从文件读入的镀膜。已保存的镀膜是 Coatings 文件夹（首选项，数据文件夹）中的 `.tfsc` JSON 文件；同名镀膜会被替换。**删除**移除所选的已保存镀膜。

**分享镀膜…**把你的一个镀膜提交到内置库：通过预填了层表和条件的 GitHub 讨论或电子邮件，**保存文件以便发送…**则把镀膜连同材料数据写成一个可附加的文件。投稿的镀膜会随下一个版本发布，并在来源一栏中署名。

## 镀膜中的材料

- 已保存的镀膜嵌入所有非内置材料，因此其来源目录被重命名或删除后仍然可用。只要其来源目录还在这台电脑上，镀膜在库中和设计中都按该目录的当前数据计算。
- 来自另一台电脑的镀膜可以在某个 ID 下自带一份副本，而这台电脑上的目录在同一 ID 下有不同的 n、k。库按该副本计算，尚未使用该 ID 的设计也按该副本计算。
- 当镀膜带来的定义所用的 ID 在设计中已按其他数据计算时，设计保留自己的定义，窗口会说明；此时该镀膜的计算结果可能与库中不同。
