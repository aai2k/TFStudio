**边缘滤光片**用两种材料构建一个在斜入射角下使用的短波通或长波通滤光片，使 s 偏振光与 p 偏振光的边缘位于同一波长。你给出边缘波长、入射角和材料；窗口找出能做到这一点的周期，预览完成的滤光片，并把它放入设计。

在 45° 下使用的四分之一波堆栈会分裂：它的 s 边缘与 p 边缘彼此分开，对非偏振光而言，边缘的陡度不会超过这一分裂。改变 (0.5H L 0.5H) 周期中两层的厚度都无法消除它。五层周期可以：

```
aA bB cA bB aA
```

其中 A 与 B 是两种材料，a、b、c 是边缘波长处的四分之一波倍数。对每个 a，都有使 s 与 p 边缘在所选角度下重合的 b 与 c 值，窗口搜索的就是它们。

## 边缘指什么

边缘是该周期无限重复所成堆栈的截止带的边缘。对称周期的作用如同单层，当其特征矩阵的对角元 N11 落在 −1 到 1 之外时，光无法穿过许多个这样的周期；截止带在 N11 = ±1 处结束。这只是周期本身的性质。周期数、基底以及之后添加的任何匹配层都不会移动它。

完成的滤光片的边缘，即其透射率穿过 50 % 之处，紧靠截止带边缘，并随周期增加而向它靠拢。堆栈的 p 边缘比 s 边缘略缓，因此在周期较少且没有匹配层时，即使两个截止带从同一波长开始，两个 50 % 点也会相隔零点几纳米到几纳米。预览显示的是完成的滤光片，因此两者你都能看到。

## 设置

**短波通 / 长波通**：边缘的哪一侧透射。对短波通，截止带位于边缘波长之上。

**边缘 λ**：两个截止带开始的波长。周期以此波长处的四分之一波写出。

**入射角**：在入射介质中使 s 与 p 重合的角度，在 0° 与 90° 之间。正入射时无需使其重合。

**周期数**：滤光片包含的周期个数。它不改变搜索，只改变预览和应用的滤光片。

**入射介质**与**基底**：滤光片两侧的介质。搜索使用入射介质；基底用于预览并写入设计。

**材料 A** 与**材料 B**：两种材料。窗口打开时取设计正面镀膜中折射率最低与最高的材料；若不足两种，则取 SiO2 与 TiO2。

**a 起**、**a 止**、**a 步长**：外层的搜索范围。起点在 0 与 1 之间，终点大于起点且不超过 2，步长在 0.0001 与 1 之间。默认的 0.1 到 1、步长 0.05 通常已足够；步长越细，耗时越长。

## 搜索

对每个 a 值，窗口找出使 s 与 p 截止带边缘在边缘波长处重合的 b 值，并对每个 b 找出把边缘放到那里的 c。它把周期正反两种排列都试一遍：A 在外与 B 在外。找到的每个周期的边缘位于奇数级截止带 (N11 = −1) 或偶数级截止带 (N11 = +1)；若 s 与 p 截止带都从边缘开始却位于其两侧，则该周期不是边缘滤光片，会被舍去。

搜索取每种材料在边缘波长处的折射率，并把膜层视为无损耗。当某材料在该处有吸收时，窗口会说明；搜索只用其 n，预览则使用完整的 n 与 k。离开边缘波长后，真实材料的折射率会变化，预览会显示这一点，而表中的截止带宽度不会。

搜索在后台运行。**停止**可结束它。

## 如何阅读结果

找到的每个周期占一行：外层材料、a、b、c、从边缘起的 s 截止带与 p 截止带宽度，以及从边缘到任一偏振的下一个截止带的通带宽度。所有宽度以纳米为单位，按边缘波长处的折射率计算；∞ 表示后面没有截止带。

最佳周期列在第一行并被选中。非偏振光只在两个截止带都覆盖的地方被截止，所以 s 与 p 截止带中较窄的那个就是滤光片的截止带，各周期按这一宽度从宽到窄排列。宽度相同时，通带较宽者在前。点击另一行即可预览并应用该周期。

## 放入设计

**公式**框以[膜系公式](/zh/design/stack-formula/)记法给出所选周期，例如 `(0.4L 0.548843H 0.362692L 0.548843H 0.4L)^19`，其中 H 是边缘波长处折射率较高的材料，L 是另一种。选中即可复制，或按**在膜系公式中打开**，在那里继续工作，公式、材料和边缘波长都已填好，例如在其两侧添加匹配层。

底部按钮的作用与膜系公式中相同。**替换**用滤光片取代所选面的镀膜，**追加**把它加在已有镀膜之外，**新建设计**用它创建一个新设计。替换还会把设计的参考波长设为边缘波长、把基底设为此处所选，入射介质则成为正面镀膜的入射介质或背面镀膜的出射介质。两个周期相接处，它们的外层是同一种材料，在设计中合为一层，厚度为两者之和。

搜索不考虑通带中的波纹，波纹取决于周期的等效导纳与介质的匹配程度。要使其平滑，可用[精炼](/zh/synthesis/refinement/)优化滤光片，只放开两端的几层，其余全部锁定。
