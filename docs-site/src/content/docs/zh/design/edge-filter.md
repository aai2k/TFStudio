边缘滤光片用两种材料构建在斜入射角下使用的短波通或长波通滤光片，使其 s 与 p 边缘位于同一波长。四分之一波堆栈在 45° 下其 s 与 p 边缘分开，改变 (0.5H L 0.5H) 周期中两层的厚度都无法使它们重合。五层周期可以：

```
aA bB cA bB aA
```

其中 A 与 B 是两种材料，a、b、c 是边缘波长处的四分之一波倍数。对某些 a 值，存在使 s 与 p 边缘在所选角度下重合的 b 与 c；窗口在一个 a 范围内搜索，并列出找到的周期。

## 计算的量

| 列 | 含义 |
|---|---|
| **外层** | 外层的材料。 |
| **a, b, c** | 周期在边缘波长处的四分之一波倍数。 |
| **宽度 (nm) s, p** | 从边缘起 s 与 p 高反射截止带的宽度。 |
| **宽度 (nm) 通带** | 从边缘到通带一侧任一偏振的下一个截止带；没有时为 ∞。 |

宽度按边缘波长处的折射率计算。非偏振光只在两个截止带都覆盖的地方被截止，所以 s 与 p 截止带中较窄的那个就是滤光片的截止带：各周期按它从宽到窄排列，宽度相同时通带较宽者在前，第一行被选中。

图中显示完成的滤光片在入射角下 s、p 及其平均的 T，并标出边缘。**公式**以[膜系公式](/zh/design/stack-formula/)记法给出所选周期，H 是边缘波长处折射率较高的材料；对 SiO2 与 TiO2，边缘在 510 nm、在空气中以 45° 入射、19 个周期时，它是 `(0.4H 0.593622L 0.294978H 0.593622L 0.4H)^19`。

## 控件与设置

**短波通 / 长波通**：边缘透射的一侧。**边缘 λ (nm)**：两个截止带开始的波长。**周期数**：预览和应用的滤光片的周期数；它不改变搜索。

**入射角 (°)**：从 0° 到小于 90°。在 0° 时 s 与 p 是同一列波，因此窗口给出普通的四分之一波周期，缩放到使其截止带从边缘开始，两种排列都列出：短波通先列 (0.5L H 0.5L)，长波通先列 (0.5H L 0.5H)，这是在空气与玻璃之间匹配更好的排列。

**入射介质**与**基底**：搜索使用入射介质；基底用于预览和设计。**材料 A** 与**材料 B** 初始为正面镀膜中折射率最低与最高的材料，或 SiO2 与 TiO2。

**a 起**、**a 止**、**a 步长**：搜索范围，从 0 到 2，步长不小于 0.0001。a 增加略大于 2 的量，相当于在每个外层中加入倾斜的半个波长，会再次得到相同的 b 与 c，所以范围止于 2。默认的 0.1 到 1、步长 0.05 不到一秒即可完成；0 到 2、步长 0.0001 需要几分钟。窗口打开时以及按**搜索**时在窗口线程之外搜索；按**停止**结束。

窗口在每次打开之间记住通带类型、角度、周期数、材料以及 a 的范围；边缘波长与介质取自设计。

**在膜系公式中打开**把公式、材料、介质和边缘波长带到那里，例如用来添加匹配层。**替换**、**追加**和**新建设计**的作用与膜系公式中相同；替换还会设定参考波长为边缘波长，并设定基底以及所选面的入射或出射介质。两个周期相接处，两个外层合为一层，厚度为两者之和。

## 截止带边缘与完成的滤光片

- 截止带边缘只属于周期本身：周期数、基底和匹配层都不会移动它。完成的滤光片的 50 % 点位于其附近，并随周期增加而靠拢。p 边缘比 s 边缘缓，因此周期较少时，即使两个截止带同时开始，两个 50 % 点也会相隔零点几纳米到几纳米。
- 搜索取边缘波长处的各折射率，并把膜层视为无损耗；某材料在该处有吸收时窗口会说明，预览则使用 n 与 k。离开边缘波长后，真实材料的折射率会变化，预览会显示这一点，而宽度不会。
- 搜索不考虑通带波纹，波纹取决于周期的等效导纳与介质的匹配程度。要使其平滑，可运行[精炼](/zh/synthesis/refinement/)，只放开两端的几层，其余全部锁定。

## 理论

λe 为边缘波长，倍数为 m、折射率为 n 的膜层厚度为 d = m λe / (4n)，其相位厚度与倾斜导纳为（Macleod，第 9.2 节，式 9.2）

```
δ = 2π n d cos θ / λ
η_s = n cos θ,     η_p = n / cos θ
```

cos θ 由 n₀ sin θ₀ 求出。无损耗膜层组成的对称周期，其特征矩阵的对角元为实数且相等，N₁₁ = N₂₂（Macleod，第 7.2.2 节，式 7.5–7.6）。当 |N₁₁| > 1 时，随周期增加，该周期堆栈的反射率趋于 1，截止带边缘位于 N₁₁ = ±1 处（第 9.5.1 节，式 9.21）。

中心层以 cos γ 与 sin γ 的线性形式出现，γ 为其相位：

```
N₁₁ = P cos γ + Q sin γ
```

P 为去掉中心层时的 N₁₁，Q 为中心层为四分之一波时的 N₁₁。γ 对 s 与 p 相同，因此要求两种偏振在 λe 处都满足 N₁₁ = σ（σ = ±1），就是关于 cos γ 与 sin γ 的两个线性方程。其解只在特定的 b 下落在单位圆上：

```
F(b) = x² + y² − 1 = 0,    x = σ (Q_p − Q_s) / D,    y = σ (P_s − P_p) / D,    D = P_s Q_p − Q_s P_p
```

对每个 a 以及任一材料在外，在 b 的一个周期上对 F 采样，用二分法求出每个根，再由 γ 得到 c。只保留两个截止带都位于滤光片截止一侧的根。
