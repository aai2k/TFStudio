**材料编辑器**是你管理 TFStudio 所知的每一个折射率来源的地方。每种材料提供折射率 `n(λ)` 与消光系数 `k(λ)`；吸收材料具有 `k > 0`。应用中每个要求你选择材料的下拉框都从这里读取。

材料按来源分组到各个目录中：

| 目录               | 来源                                                       | 可编辑性     |
| ------------------ | ---------------------------------------------------------- | ------------ |
| **内置（Built-in）** | 一组精选的 16 种常见光学材料。                             | 只读         |
| **AGF**            | 放置在你的 TFStudio 数据文件夹的 `Materials` 子目录中的 Zemax `.agf` 文件。     | 通过文件     |
| **用户（User）**   | 你在 TFStudio 内部创建的材料与目录。                       | 是           |
| **RefractiveIndex** | 你从 refractiveindex.info 数据库导入的材料。             | 是           |

左侧面板包含目录选择器、搜索框与材料列表；右侧面板分两页显示所选材料：**n 与 k** 和**力学**。内置与 AGF 材料显示只读详情（属性、色散公式、列表数据，以及 n/k 图表）；用户与导入材料在可编辑表单中打开。名称、ID、颜色与波长范围位于两页之上，因为无论打开哪一页，它们标识的都是同一种材料。

## 设置

**目录选择器**：选择单个目录或**全部（All）**。选择器显示每个目录的材料数量，其下方是管理所选目录的操作。

**搜索**：按名称过滤列表（不区分大小写）。过滤器遵循你所选择的目录。

**导入 AGF**：将一个 Zemax `.agf` 玻璃文件作为新目录加载。AGF 文件存储内部透射率随波长的变化；TFStudio 会自动将其转换为 `k(λ)`。你放置在 TFStudio 数据文件夹的 `Materials` 子目录中的 AGF 文件在应用启动时也会自动被拾取。色散公式编号不在 TFStudio 可计算范围内的玻璃不会进入目录，导入消息会列出它的名称。启动时自动拾取的文件没有可以显示消息的窗口，因此要查看哪些玻璃被略去，请用**导入 AGF** 导入该文件。

**导入材料文件**：加载其他镀膜软件写出的材料文件，可一次选择多种来源的文件：

| 程序               | 文件                                                                    |
| ------------------ | ----------------------------------------------------------------------- |
| TFCalc             | `MATERIAL` 与 `SUBSTRAT` 文件夹中的 `.mat`                                |
| Essential Macleod  | 材料数据库文件夹中的 `.tfx`，或通过 File → Export → Material 导出的 `.mtx` |
| OptiLayer          | `.lm` 与 `.sub`                                                          |

导入对话框列出读取到的每种材料及其来源程序与数据类型（带点数的表格，或以原程序名称给出的公式），并预览当前选中的材料：公式与系数或表格数据行，以及 n/k 图表。取消勾选不需要的材料，选择要添加到的目录，或创建一个新目录。

TFCalc 与 Essential Macleod 的文件不记录波长单位。对话框默认按纳米处理；当 `.tfx` 文件位于其数据库文件夹中时，会读取该 Essential Macleod 数据库自身的单位设置；如果预览中的曲线位置不对，可切换为微米。

公式材料在 TFStudio 具有相同形式时保留公式。TFStudio 没有的 TFCalc 形式（Hartmann、Drude 以及所有 k 公式）会在文件声明的范围内采样为表格。Essential Macleod 的内部透过率表在这里没有对应项，因此不导入；`k` 列按原样导入。Essential Macleod 材料库中的压缩文件无法读取：请先在 Essential Macleod 中打开该材料并保存到你的数据库中。

`k` 小于零的表格点按原样导入，并在对话框中标出，预览里给出个数。Essential Macleod 自带的材料里有几个这样的点，refractiveindex.info 的一些表格也有；它们是生成表格的拟合留下的残余。负的消光系数意味着增益，因此所有计算在这类点处都按 `k = 0` 处理，材料编辑器的 n,k 网格也会标出该行。

**浏览 RII**：打开 refractiveindex.info 浏览器，从在线数据库中选择（首次获取材料时需要互联网连接）。该材料被添加到你选择的用户目录中，之后即存在于本地。

**新建目录**：创建一个空的用户目录来组织你自己的材料。

**复制**：将所选目录（来自任何来源）复制到一个新的、可编辑的用户目录中。**复制到目录**将单个材料复制到一个用户目录中，这是制作只读材料的可编辑变体的方式。

## 创建材料

打开一个用户目录并选择**新建材料**。**n 与 k** 页存放光学数据；在那里选择一种数据类型：

1. **列表（Tabular）**：粘贴或输入一个 `λ, n, k` 表格。你可以直接从电子表格粘贴（Ctrl+V），网格支持键盘导航、排序与逐单元格编辑。
2. **公式（Formula）**：选择一种色散公式（Sellmeier、Cauchy、Conrady、Schott、Herzberger 及其他标准形式），输入其系数，并可选择添加一个 `λ, k` 表格以表示吸收。公式会被完整渲染，以便你确认其约定。Cauchy 与通用 Sellmeier 形式可添加任意多项；保存材料时，保持为零的项会被丢弃。

一个实时的 n/k 图表会随你的编辑更新，你设置的波长范围界定了材料有效的边界，也是图表显示的范围。图表下方可输入一个波长以读取该处的 `n` 与 `k`，并有一张采样表列出曲线的数值。只读材料的图表下方也有同样的查询框与表格。在公式没有有限值的波长处，预览不给出 `n`。

TFStudio 无法计算的材料绝不会被赋予一个替代折射率。TFStudio 没有求值方法的公式，或者没有任何一行同时包含波长和 `n` 的表格，都会使该材料不可用：使用它的设计会把它列在不可用的材料中，在你替换它之前计算会被阻止。保存设计时这类定义按原样保留，其中的内容不会丢失。

### 表格点之间

表格对点与点之间的波长不作任何说明，因此每个列表化的 `n` 与 `k` 列都带有一条在那里读取它的规则。网格下方的控件提供两种：

- **保形三次插值**（PCHIP），新材料的默认值。曲线穿过每一个提供的点，并保持在每一对括值点的值范围之内，因此一个非负的 `k` 表格不会因插值过冲而获得光学增益；曲线处处有斜率，这正是相位与色散计算所需要的。
- **线性**，点与点之间取直线。这是 Essential Macleod 与 TFCalc 评估表格的方式，从它们导入的材料保持这一规则，因此用这类材料导入的设计能复现它在原程序中给出的数值。斜率在每个点处突变；GD/GDD 窗口会在这些位置断开曲线，而不是把跳变画成连续线。

规则属于材料而非某个窗口，因此它作用于用该材料所做的每一次计算，随嵌入设计的材料一起传递，也正是两种程序在测量点之间产生分歧之处。两种规则都不会添加表格本身没有的信息：当结果取决于测量点之间 `n(λ)` 的曲率时，平滑色散拟合才是诚实的模型。在列表范围之外，两种规则都保持最近端点的值恒定。

### 平滑色散拟合

一个可编辑的列表材料可以存储一个显式的平滑拟合，用于需要高阶导数的计算。透明材料可对 `n` 使用 Cauchy 或一到三项的 Sellmeier 模型；当表格包含足够多的正值时，`k` 使用非负的 Urbach 形式，否则保持为零。金属可使用耦合的 Drude 或 Drude-Lorentz 介电模型，该模型同时拟合 `n` 与 `k`。

拟合有自己的波长范围，由**拟合起**与**拟合止**设定，与表单顶部的有效范围分开。它以膜系的计算范围为起点（前提是表格覆盖到那里），因为拟合必须在那里准确；在拟合范围之外直接读取数据表。拟合在数据表内部结束的地方，`n` 与 `k` 从拟合值跳变到数据表值，跳变量就是拟合在该处的残差。拟合面板会给出两端各自的跳变量，GD/GDD 窗口与材料色散窗口会在该处断开曲线，而不是把跳变画成连续线。在数据表第一行或最后一行结束的拟合没有跳变。该范围与拟合一起存储，下次打开该材料时会恢复。

如果范围跨越的光子能量超过一个数量级，窗口会明确指出。没有一个模型能同时描述自由电子行为、带间吸收边和透明区，因此覆盖整个范围的拟合处处都差；此时窗口会给出膜系的计算范围作为替代，并附上它能达到的残差。

选择**拟合（Fit）**或**重新拟合（Refit）**来计算它。TFStudio 会显示 `n` 与 `k` 的 RMS 与最大残差，以及一张残差图。在使用该模型之前请检查这些误差。对数据表做的 Cauchy 或 Urbach 拟合还会给出每个系数及其标准误差。对于金属模型，窗口还会指出停在模型自身限制上的参数，以及在该范围内对 `n` 的改变小于残差的振子：二者都不是对材料的测量，而仅凭残差看不出这一点。拟合不会在后台静默创建。它存储在材料上，随嵌入式用户材料一起携带，并在其源表格发生变化时自动移除。内置材料保持只读；在拟合不同表示之前，请先将其复制到一个用户目录。

### 力学常数

**力学**页存放材料在色散之外的属性。

| 常数 | 单位 | 含义 |
| --- | --- | --- |
| 杨氏模量 | GPa | 受拉时的刚度。 |
| 泊松比 | | 被拉长时的横向收缩。 |
| 线膨胀系数 | ppm/K | 每开尔文的伸长量。 |
| dn/dT | ppm/K | 折射率随温度的变化。 |
| 本征应力 | MPa | 该材料成膜时自带的应力，拉应力为正。 |
| 参考温度 | °C | 本征应力所对应的沉积温度。 |
| 表面能 | J/m² | 新生表面所需的能量，也就是开裂或脱膜所付出的代价。 |

两个温度系数都按 ppm/K 输入，与各类手册的印法一致：每开尔文 0.00000055 的线膨胀系数输入为 0.55。

每个输入框彼此独立，任何一个都可以留空，留空表示未知而不是零：某种材料如果测过应力却从未查过模量，它就只带着应力。这些常数属于材料本身，因此随它进入用户目录、进入副本，也进入嵌入了它的设计文件。从 AGF 目录导入的玻璃会带着已填好的线膨胀系数、杨氏模量与泊松比，这就是这类文件所携带的部分。

## 如何阅读它

对于内置或导入材料，n/k 图表显示实部折射率 `n`（左轴），以及（当存在时）消光系数 `k`（右轴，虚线）。属性面板在来源提供时列出 d 线折射率、阿贝数、密度与波长范围，并在材料基于公式时列出色散公式与系数。一个具有平坦、零 `k` 的材料在所绘范围内是非吸收的。它的**力学**页只列出该目录给出的常数，一个也不多；什么都没有给出的材料会直接说明。

目录被保存到你的 TFStudio 数据文件夹的 `Materials` 子目录中，并在各会话之间持久存在，因此一个导入或手工构建的材料在你下次打开应用时仍然可用。
