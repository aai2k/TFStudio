材料编辑器保存 TFStudio 所知的每一种折射率来源。每种材料给出 $n(\lambda)$ 和 $k(\lambda)$，吸收材料的 $k > 0$，应用中的每个材料选择器都从这里读取。材料按来源分在各目录中：

| 目录 | 来源 | 可编辑 |
|---|---|---|
| **内置** | 22 种常用光学材料。 | 只读 |
| **AGF** | 数据文件夹 `Materials\agf` 子文件夹中的 Zemax `.agf` 文件。 | 通过文件 |
| **用户** | 你创建的材料和目录。 | 是 |
| **RefractiveIndex** | 从 refractiveindex.info 导入的材料。 | 是 |
| **此设计** | 打开的设计所用的材料；随设计文件带来、而本机没有任何目录包含的材料只列在这里。 | 只读，**复制到我的目录…** |

## 计算的量

图中左轴为 n，右轴虚线为 k。图下方输入一个波长即可读出该处的 n 和 k，采样表列出曲线的数值。属性面板在来源给出时显示 d 线折射率、阿贝数、密度和波长范围，以及公式材料的公式和系数。平滑拟合显示 n 和 k 的 RMS 与最大残差及残差图，Cauchy 或 Urbach 拟合还给出每个系数及其标准误差。

## 控件与设置

**目录选择器**：一个目录及其材料数，或**全部目录**。旁边的 **⋯**：所选目录的**重命名**、**复制**和**删除**，以及**新建空目录…**和**从 Zemax AGF 新建目录…**。**搜索**在所选目录内按名称筛选。

**添加**把材料放入你自己的某个目录：**空白材料**、**从 refractiveindex.info 添加…**，或**从 TFCalc、Macleod 或 OptiLayer 文件导入…**。空白材料在所选目录属于你时放入该目录，否则放入你唯一的目录、你选择的目录，或新建的**我的目录**。其 ID 在首次保存时由名称生成，此后不再改变，因为设计按 ID 引用它。**复制到我的目录**为任何材料生成可编辑的副本。

材料有两页。**n 与 k** 选择数据类型：

1. **表格**：$\lambda$、$n$、$k$ 表，可输入或从电子表格粘贴，并带有点与点之间波长的读取规则（[见下文](#表格点之间)）。
2. **公式**：色散公式及其系数，以及可选的 $\lambda$、$k$ 表。公式按来源分组，各用来源自己的编号：Zemax（Schott、Sellmeier、Herzberger、Conrady 等）、通用级数与 OptiLayer 形式，以及 refractiveindex.info 的九种公式。Cauchy、通用 Sellmeier 和级数可以添加任意多项；为零的项在保存时删去。

顶部的有效范围限定材料成立的范围以及图所覆盖的范围。

**力学**页保存[应力](/zh/analysis/stress/)和[环境](/zh/design/environments/)温度模型所用的常数：

| 常数 | 单位 | 含义 |
|---|---|---|
| 杨氏模量 | GPa | 拉伸下的刚度。 |
| 泊松比 | | 拉伸时的横向收缩。 |
| 线膨胀系数 | ppm/K | 每开尔文的伸长。 |
| dn/dT | ppm/K | 折射率随温度的变化。 |
| 本征应力 | MPa | 薄膜沉积时带有的应力，张应力为正。 |
| 参考温度 | °C | 该应力所对应的沉积温度。 |
| 表面能 | J/m² | 新表面的代价，即裂纹或脱层所付出的能量。 |

两个温度系数都按目录的印法以 ppm/K 输入：每开尔文 0.00000055 输入为 0.55。空框表示未知，各项计算会说明缺少它时如何处理。这些常数随材料进入副本、用户目录和设计文件。AGF 玻璃导入时带有其膨胀系数、杨氏模量和泊松比。

目录保存在数据文件夹的 `Materials` 子文件夹中。**全部刷新**，即标题栏左侧的圆形箭头，读取应用运行时复制进来的目录文件和 AGF 文件，并重新读取项目文件夹中在 TFStudio 之外修改的设计文件。打开的窗口按读到的内容重新计算；优化、综合和拟合运行不会重复。未保存的编辑保留，除非其文件此后又被保存过；此时载入文件，Ctrl+Z 可找回这些编辑。

## 设计中的材料

- 设计按目录和 ID 引用每种材料，其文件保存每种非内置材料的副本。你创建的目录有自己的 ID，因此另一台电脑上同名的目录是另一个目录。
- 只要本机某个目录包含该材料，设计就按该目录计算：在这里的编辑会改变所有使用它的设计，保存设计时副本随之更新。
- 只有在本机没有目录包含该材料时才使用副本：来自另一台电脑的设计、已删除的材料或目录，或本机目录在同一 ID 下有不同材料。它列在**此设计**下；**复制到我的目录…**在新 ID 下生成可编辑的材料，设计保留其副本，直到你为其膜层选择新材料。
- 当本机目录在同一 ID 下有不同材料时，该目录的材料不会提供给设计的膜层。已删除材料的 ID 不会分配给其目录中的新材料。
- TFStudio 无法计算的材料（没有求值器的公式，或没有一行同时含波长和 n 的表格）绝不会被赋予替代折射率：设计把它列为不可用，计算停止，直到它被替换。保存时按原样保留其定义。
- 公式按原样求值，n 没有下限。在公式给不出实的正 n 的地方，例如极点或 $n^2$ 为负处，材料没有折射率，设计在这些波长上没有结果。

## 导入

**从 Zemax AGF 新建目录**：AGF 文件保存的内透射率转换为 $k(\lambda)$（[理论](#理论)）。TFStudio 不能求值其公式编号的玻璃会被略去，导入信息会列出它；启动时自动读入的文件没有窗口可以报告，因此手动导入一次即可看到略去了什么。

**从 TFCalc、Macleod 或 OptiLayer 文件导入…**，一次可混合选择：

| 程序 | 文件 |
|---|---|
| TFCalc | `MATERIAL` 和 `SUBSTRAT` 文件夹中的 `.mat` |
| Essential Macleod | 材料数据库文件夹中的 `.tfx`，或 File → Export → Material 写出的 `.mtx` |
| OptiLayer | `.lm` 和 `.sub` |

- 对话框列出每种材料及其程序和数据类型，并预览高亮的一项；取消勾选不需要的，并选择目录。
- TFCalc 和 Essential Macleod 文件不记录波长单位。默认为纳米；`.tfx` 位于其数据库文件夹中时读取该数据库自身的设置；预览位置不对时可用开关改为微米。
- 公式在 TFStudio 有同样形式时保留其形式。TFStudio 没有的 TFCalc 形式（Hartmann、Drude 以及所有 k 公式）在文件给出的范围内采样为表格。Essential Macleod 的内透射率表会被略去，其 k 列按原样使用；其材料库的压缩文件无法读取。
- k 小于零的表格点（某些表格背后拟合留下的痕迹）按原样导入并标出；所有计算在该处取 $k = 0$，因为负的 k 意味着增益。

**从 refractiveindex.info 添加…**：在线数据库，首次需要联网。表格页面带有其全部行；公式页面以该公式导入，带有其给出的范围和页面的 k 表，在该范围之外按公式本身求值。浏览器可用图或表显示页面，读出某一波长的 n 和 k，并指出公式页面在其范围内何处没有实的 n。

## 表格点之间

每个表格的 n 列和 k 列各带有一条在点与点之间读取的规则，在表格下方设定。规则属于材料，因此作用于每项计算，并随嵌入的材料一起传递。在表格之外，两种规则都保持最近端点的值。

- **保形三次插值**（PCHIP），默认：经过每个点，并保持在每对相邻点的取值之间，因此非负的 k 表不会出现过冲，而且处处有斜率，这是相位和色散计算所需要的。
- **线性**：点与点之间连直线。从 TFCalc 或 Essential Macleod 文件导入的材料保留这一规则，因此导入的设计给出与原来相同的数值。其斜率在每个点处跳变，群延迟 / GDD 窗口会在那里断开曲线。

两种规则都不会添加表格中没有的信息。当结果取决于测量点之间 $n(\lambda)$ 的曲率时，平滑拟合才是如实的模型。

## 平滑色散拟合

可编辑的表格可以带一个平滑拟合，供需要高阶导数的计算使用：n 用 Cauchy 或一到三项 Sellmeier，表格中正值足够时 k 用非负的 Urbach 形式，否则 $k = 0$；金属则用同时拟合 n 和 k 的 Drude 或 Drude-Lorentz 模型。

- **拟合起 (nm)** 和**拟合止 (nm)**设定其范围，与有效范围分开。在表格覆盖到的情况下，它从设计的计算范围开始；范围之外读取表格本身。拟合在表格内部结束处，n 和 k 按该处的拟合残差跳变：面板会给出这一跳变，群延迟 / GDD 和材料色散窗口在该处断开曲线。
- 跨越超过十倍光子能量的范围会被提示，因为没有一个模型能同时描述自由电子、带间吸收边和透明区，此时会建议设计的范围并给出其能达到的残差。
- **拟合**或**重新拟合**进行计算。对金属模型，面板还会指出停在其限值上的参数，以及使 n 的变化小于残差的振子：两者都不是对材料的测量。
- 拟合保存在材料上，随材料传递，其表格改变时自动删除。要拟合内置材料，先把它复制到用户目录。

## 理论

拟合模型，$\lambda$ 以 µm 计，$E = 1.239841984 / \lambda$ 以 eV 计：

$$
\begin{aligned}
\text{Cauchy:} \quad & n = A_0 + \frac{A_1}{\lambda^2} + \frac{A_2}{\lambda^4} + \cdots \\
\text{Sellmeier:} \quad & n^2 = A + \sum_j \frac{B_j \lambda^2}{\lambda^2 - C_j} \\
\text{Urbach:} \quad & k = k_0 \exp\!\left(\frac{k_b}{\lambda} + k_c \lambda\right) \\
\text{Drude-Lorentz:} \quad & \varepsilon = \varepsilon_\infty - \frac{E_p^2}{E^2 + i\Gamma E} + \sum_j \frac{f_j}{E_j^2 - E^2 - i\gamma_j E} \\
& n + ik = \sqrt{\varepsilon}
\end{aligned}
$$

金属模型是 Rakić 的 Lorentz-Drude 函数，其符号按 TFStudio 的 $n + ik$ 约定取共轭；单纯的 Drude 模型没有振子项。只有在显著减小残差时才增加一项，因此拟合跟随的是色散而不是表格的舍入。

AGF 玻璃在厚度 $d$ 上的内透射率 $\tau$，在每个表列波长处换算为（Beer–Lambert）：

$$
k(\lambda) = -\frac{\lambda}{4\pi d} \ln\tau(\lambda)
$$

位于玻璃数据短波端起始连续行中的 $\tau$ = 0 是其紫外截止：按该行厚度上的 $\tau$ = 0.0005 读取（最后一位印刷数字的一半）：这是印刷的 0 所允许的最小吸收，因此比目录更薄的样片在该处仍有部分光透过。其他位置的 $\tau$ = 0，例如部分旧 Schott 玻璃在 1.06 µm 处的行，表示没有数据，该行被舍去。
