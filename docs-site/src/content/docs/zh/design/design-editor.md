设计编辑器是构建镀膜的地方：膜层、膜层的材料和厚度、基底和介质，以及正在设计的表面。其他所有窗口都读取这一个设计，因此这里的修改会立即反映到各处。一个设计带有入射侧的**正面镀膜**和出射侧的**背面镀膜**；在两个标签页中，紧贴基底的膜层都列在第一行。

## 计算的量

四个厚度列以不同单位显示同一膜层；编辑其中任何一列，其余各列随之更新。以 nm 计的物理厚度是存储的值。

| 列 | 含义 |
|---|---|
| **nm** | 物理厚度 d |
| **OT** | λ₀ 处的光学厚度 |
| **QW** | λ₀ 处的四分之一波数 |
| **FW** | λ₀ 处的全波数 |

表格下方的**堆栈几何**以材料颜色画出入射介质、正面镀膜、基底、背面镀膜和出射介质，并给出每一面的层数和总物理厚度。

## 控件与设置

### 设置

**参考 λ₀ (nm)**：OT、QW 和 FW 列所用的波长。修改它时，每层保持其四分之一波数，物理厚度按比例改变。

**基底**：材料和以 mm 计的厚度。**入射介质**和**出射介质**：通常为空气；浸没或胶合的元件可选任意目录材料。

**表面**和**忽略另一面**，位于顶部栏中：优化器移动哪一层镀膜以及每个窗口评价什么，详见[表面与评估模式](/zh/design/evaluation-modes/)。

**在照明锥上取平均**，默认关闭：每个 R、T 和 A 都在入射角周围的一个角度锥上取平均，同时作用于每个窗口和每一行评价函数。半角旁显示其 NA、f 数和全孔径。锥内的强度分布为**均匀**、**朗伯**或按表格给出的**用户自定义**，**网格点数**是角度数的起点（[照明锥](#照明锥)）。

**环境**：在有多个[环境](/zh/design/environments/)的设计上，一个两侧带箭头的下拉列表选择设置所显示的环境。此时介质、基底、锥角、**忽略另一面**和**温度**都是该环境的；在环境 2 及以后，修改只为该环境设置字段，字段带有环境编号和一个可恢复沿用的叉号，沿用时则显示 **= 环境 1**。λ₀ 和**表面**属于设计本身，膜层表在每个环境中都是同一份配方。

### 膜层表

每一行是一层：材料、四个厚度列、锁定开关，以及移动、复制或删除它的按钮。锁定层在每次优化和综合运行中保持厚度不变。工具栏可添加和移除膜层、反转顺序、锁定或解锁整个面，并把堆栈复制到另一面。

**+ 膜层**在所选行下方（或在底部）添加一层并选中它。新层复制其相邻层另一侧、相隔两行的那一层，因此高低交替的膜层得以延续。若没有这样的层，或它与相邻层是同一种材料，新层为 λ₀ 处的四分之一波：在折射率高于 SiO2 的材料旁为 SiO2，在其他材料旁为 TiO2，空的面上为 SiO2。

| 输入 | 作用 |
|---|---|
| 厚度单元格上的箭头，滚轮作用于带边框的单元格 | nm 和 OT 列步进 1 nm，QW 列 0.1，FW 列 0.025；Shift ×10，Ctrl ×0.1。按住时持续步进。选中多行时全部步进，各按其自身的光学厚度。 |
| 方向键 | 在单元格之间移动，从行号经材料到 FW。 |
| 在厚度上输入数字、Enter 或 F2 | 编辑该单元格。 |
| 在材料上双击、点击箭头、输入字母或 Enter | 打开材料选择器，输入的字母用于搜索。 |
| Shift+方向键、Shift 单击、拖动 | 选择一个矩形区域的单元格；Escape 取消。Delete 和步进作用于其覆盖的每一行。 |
| 在行号上单击、Shift 单击、Ctrl 单击 | 选择一层、一段，或加选一行。 |
| Insert、Shift+Insert、Delete | 在当前行上方或下方添加一层；删除所选行（锁定层除外）。 |
| 在单元格上 Ctrl+C、Ctrl+V | 复制为制表符分隔的文本；向右下方粘贴，数字按所在列的单位读取，材料列上的名称先在设计的材料中查找，再在目录中查找。在矩形区域上数值会重复以填满它。 |
| 在行号上 Ctrl+C、Ctrl+V | 复制并粘贴整层，包括材料和锁定；粘贴到单元格上时插入到其所在行的下方。 |

一整串步进或一次粘贴是一个 Ctrl+Z。粘贴不改变锁定层，丢弃超出最后一行的数值，并忽略既不是数字也不是材料名的文本。

### 工具

表格上方的**工具…**包含作用于整个设计或一个面的编辑；每次编辑是一个撤销步骤。

- **替换材料…**：用另一种材料替换介质、基底或膜层中的任意材料。**保持光学厚度 (n·d)** 会调整每个被更改的膜层，使其在 λ₀ 处的 n·d 保持不变。
- **取整 / 量化厚度…**：把每个未锁定膜层取整到**小数位数**、**控制步长 (nm)** 或 λ₀ 处的 **QWOT 增量**，并显示**前评价函数**和**后评价函数**。
- **扰动厚度…**：在**最大扰动 (±%)** 内对每个未锁定膜层施加一次随机扰动；预览保持同一样本，直到**重新洗牌**。
- **以表格形式复制堆栈**：该面的材料和厚度，以制表符分隔的文本复制。
- **将所选折叠为 Herpin 等效层…**：把所选的对称、无损膜层组替换为 λ₀ 处的一个等效层，原组保存在该层中，因此**展开 Herpin 层**可精确恢复。等效只在 λ₀ 和正入射下成立。
- **将镀膜保存到库…**：把正面或背面堆栈保存到[镀膜库](/zh/design/coating-library/)。

## 照明锥

- **网格点数**是起始数目。TFStudio 把角度数加倍，直到连续两次加倍各自使 R、T 或 A 的变化小于 0.01 %，采用最后一次加倍之前的数目，并在超过 480 之前停止加倍。一次吻合不够：两个粗的数目可能同样漏掉一个尖峰。宽带减反射膜在网格点数或其两倍处即收敛；窄带滤光片需要更多，因为其通带在锥内移动。
- 评价函数在每一行采样的每个波长上确定角度数，因此只有尖锐谐振附近的波长才会用到更多角度；绘图窗口对整条曲线使用同一个数目。
- 超过掠入射的光线到达不了膜层。当入射角加上半角超过 90° 时，平均只覆盖到达表面的光线；当评价函数中有行处于这样的角度时，锥角设置会给出警告。
- 在锥角下仍会计算 s 和 p，但只是形式上的：每条光线有自己的入射面，因此只有偏振平均是严格的。

## 理论

厚度各列，n(λ₀) 为该层在 λ₀ 处折射率的实部（Macleod，第 3.1 节）：

```
OT = n(λ₀) · d
QW = 4 · n(λ₀) · d / λ₀
FW = n(λ₀) · d / λ₀
```

在锥角下，每个结果 Q 在到达表面的光线上取平均，α 为光线与锥轴的夹角，θ 为其入射角：

```
Q̄ = ∫∫ Q(θ) I(α) dΩ / ∫∫ I(α) dΩ
I(α) = 1 (Uniform),   cos α (Lambertian),   interpolated from the table (User-defined)
NA = n₀ sin α_max,     f-number = 1 / (2 NA)
```

锥上的积分化为对 θ 的一维积分，用 Clenshaw–Curtis 求积计算。窄通带在入射角 θ 下大约移动 Δλ/λ = sin²θ / (2 n*²)，n* 为其有效折射率（Macleod，式 8.39），这就是窄带滤光片需要很多角度的原因。镀膜层是相干的，按特征矩阵组合；整个元件的基底是非相干的，详见[表面与评估模式](/zh/design/evaluation-modes/)。

这些工具按如下方式改变每个未锁定的膜层，s 为控制步长，m 为 QWOT 增量，p 为以分数表示的扰动：

```
keep n·d:   d′ = d · n_old(λ₀) / n_new(λ₀)
step:       d′ = s · round(d / s)
QWOT:       d′ = q · round(d / q),    q = m λ₀ / (4 n(λ₀))
perturb:    d′ = d · (1 + p u),       u uniform on [−1, 1]
```

无损膜层组成的对称膜层组在 λ₀ 处的特征矩阵具有单层的形式（Macleod，第 7.2.2 节，式 7.5–7.10）：

```
M₁₁ = M₂₂ = cos γ,    M₁₂ = i sin γ / E,    M₂₁ = i E sin γ
E = √(M₂₁ / M₁₂),     d_eq = γ λ₀ / (2π E)
```

E 为 Herpin 折射率，γ 为等效相位，取最接近该组总相位的分支。在 λ₀ 处位于截止带中的膜层组（|M₁₁| > 1）没有实的 E，会被拒绝。
