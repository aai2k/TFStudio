规格保存镀膜必须满足的要求，形式为合格/不合格检查，例如“在 450–650 nm 上平均 $T \ge 99\,\%$”或“不超过 30 层”。它是要求清单，与优化器最小化的[评价函数](/zh/design/merit-function-editor/)分开；**生成评价函数**把清单转为评价函数，使运行恰好瞄准所规定的内容。检查随设计保存。

## 计算的量

每一行在目标旁显示它在设计上读出的值，以及绿色勾或红色叉；未通过的行另加一行说明原因。只有开启的每一行都通过时，横幅才变为绿色，并统计通过的行数。

| 类型 | 读取 | 单位 |
|---|---|---|
| **T / R / A at λ** | 单一波长处的通道值。 | % |
| **波段平均 T / R / A** | 通道在波段上的平均值。 | % |
| **最小/最大** | 通道在波段内的最低或最高值，因此平均值良好但中间有窄尖峰时仍判为未通过。 | % |
| **加权积分** | 按光源和探测器加权的通道值，例如 Tvis 或 Tsol。 | % |
| **中心 λ** | 波段内峰或陷波的波长。 | nm |
| **FWHM** | 峰或陷波在某一水平处的宽度，默认为峰值的一半。 | nm |
| **边缘 λ** | 通道在峰的一侧穿过该水平的位置，即长通或短通滤光片的边缘。 | nm |
| **总厚度** | 正面、背面或两面的物理厚度。 | nm |
| **膜层数量** | 正面、背面或两面的层数。 | 个 |
| **相对曲线的峰峰误差** | 设计相对一条实测 T、R 或 A 曲线的误差的峰峰值，增益平坦滤光片按此规定。 | dB |

变暗并标有 ≈ 的值是在按检查自身**步长**的数值算出之前，按默认步长读出的。优化器运行期间，窗口保持默认步长，直到运行停止。

## 控件与设置

每一行只显示其类型用到的字段：**通道**、波长或 **λ 起**与 **λ 止**、**入射角**、**偏振**，以及峰的**方向**（最大或最小）。FWHM 与边缘 λ 另有**水平**，即峰值的 0 到 1 之间的分数；边缘 λ 还有**边缘**，取峰的左侧或右侧。**比较**为 ≥、≤、= ± **容差**，或介于**低**与**高**之间。

**步长**：检查搜索或采样其波段的精细程度。

- 在峰上（最小/最大、中心 λ）：搜索步长，默认 1 nm，最细 0.001 nm。相距不到约两个步长的峰可能被读作一个。谷上的检查按设计的干涉条纹搜索，没有步长。
- 在波段平均或积分上：**自动**按设计的干涉条纹取网格，点距不超过 2 nm（[波段采样](/zh/design/operands/#波段采样)），可能跨过很窄的通带；设定的步长即为网格步长。
- 在 FWHM 与边缘 λ 上：扫描步长，默认 1 nm，整个波段至少 301 个采样点。每个交点都在采样点之间精确求出，因此步长只决定找到哪个峰，以及能否看到紧挨着它的窄特征。

凡是读取该检查的地方都使用同一步长：报告、镀膜库、蒙特卡洛良率以及公差窗口的徽标。在宽波段上使用细步长，在所有这些地方以及每一次优化运行中都会变慢：0.01 nm 时，覆盖几百纳米的检查只需不到一秒，0.001 nm 时需要几秒。

**面**：厚度或层数累加的对象，正面、背面（对称设计中为正面的镜像）或两面。

**曲线**：峰峰误差检查读取设计的一条[实测曲线](/zh/data-exchange/measured-spectra/)，按该曲线自身的点与条件读取，而不是读取波段。

**环境**：在有多个[环境](/zh/design/environments/)的设计上，**全部**在每个开启的环境中判定检查，按编号选择的环境则只在其开启时在其中判定。检查在每个环境中都通过才算通过。各行显示当前环境中的值，不在当前环境判定的行显示短横线；横幅统计所有开启的环境，并指出未通过的检查在哪些环境中未通过。删除一个环境会删除只在其中判定的检查。

**预设**：常见镀膜的内置规格表，可**替换**或**追加**。**保存…**把列表保存为自己的预设，位于 Documents\TFStudio\Qualifiers，从**已保存**载入。预设不带环境。

## 生成评价函数

**生成评价函数**替换设计的评价函数，作为一个撤销步骤。每个检查变成一个权重为 0 的测量行，以及把它约束到目标的行：≥ 为 `OPGT`，≤ 为 `OPLT`，范围在低与高处各一行，等式则在目标 ± 容差处各一行。这样，评价函数恰好在检查通过时得到满足，运行停在容差的边缘而不是中心。没有容差的等式写成取其目标的测量行；但最小/最大和峰峰误差的行只对一侧计分，因此仍写成一对。每一行都带有其检查的步长和环境。

- 作用于优化器所移动镀膜的**总厚度**写成一行 `TT`，范围则写成 `TT` 的最小值与最大值。
- 峰峰误差检查把其曲线写成一个权重为 0 的数据块、一行针对它的 `PPEF` 以及比较行（[曲线](/zh/design/operands/#曲线)）。
- **FWHM**、**边缘 λ**、**膜层数量**、作用于另一面的厚度以及曲线不在设计中的峰峰误差检查不写入任何行；按钮旁的说明会列出它们。

## 理论

$C(\lambda)$ 为以分数表示的通道值，波段平均与积分为

$$
\begin{aligned}
\bar{C} &= \frac{\int C\,d\lambda}{\lambda_2 - \lambda_1} \\
C_w &= \frac{\int S(\lambda)\,D(\lambda)\,C(\lambda)\,d\lambda}{\int S(\lambda)\,D(\lambda)\,d\lambda}
\end{aligned}
$$

积分在波段上进行，$S$ 为积分的光源，$D$ 为探测器。FWHM 与边缘 λ 从按中心 λ 方式找到的峰 $\lambda_p$ 出发，其值为 $C_p$。水平为 $L$ 时，交点值为

$$
\begin{aligned}
C_x &= L\,C_p && \text{峰（最大）} \\
C_x &= C_p + L\,(1 - C_p) && \text{陷波（最小）} \\
\text{FWHM} &= \lambda_\text{right} - \lambda_\text{left}
\end{aligned}
$$

$\lambda_\text{left}$ 与 $\lambda_\text{right}$ 是 $\lambda_p$ 两侧 $C$ 首次达到 $C_x$ 的波长，各自在扫描采样点之间用二分法求出。边缘 λ 为 $\lambda_\text{left}$ 或 $\lambda_\text{right}$。$L$ 限制在 0.001 到 0.999 之间，因为水平为 0 或 1 时没有交点。
