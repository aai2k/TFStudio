**规格说明**窗口将你的设计*要求*保存为一组 PASS/FAIL（通过/失败）**限定符**："在 450–650 nm 上平均 T ≥ 99 %"、"在 550 nm 处 R ≤ 0.5 %"、"不超过 30 层"，等等。它是镀膜必须满足的、人类可读的契约，与优化器最小化的[评价函数](/zh/design/merit-function-editor/)分开保存。每个限定符都带一个容差来回答一个是/否问题，一个按钮将整个列表转换为评价操作数，以便你能够精确地朝着你所指定的内容进行优化。

每一行都针对活动设计进行评估，并在每次更改时重新计算，显示逐行判定与顶部的整体 PASS/FAIL 徽标。

平均与积分行在评价函数表格为同一行所用的网格上读取其波段，因此 **生成 MF** 为它写入的行读出同一个数值（[波段采样](/zh/design/operands/#波段采样)）。

峰上的**最小 / 最大**或**中心 λ**检查（T 或 A 的最大值、R 的最小值）有一个**步长**：默认 1 nm，也可选 0.1、0.01 或 0.001 nm。检查以该步长搜索其波段，**生成 MF** 会把同一步长写入它的评价函数行，因此两者读到同一个峰。相距不到约两个步长的峰可能被读作一个；更细的步长能把它们分开，但在宽波段上会使使用该评价函数的每次优化运行变慢。**FWHM** 与 **边缘 λ** 没有评价函数行：它们以 0.01 nm 搜索其波段，并在该步长的扫描样点之间用二分法精确求出电平的每个交点。以 1 nm 搜索的值立即显示，更精细的值算出后将其替换：在几百纳米的波段上每项检查不到一秒，波段越宽越久；窗口在优化运行期间实时更新时保持 1 nm，直到运行停止。参见[寻找峰或谷](/zh/design/operands/#寻找峰或谷)。

## 限定符种类

| 种类                | 询问                                                         | 单位 |
| ------------------- | ------------------------------------------------------------ | ---- |
| **λ 处的 T / R / A** | 单波长下的通道值与目标值比较。                               | %    |
| **T / R / A 平均**   | 波长范围内的带平均通道值。                                   | %    |
| **最小 / 最大**      | 一个通道在带上的最坏情况极值（捕捉尖峰）。                   | %    |
| **积分**            | 源 × 探测器加权度量（例如 T_vis、T_sol）。                    | %    |
| **中心 λ**          | 通带或边缘特征的中心波长。                                   | nm   |
| **FWHM**            | 一个特征在半高处的全宽。                                     | nm   |
| **边缘 λ**          | 通道穿过某个电平的波长（一个滤波边缘）。                     | nm   |
| **厚度预算**        | 正面、背面或两面的总物理厚度。                               | nm   |
| **层数**            | 正面、背面或两面的层数。                                     | 计数 |
| **相对曲线的峰峰误差** | 设计相对一条实测 T、R 或 A 曲线的误差的峰峰值，单位 dB。     | dB   |

## 设置

每一行只暴露适用于其种类的字段：

**种类**：上述限定符种类之一。**通道**选择 T、R 或 A（对于"在波长处"与"平均"种类固定）。**λ / 带**是单个波长或起始/结束范围。**AOI** 与 **pol** 设置光学种类的入射角与偏振。**步长**设置寻峰检查搜索其波段的精细程度（见上文）。

**比较与目标**：实际的测试。你可以要求 `≥`、`≤`、等式 `= ± tol`，或一个范围 `∈ [lo, hi]`，针对你输入的目标值（T/R/A 为百分比；几何种类为纳米或计数；峰峰误差为 dB）。

**面**：厚度预算或层数累加正面堆栈、背面堆栈（对称设计中为正面的镜像）或两面。新加入的检查从设计所镀的面开始；保存时未设定面的检查累加两面。

**曲线**：峰峰误差种类取设计在[实测光谱](/zh/data-exchange/measured-spectra/)中的一条曲线，代替波段、入射角与偏振；它在该曲线自身的点与条件下读取。这是增益平坦滤光片的规格所用的数值，即[操作数参考](/zh/design/operands/)中的 `PPEF` 操作数。**生成 MF** 会把该曲线以权重 0 的曲线块写入评价函数，再写入一行相对它的 `PPEF` 和比较行。

**预设**：放入一组为常见镀膜类型准备好的需求集，替换或追加到当前列表。你也可以将当前列表保存为你自己的可复用预设，并在之后加载回来。

## 如何阅读它

每一行都带一个彩色判定：通过时为绿色与对勾，失败时为红色与叉号，并在目标旁显示测量值。顶部的横幅仅当每个活动行都通过时才变绿，并报告总数中有多少正在通过。一个失败的行会添加一行简短摘要，解释偏差所在。

对于阻带抑制，优先使用**最小 / 最大**（最坏情况）种类：一个带*平均*可能通过，而一个窄共振却会尖峰穿过它。一旦你的需求就位，**生成 MF** 会将它们作为 `OPGT`/`OPLT` 评价操作数写入设计中：每个规格变成一个测量行外加引用它的目标（`≥` 或 `≤` 一个，范围或 `= ± tol` 两个，位于目标 − tol 与目标 + tol），检查通过时这些行恰好满足，因此[精炼](/zh/synthesis/refinement/)与综合工具直接朝着规格优化，并与它保持同步。优化运行会停在容差的边缘，而不是其中心；没有容差的等式写成位于其目标的测量行，但最小 / 最大或峰峰误差的等式例外：其行只计一侧，因此仍写成位于目标的一对。它写入的寻峰行带有检查的 **步长** 作为标志，因此评价函数与检查以同样方式搜索该波段。位于优化器所处理镀膜上的 **厚度预算**（表面为正面或对称的设计的正面、表面为背面的设计的背面、两面时的两面）会写成一个 `TT` 行，范围或 `= ± tol` 则写成 `TT` 最小值与最大值两行。**FWHM**、**边缘 λ**、**层数** 以及位于其他面上的厚度预算没有评价函数行：列表中有这类检查时，**生成 MF** 旁的说明会列出它们，也会列出曲线不在设计中的峰峰误差检查，因为它写入的评价函数不包含它们。规格与设计一起保存在项目文件中。
