同一个镀膜很少只在一个地方使用。一个减反射膜既镀在 BK7 透镜上，也镀在蓝宝石窗口上；一个滤光片既在空气中使用，也被胶合使用；夹具边缘的零件比中心的薄几个百分点。环境窗口列出一个设计在其中评分的各种条件，每个环境一列，评价函数同时在所有这些环境中为设计评分。它从功能区“设置”选项卡上的**环境**打开。

环境 1 就是设计本身：它的介质、基底和膜层列表。其他每个环境只设置与它不同的内容，其余沿用环境 1，因此对环境 1 的修改会传到所有未设置该字段的环境。

## 计算的量

在**评价函数**下，每一列显示**在此评分的行数**、这些行上的**该环境的 MF**，以及它**占 MF² 的比例**。表格下方的一行是所有开启环境上的 MF：即[评价函数编辑器](/zh/design/merit-function-editor/)显示、运行所最小化的数值。比例最大的环境就是拉高评价函数的环境。这些数值像评价函数表格一样跟随运行更新。

## 控件与设置

**添加**在末尾新增一个环境，各方面都沿用环境 1，并把它设为当前环境；**复制**复制当前环境及其设置的每个字段。**删除**移除当前环境以及只在其中评分的评价函数行，一次 Ctrl+Z 可把两者都恢复。环境 1 不能删除；最后一个其他环境删除后，设计保存为不带环境的设计。

**当前**，即列顶的单选按钮：设计编辑器的设置所显示和编辑、评价函数表格所显示数值的环境。它不改变设计，也不保存；[设计编辑器](/zh/design/design-editor/)设置中的下拉列表以及功能区上的**上一个**与**下一个**改变的是同一个环境。

**开启**：该环境是否在评价函数和运行中评分；关闭的环境保留其字段和行。**名称**：在列出环境的地方显示在编号之后。

在环境 1 的列中，各字段就是设计自身的字段。在其他列中，浅色的值沿用环境 1：点击它即为该环境设置自己的值；值旁边的叉号让它重新沿用环境 1。

| 字段 | 在环境 1 中 | 设置内容 |
|---|---|---|
| **入射介质**、**基底**、**基底厚度**、**出射介质** | 设计的介质和基底 | 该环境的介质和基底 |
| **入射锥角** | 设计编辑器的**在照明锥上取平均** | 开关和半角，或**准直**；未设置的部分取自环境 1 |
| **另一面** | **忽略另一面** | 单面设计只按其镀膜面评分（**忽略**）或按整个元件评分（**计入**） |
| **温度** | 给出厚度和 n、k 的温度，默认 20 °C | 计算膜层和基底所用的温度（[理论](#理论)） |
| **厚度系数**，每种膜层材料一个 | 无 | 该材料的每一层都变为相应倍数的厚度，如同腔体中的某个位置 |
| **替换的材料**，每种膜层材料一个 | 无 | 该材料的每一层都换成另一种材料，如同折射率在真空与空气之间漂移的薄膜 |

**缺少常数**，位于温度下方：在其他温度下计算、但缺少模型所需常数的材料，悬停可查看缺少的常数。这些常数来自[材料编辑器](/zh/design/material-editor/)。

## 跨环境评分

- 评价函数行在每个开启的环境中评分，除非它在评价函数编辑器中的**环境**单元格指定了某一个环境。[规格](/zh/design/specification/)检查按同样方式判定，在每个环境中都通过才算通过。
- 精炼、针法、渐变演化、结构优化器和深度合成在每个开启的环境中评分。针层进入每个环境时，换成该环境所替换的材料，厚度乘以该环境中的厚度系数 f，并处于该环境的温度。
- 综合窗口建议的最小厚度在各自的环境中读取每一行 MNT：在 TiO2 长成 0.8 倍厚度的环境中，MNT 20 nm 要求每层 25 nm。
- 蒙特卡洛良率、报告和公差窗口的判定计入每个开启的环境。分析窗口计算其**环境**下拉列表所指定的环境，默认为当前环境；**全部**在各窗口中的作用见各自的页面。
- 当设计给出了其薄膜应力所对应的温度（由[应力](/zh/analysis/stress/)窗口设定）时，处于其他温度的环境中的应力行读出按同样温差移动后的应力。

## 理论

在 N 个开启且有行在其中评分的环境上，MF_k 为环境 k 在其自身行上的评价函数，总评价函数为：

```
MF² = (1/N) Σ_k MF_k²
share_k = MF_k² / Σ_j MF_j²
```

在其他温度下，每一层在应用该环境的厚度系数和替换材料之后，按 H. Takahashi, *Appl. Opt.* **34**, 667 (1995) 的应变模型（式 14、15 和 18）计算，以 ΔT 代替论文中的 1 °C。附着在基底上的薄膜在其平面内跟随基底膨胀，并按其泊松比变薄；其堆积密度 P 随之变化，折射率也随之变化：

```
A = 2(α − β)(1 − 2ν)/(1 − ν) · ΔT
B = 2ν(α − β)/(1 − ν) · ΔT
P = (1 + 3βΔT) / (1 + 3βΔT + A)
d = d₁ (1 − B + βΔT)
n = (n₁ + (dn/dT) ΔT) P + 1 − P
```

ΔT 为该环境的温度减去环境 1 的温度，α 为基底的线膨胀系数，β、ν 和 dn/dT 为膜层材料的线膨胀系数、泊松比和 dn/dT，单位均为每开尔文；d₁ 和 n₁ 为该层在环境 1 温度下的厚度和折射率，并视其在该温度下完全致密。n 在每个波长上计算，k 保持不变，因为论文只对实折射率建模。

- 材料缺少 β 或 ν、或其基底缺少 α 的薄膜按无应变处理：A = B = 0，因此 d = d₁ (1 + βΔT)，n = n₁ + (dn/dT) ΔT，缺少的 β 或 dn/dT 按 0 计。
- 论文把整个滤光片当作一层薄膜处理，使用平均折射率和一个 dn/dT。TFStudio 对每一层用其自身材料的常数应用这些方程，并把 dn/dT 取为在所有波长上相同的一个值；这两点都是 TFStudio 的做法，而非论文的。
- 论文没有基底的模型。TFStudio 把基底折射率移到 n₁ + (dn/dT) ΔT，把厚度移到 d₁ (1 + αΔT)，k 保持不变；缺少常数时相应部分保持不变。介质不变。
