同一个镀膜很少只在一个地方使用。一个减反射膜既镀在 BK7 透镜上，也镀在蓝宝石窗口上；一个滤光片既在空气中使用，也被胶合使用；夹具边缘的零件比中心的薄几个百分点。**环境**窗口列出一个设计在其中评分的各种条件，每个环境一列，评价函数同时在所有这些环境中为设计评分。从功能区“设置”选项卡上的**环境**打开它。

环境 1 就是设计本身：它的介质、基底和膜层列表。其他每个环境只设置与它不同的内容，其余沿用环境 1，因此对环境 1 的修改会传到所有未设置该字段的环境。

## 设置

**添加**：在列表末尾添加一个环境，并把它设为当前环境。在你设置不同之处之前，它在所有方面沿用环境 1。

**复制**：添加当前环境的副本，包括它设置的每个字段。

**删除**：删除当前环境，以及只在其中评分的评价函数行。一次 Ctrl+Z 即可把二者一起恢复。环境 1 不能删除。删除最后一个其他环境后，设计重新只有一个环境，保存时也不再带有环境。

**当前**：每列顶部的单选按钮。当前环境是设计编辑器的设置中显示并编辑的环境，也是评价函数表格中显示每一行数值所在的环境。切换它不会改变设计：它不是一个撤销步骤，也不会被保存。[设计编辑器](/zh/design/design-editor/)设置中的下拉列表，以及功能区“设置”选项卡上的**上一个**与**下一个**，改变的是同一个当前环境。

**开启**：该环境是否在评价函数和运行中评分。关闭的环境保留它的字段和它的行。

**名称**：用来区分各个环境的名称，在列出环境的地方显示在编号之后。

**入射介质**、**基底**、**基底厚度**、**出射介质**：每个环境的介质和基底。在环境 1 的列中，它们就是设计自身的字段，与设计编辑器中的相同。在其他列中，浅色的值是环境 1 的值：点击它即为该环境设置一个自己的值，然后修改它。值旁边的叉号让该字段重新沿用环境 1。

**入射锥角**：该环境评分时所用的入射角锥，即它的开关和半角；关闭时显示**准直**。环境 1 的锥角就是[设计编辑器](/zh/design/design-editor/)中设计自身的**在照明锥上取平均**。其他环境设置锥角时，它未设置的部分取自环境 1 的锥角；把该环境设为当前环境后，设计编辑器的设置可以设置其余部分，即强度分布和网格点数。

**另一面**：单面镀膜的设计在该环境中如何评分：只评价镀膜面（**忽略**），或连同基底的另一面按整个元件评价（**计入**）。环境 1 的值就是设计的**忽略另一面**。两面都镀膜的设计在每个环境中都按整个元件评价。

**温度**：该环境所处的温度，单位 °C。环境 1 的温度是给出膜层厚度和材料 n、k 时的温度，在你修改之前为 20 °C。在其他温度下，膜层和基底按下文[温度](#温度)一节所述相对于它们发生变化。在带有环境的设计上，设计编辑器的设置显示当前环境的温度。

**缺少常数**：位于温度下方，列出该环境在其温度下计算时所用、但缺少模型所需常数的材料，悬停时显示每种材料缺少哪些常数。这些常数属于材料本身，在[材料编辑器](/zh/design/material-editor/)中输入。薄膜的材料缺少线膨胀系数或泊松比，或其基底缺少线膨胀系数时，该薄膜按无应变处理，见下文[温度](#温度)；缺少其他常数时按 0 计算。

**厚度系数**：膜层所用的每种材料各一行。在该环境中，这种材料的每一层都是原来的这么多倍厚，例如在膜层长得较薄的腔体位置。系数为 1 时膜层不变。

**替换材料**：膜层所用的每种材料各一行。在该环境中，这种材料的每一层都改用你选择的材料，例如折射率在真空与空气之间变化的薄膜。

环境 1 没有厚度系数，也没有替换材料：它的膜层就是当前的膜层列表。

## 温度

附着在基底上的薄膜不能像独立时那样在自身平面内膨胀：它随基底一起伸缩，并因此按其泊松比变薄或变厚。于是它的材料在薄膜中所占的比例发生变化，折射率随这一比例以及材料自身的 dn/dT 一起变化。TFStudio 按 H. Takahashi, *Appl. Opt.* **34**, 667 (1995) 的模型（式 14、15 和 18）计算处于其他温度的环境，以温度变化 ΔT 代替论文中的 1 °C。

ΔT 是该环境的温度减去环境 1 的温度。每一层在应用该环境的厚度系数和替换材料之后变为：

```
A = 2(α − β)(1 − 2ν)/(1 − ν) · ΔT
B = 2ν(α − β)/(1 − ν) · ΔT
P = (1 + 3βΔT) / (1 + 3βΔT + A)
d = d₁ (1 − B + βΔT)
n = (n₁ + (dn/dT) ΔT) P + 1 − P
```

α 是该环境基底的线膨胀系数，β、ν 和 dn/dT 分别是该层材料的线膨胀系数、泊松比和 dn/dT，单位均为每开尔文。d₁ 和 n₁ 是该层在环境 1 温度下的厚度和折射率，并假定薄膜在该温度下完全致密，与论文对离子辅助薄膜的假定相同。n 在每个波长上分别计算；k 保持不变，因为论文只对实折射率建模。

应变需要 α、β 和 ν。薄膜的材料缺少 β 或 ν，或其基底缺少 α 时，该薄膜按无应变处理：A = B = 0，因此 P = 1，厚度为 d₁ (1 + βΔT)，折射率为 n₁ + (dn/dT) ΔT；β 或 dn/dT 缺少时也按 0 计算。基底缺少 α 时厚度不变，缺少 dn/dT 时折射率不变。**缺少常数**一行会列出这些材料。

论文把整个滤光片当作一层薄膜处理：折射率取平均值，dn/dT 取各材料的加权平均，滤光片及其材料取同一个膨胀系数。TFStudio 则对每一层分别应用这些公式，使用该层材料自身的 β、ν 和 dn/dT，并把 dn/dT 取为在每个波长上相同的一个值；这两点是 TFStudio 的做法，不是论文的。

论文没有给出基底本身的模型。TFStudio 让基底的折射率按其自身的 dn/dT 变化，n = n₁ + (dn/dT) ΔT，厚度按其自身的膨胀变化，d = d₁ (1 + αΔT)，k 同样保持不变。介质保持不变。

合成运行放入的针式层也按同样方式变化：在每个环境中，它是该环境温度下由其材料构成的一层。合成窗口建议的最小厚度在读取每个 MNT 行时，按该行所在环境的温度取各层的厚度。

设计如果给出了评估薄膜应力的温度（即[应力](/zh/analysis/stress/)窗口设置的温度），那么在处于其他温度的环境中计分的应力行，读取的是该温度按同样的温度变化移动之后的应力。

## 如何阅读它

**评价函数**下方的各行对每个环境显示：其中评分的评价函数行数、它在这些行上自己的 MF，以及它占总值的比例。网格下方的一行是所有开启的环境上的 MF，即评价函数编辑器显示、运行所最小化的数值：

```
MF² = (1/N) Σ_k MF_k²
```

N 是开启且有行在其中评分的环境数，MF_k 是环境 k 在自己的行上的评价函数，按只有一个环境的设计那样计算。一个环境的比例是 MF_k² / Σ_j MF_j²，因此比例最大的环境就是把评价函数拉高的那个。这些数值与评价函数表格一样在运行中实时更新。

评价函数的一行在每个环境中评分，除非它在[评价函数编辑器](/zh/design/merit-function-editor/)中的**环境**单元格指定了其中一个。[精炼](/zh/synthesis/refinement/)、[针式变化](/zh/synthesis/needle/)（自动和手动）、[渐进演化](/zh/synthesis/gradual-evolution/)、[结构优化器](/zh/synthesis/structural-optimizer/)和深度合成都在每个开启的环境中评分。针式层放入每个环境时，取该环境替换后的材料，厚度乘以该材料的厚度系数；合成窗口建议的最小厚度按每个 MNT 行所在的环境计算：MNT 为 20 nm、TiO2 的厚度系数为 0.8 时，每层至少 25 nm。[规格说明](/zh/design/specification/)中的检查在每个开启的环境中判定，除非它的**环境**字段指定了其中一个；它在判定所在的每个环境中都通过才算通过。蒙特卡洛良率、报告和公差窗口的判定都统计每个开启的环境。[光学评估](/zh/analysis/optical-evaluation/)、[颜色评估](/zh/analysis/color-evaluation/)、[积分值](/zh/analysis/integral-values/)、[群延迟 / GDD](/zh/analysis/gd-gdd/)、[椭偏仪](/zh/analysis/ellipsometry/)、[导纳图](/zh/analysis/admittance/)、[电场](/zh/analysis/efield/)和[折射率分布](/zh/analysis/refractive-index-profile/)绘制图下方**环境**下拉列表所选的环境（默认为当前环境），或每个开启的环境。[蒙特卡洛](/zh/analysis/error-analysis/)和[系统偏差](/zh/analysis/systematic-deviations/)一次显示一个环境，即其下拉列表所选的环境；[层灵敏度](/zh/analysis/layer-sensitivity/)探测该环境或每个开启的环境上的评价函数。其他分析窗口绘制的是环境 1。
