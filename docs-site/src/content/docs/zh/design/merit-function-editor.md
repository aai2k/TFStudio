评价函数编辑器保存优化器所趋向的目标：一组操作数，每个操作数是带有目标、权重和比较的一个数值。评价函数（MF）表示设计与它们全体相差多远，精炼、针法、渐变演化和结构优化器通过移动膜层厚度来降低它。每种操作数类型、其参数和评分方式见[操作数参考](/zh/design/operands/)；本页说明这个窗口。

## 计算的量

- **MF**：所有行上的评价函数。**OMF**：只在光学行上的同一值，不计 `MNT`、`MXT`、`TT` 和 `STR`。MF 高而 OMF 低时，光谱没有问题，是某个约束在拖累它：膜层过薄或过厚、总厚度预算，或镀膜把基底弯得太厉害。
- 每一行的**当前**值及其**占 MF² 的 %**，即它在总值中所占的份额，因此拉高评价函数的行一目了然。
- 在有多个[环境](/zh/design/environments/)的设计上，**当前**是当前环境中的值，并在列标题中注明，例如**当前 (2)**，不在该环境中评分的行显示短横线；**占 MF² 的 %** 把一行在其评分的每个环境中的部分相加，MF 覆盖所有开启的环境。

自带**步长**的行在宽波段上计算可能需要几秒，因此先立即按默认步长显示，以淡色显示并加上 ≈，直到在窗口线程之外算出按其步长的数值。读取它的数学行也以同样方式标记；它带有权重时，MF、OMF 和**占 MF² 的 %** 也会标记。表格跟随优化运行时保持默认步长，直到运行停止。在入射锥角下，每一行都在线程之外计算。「取整 / 量化厚度」和「扰动厚度」对话框、[设计清理器](/zh/synthesis/design-cleaner/)、[历史](/zh/design/history/)中的 MF，[针法手动](/zh/synthesis/needle/#needle-manual)中的 OMF，以及[膜层灵敏度](/zh/analysis/layer-sensitivity/)中的排序，也以同样方式读取。

## 控件与设置

### 向导

表格上方的向导根据几个数值写出成块的行。其标题栏带有**优化**和**评价**徽标以及 MF 和 OMF，左侧的箭头可折叠表单。

- **预设**：类别（减反射、反射镜、分束器、边缘滤光片、带通或陷波、渐变、积分或最坏情况、自定义目标、曲线目标、颜色）、类别中的类型及其数值，波长范围在前。**自定义目标**写出一个你自己的目标：通道 T、R 或 A，单位 %、dB 或 OD，比较 `=`、`≤` 或 `≥`，一个值和一个范围。
- **角度与目标**：一个角度，或一段角度范围及其步数，偏振（类型自行设定偏振时不显示，例如偏振分束器），以及连续线或离散点。在有环境的设计上，**环境**使这些行只在一个环境中或在**全部**环境中评分；标题行和厚度限制在全部环境中评分。
- **厚度限制**：最小和最大膜层厚度（`MNT`、`MXT`）以及总厚度上限，各由一个复选框控制。

以 dB 或 OD 表示的自定义目标写出一种[以 dB 或光密度计的行](/zh/design/operands/#波段内的最坏情况)：dB 下的 T ≥ 为 `TDBMN`，dB 下的 T ≤ 为 `TDBMX`，dB 下的 R ≤ 为 `RDBMX`，OD 下的 T ≥ 为 `ODMN`，dB 下的 T = 则每个波长步长一行 `TDB`。只提供这些组合。切换单位时保持同一电平，例如 80 % 变为 −0.97 dB。

**起始行**保留其上方的行，并用生成的块替换从该行起向下的每一行；默认在最后一行之后，即追加。**生成**写出该块，作为一个撤销步骤。窗口关闭后表单仍保留其值。

#### 曲线目标

**曲线目标**取设计在[实测光谱](/zh/data-exchange/measured-spectra/)中的一条曲线而不是数值，其行采用曲线自身的入射角和偏振。设计上没有可用曲线时，会出现**打开“实测光谱”**。

- **曲线**写出**拟合…**为该曲线写出的曲线块，以 % 或 dB 计。
- **增益平坦**取设计上的一条目标损耗曲线，或以 dB 计、可导入或用**输入…**输入的放大器增益，以及滤光片的**插入损耗**和**峰峰误差**。它把目标写成以 dB 计、水平自由的曲线块，使该块评价形状而非水平；写出一行相对它的 [`PPEF`](/zh/design/operands/#曲线)，目标为峰峰值；再写出一行位于目标最高处波长的 `TDBMN`，目标为插入损耗的负值。两个值都从 0 dB 开始，即膜堆所能达到的最平坦形状与最小损耗。它还会取消勾选膜层最大厚度，因为这类滤光片常需要几微米厚的膜层。

综合工具会略去 `PPEF` 行，因为它的梯度只来自最差的两个波长，会使针法搜索停滞；之后运行一次[精炼](/zh/synthesis/refinement/)即可压低峰峰误差。

#### 颜色目标

**颜色**按颜色规格给出的角度对镀膜的颜色评分。**类型**为**反射颜色**或**透射颜色**；**目标**放置**照明体**、**观察者**和打开**颜色目标**窗口的**选择…**。

<!-- new:color-targets | two reflected-color targets on the a*, b* diagram, the selected one as a diamond beside the ring of the coating's color at its angle, the target list with Name, AOI and Pol on the left -->

窗口列出各目标，每个目标带有其颜色的色块、**名称**、**入射角 (°)** 和**偏振**，并有**添加**和**删除**；始终至少保留一个目标。新目标从镀膜在 0° 下的颜色开始。**色空间**设定所选目标的图：x, y, Y 对应 x, y 图；L\*, a\*, b\* 对应该目标 L\* 下的 a\*, b\* 平面；u′, v′, Y 对应 u′, v′ 图。在图上单击或拖动可移动目标的两个坐标并保持第三个；三个值也可直接输入。圆环标出镀膜在各目标角度下的颜色。**确定**保留列表，**取消**放弃更改。

**生成**为每个目标所用空间的每个坐标写出一行 `RCOL` 或 `TCOL`，采用其入射角和偏振，详见[操作数参考](/zh/design/operands/#颜色)。

### 表格

每行一个操作数，编辑方式与电子表格相同。

| 输入 | 作用 |
|---|---|
| 在数字上输入、Enter、双击、Backspace | 编辑单元格；Enter 提交并下移，Tab 右移，Escape 取消。 |
| 在**类型**上输入字母、Backspace、Enter 或点击箭头 | 打开按标签页分组的操作数选择器，并搜索该字母。 |
| 在列表单元格上 Enter、点击箭头或双击 | 打开其取值：**偏振**（可直接输入 `a`、`s`、`p`）、以 `#4 TMN` 形式显示的**操作数#**、`TT` 与 `STR` 的**比较**、**积分**、**曲线**、**颜色**和**照/观**。**操作数#**或**曲线**的第一项清空单元格。 |
| 在单元格上拖动、Shift、Ctrl | 选择矩形区域或加选单元格。 |
| 在单元格上 Ctrl+C、Ctrl+V | 复制为制表符分隔的文本；把一个值粘贴到整个选区，或从当前单元格起粘贴一块。列表单元格复制和接受其值的名称；复制的行按行粘贴。 |
| 在行号上单击、拖动、Shift、Ctrl | 选择行；从一行的第一个单元格按向左键移到行号，Ctrl+C、Ctrl+V 复制和粘贴整行。 |
| Ctrl+X、Ctrl+D、Delete、Insert、Shift+Insert | 剪切、复制一份和删除所选行（或所选单元格所在的行）；在上方或下方插入。 |
| 右键 | 以菜单给出同样的操作。 |

- 在有环境的设计上，**类型**之后是**环境**：**全部**，或该行评分所在的那一个环境。常数在任何环境中都不评分，显示短横线。
- **标志**在接受它的行上显示为**步长**：在寻峰的行上（例如 `TMX` 或 `MXWT`）为搜索步长，从 1（1 nm）到 4（0.001 nm）（[寻找峰或谷](/zh/design/operands/#寻找峰或谷)）；在波段平均、光谱目标、积分、颜色或 `*FLAT` 行上为其网格的最大步长（[波段采样](/zh/design/operands/#波段采样)）。
- 注释行接受在其上输入的文字，其**类型**单元格可把它变为一个操作数。
- **加载评价函数**和**保存评价函数**把整张表保存为一个命名的评价函数，供其他设计使用。

### 约束

`MNT` 和 `MXT` 约束一段膜层（从基底起编号）的厚度。范围可以超出最后一层，以覆盖综合之后添加的膜层；它只约束运行能够移动的膜层：锁定层不计入。`MXT` 行是膜层厚度唯一的上限；没有它，膜层会按评价函数的需要一直加厚。每个优化器以各自的方式处理这些约束，见[操作数参考](/zh/design/operands/#厚度与应力)。

## 理论

```
MF = √( Σ_i  w_i · (r_i / σ_i)²  /  W )
```

`w_i` 为权重。残差 `r_i` 对于等式为 `value − target`；对于不等式或约束是单边项，条件满足时为零；对于本身就是偏差的行（`TGT`、`*FLAT` 行、曲线块）则是该值本身。`σ_i` 使不同单位的行处于同一尺度，使以纳米计的偏差不会压倒反射率的偏差。`W` 为有值的行的权重之和，`MNT`、`MXT`、`TT` 和 `STR` 除外。OMF 是只在光学行上的同一求和。各项详见[操作数参考](/zh/design/operands/#各行如何合成评价函数)。
