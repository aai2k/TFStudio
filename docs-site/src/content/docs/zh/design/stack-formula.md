膜系公式用镀膜工程师手写的四分之一波简写建立镀膜。窗口打开时，设计的正面镀膜已用这种简写写出；输入公式，检查它给出的膜层与光谱，然后把它写入设计。

```
(H L)^8 H          17 层四分之一波反射镜
0.5H L H 0.5L      分数四分之一波
LHLHL6HLHLH        单字母连写，含一个 6H 间隔层
Hi Lo Hi Lo Med    自定义符号
```

## 计算的量

- 按[设计编辑器](/zh/design/design-editor/)编号的膜层，每层给出材料、$\lambda_0$ 处的 QWOT 和物理厚度 $d$ (nm)，以及层数和总厚度。
- 正入射下 s 与 p 平均的 T 与 R（百分比），范围 $0.5\,\lambda_0$ 到 $1.75\,\lambda_0$，并标出 $\lambda_0$。镀膜位于视为半无限的基底上，因此不计背面。背面镀膜从出射介质一侧观察。

无法解析的公式会显示错误及发现错误的字符位置，修正之前预览保持空白。

## 控件与设置

**参考 λ₀ (nm)**：把系数换算为厚度所用的波长。

**符号 → 材料**：为每个符号指定材料。各行按设计中材料在 $\lambda_0$ 处的折射率排序预先填好，H 最高、L 最低；空设计则为 H、L、M，分别对应 TiO2、SiO2 和 Al2O3。公式用到但尚未指定的符号会新增一行并带有材料选择器。SiO2 或 BK7 这样的材料名无需符号即可直接使用。

**从基底开始**，默认开启：写出的第一层是紧贴基底的那一层。关闭时，写出的第一层面向入射介质。

**入射介质**、**基底**和**出射介质**设定介质；**应用于**选择**正面**、**背面**或**两面**。在对称设计上，公式写在正面，背面镜像正面。

**追加**把膜层放在现有镀膜的外侧，**替换**用它们覆盖镀膜并设定介质与 $\lambda_0$，**新建设计**在所选项目文件夹中由公式新建一个设计。追加与替换都是一个撤销步骤，公式随设计保存。

## 公式语法

- 符号前的**系数**是该层在 $\lambda_0$ 处以四分之一波计的光学厚度：`2H` 是 H 的半波，`0.5L` 是 L 的八分之一波。不带系数的符号为一个四分之一波。
- `(...)^n` 把组重复 $n$ 次。组可以嵌套。
- 单字母符号可以连写，连写中间可以有整数系数：`LHLHL6HLHLH` 读作 `L H L H L 6H L H L H`。多字母符号和材料名之间仍用空格分开。
- 公式只写膜层。入射介质、基底和出射介质在介质栏中设置，带 `|` 介质的公式会被拒绝。

## 理论

系数为 $c$、折射率为 $n(\lambda_0)$ 的膜层（Macleod，第 3.1 节）：

$$
\begin{aligned}
d &= \frac{c\,\lambda_0}{4\,n(\lambda_0)} \\
\text{QWOT} &= \frac{4\,n(\lambda_0)\,d}{\lambda_0} = c
\end{aligned}
$$

$n$ 取材料在 $\lambda_0$ 处折射率的实部。在 $\lambda_0$ 处没有折射率的材料（越过其色散公式的极点）在该处没有四分之一波，公式会被拒绝，而不是建成 0 nm 厚。在 $\lambda_0$ 处，导纳为 $\eta$ 的四分之一波层把导纳 $Y$ 变为 $\eta^2/Y$，半波层则保持不变，这正是用这种写法表示的膜堆容易分析的原因。
