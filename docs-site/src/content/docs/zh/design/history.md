历史窗口按最新优先列出活动设计的每一个已记录状态，单击某一行即可把设计跳转到该状态。它就是 Ctrl+Z 与 Ctrl+Y（以及 F3 与 Ctrl+F3）逐步经过的时间线，因此跳转之后，撤销与重做从你选中的状态继续。

## 计算的量

| 列 | 含义 |
|---|---|
| **#** | 在时间线中的位置，#1 为最早。 |
| **状态** | **最早记录**、较早状态的**撤销到此**、**当前**，或较晚状态的**重做到此**。 |
| **膜层** | 该状态中前表面与后表面的层数之和。 |
| **MF** | [评价函数编辑器](/zh/design/merit-function-editor/)对该状态显示的评价函数；该状态没有启用的行时显示短横线。 |

变暗并标有 ≈ 的 MF 是在每一行都取默认步长时读出的，按各行自身步长算出的值一旦得出就会取代它。在锥角下，MF 在窗口线程之外计算，算出之前显示“正在计算锥响应…”。红色的 MF 表示该状态缺少某种材料。优化器运行期间不会在线程之外计算 MF。

## 控件与设置

单击某一行即可使其成为当前状态。标题栏给出状态总数和当前位置。

## 时间线长度与保存

- 每个设计最多保留 50 个撤销状态和 50 个重做状态。撤销之后的任何确定编辑都会丢弃重做状态。
- 精炼、针法与渐变演化在开始时记录一个状态，并把迭代作为预览显示，因此一次 Ctrl+Z 就能撤回整次运行。
- 重命名不属于时间线：撤销时保留当前名称。
- 本机这份 TFStudio 会保留时间线以及你尚未保存的编辑，因此下次打开时两者都还在；设计文件中只有你保存过的内容。如果在此期间该文件从别处被保存过（例如另一个已安装的版本），打开的是已保存的文件，你未保存的版本则成为最后一个撤销状态。
