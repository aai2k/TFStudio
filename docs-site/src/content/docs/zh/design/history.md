**历史**窗口列出了活动设计的每一个已记录状态，并允许你跳转到其中任意一个。它与支撑 Ctrl+Z 与 Ctrl+Y 的是同一条按设计划分的时间线，以可点击列表的形式呈现，是一种广义的撤销/重做。点击任意一行，设计就会回到那个精确状态；过去与未来会围绕你的选择重建，因此撤销与重做会从那里继续工作。

状态按最新优先排列，当前状态被高亮显示。

## 如何阅读它

| 列     | 含义                                                                   |
| ------ | ---------------------------------------------------------------------- |
| **#**  | 在时间线中的位置。                                                     |
| **状态** | 该行是最旧状态、较早的（撤销）状态、**当前**状态，还是较晚的（重做）状态。 |
| **层数** | 该快照处的层数量。                                                     |
| **MF** | 该快照处的评价函数值。                                                 |

层数与 MF 列让你能够发现设计在何处发生变化、以及评价函数如何移动：例如，一次综合运行添加层并降低评价函数的那一刻。未定义任何操作数的行在 MF 处显示短横线。

时间线每个设计最多保留 50 个状态，并随项目一起保存，因此你下次打开应用时历史仍在。精炼、针式与渐进演化各自在开始时会添加一个检查点，并将其迭代作为预览流式显示，因此一次 Ctrl+Z 就能撤销整个运行，而无需逐步回退每一次迭代。
