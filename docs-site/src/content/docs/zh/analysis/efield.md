电场（Electric Field）窗口在选定波长下，将镀膜内部的场相对深度绘制成图。它显示**场在堆栈内部的集中位置**，这是激光损伤工作的关键信息，因为承载最高场强的层通常是高功率光束下最先失效的层。它还能清楚地说明为什么某一层的厚度对性能如此重要。

在每个深度处，窗口将前向与后向行波叠加，并在各层边界处匹配。在高反射镜中，第一表面之外的场可达入射振幅的两倍，因为入射波与反射波几乎同相叠加。

## 设置

**波长（Wavelength）**：计算驻波分布所用的单一波长，单位为 nm。默认取设计的参考波长。

**AOI**：入射角，单位为度。

**物理量（Quantity）**：纵轴所表示的量。

- *入射 1 W/m² 的幅值*，单位 V/m。这是绝对场强，对应每平方米一瓦的入射光束。换算到实际光束只需一次乘法，而这正是判断某一层能否承受一个脉冲时所需要的。此为默认值。
- *平方，占入射比例*，即相对入射 `|E|²` 的百分比。这是纯比值，适合比较不同设计而非不同光束。
- *平方，绝对值*，单位 (V/m)²，同样对应 1 W/m² 入射。吸收估算需要这种形式，因为吸收功率随场的平方变化。

两种绝对形式都与入射介质有关，因为在光密介质中，给定辐照度的光束所携带的场更弱：对于折射率为 `n` 的介质中的辐照度 `I`，`|E| = sqrt(2I / (ε₀cn))`。1 W/m² 的光束在空气中幅值为 27.4492 V/m，在其他介质中则为该值除以折射率的平方根。

**分量（Component）**：所绘制的场的分量。

- *总场*，即合成场。除非专门需要某个分量，应读取这条曲线。
- *沿膜层方向*，即平行于层边界的分量。
- *垂直于膜层*，即与之垂直的分量。

在正入射时，以及 s 偏振在任意角度时，场完全沿膜层方向，因此垂直分量为零，总场与之相等。只有 p 偏振在斜入射时才分为两个分量，而此时材料所感受到的是二者的合成。

**面（Side）**：绘制**前（front）**镀膜还是**后（back）**镀膜的剖面。每一侧都显示该镀膜在基底上的驻波，从其自身的入射介质评估；基底为出射介质。

## 如何解读

横轴为物理深度，单位为纳米；竖直虚线与彩色条带标出层边界与材料。一条水平虚线标出入射光束自身的水平，因此高于该线的场是被镀膜集中起来的，而不只是穿过而已。峰值为场反节点（anti-node），谷值为节点（node）。

对于激光损伤工作，承载最高场强的层是瓶颈，降低该处的场强可提高损伤阈值。在精心设计的反射镜中，反节点优先落在更坚固的材料中，这正是反射镜能承受高功率的部分原因。为此应读取总场，而不是某个单独分量：在斜入射时，p 偏振场的切向分量可能在某个深度出现节点，而该处的合成场并不小，因为垂直分量在那里承载了场。

数据表列出屏幕上各曲线的场强随深度的变化，每个列标题都带有单位，并可导出为 CSV。将场强与[折射率分布](/zh/analysis/refractive-index-profile/)对照阅读，可看出驻波峰值落在哪一层。
