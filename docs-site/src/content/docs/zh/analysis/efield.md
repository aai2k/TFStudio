电场窗口在单一波长和入射角下绘制镀膜内部电场随深度的分布。它显示**电场在膜系中集中在哪里**，这正是激光损伤分析所需要的：承受最高电场的层通常就是在高功率光束下最先损坏的层。

## 计算的量

- **入射 1 W/m² 的幅值**，单位 V/m：入射光束为 1 W/m² 时的电场。换算到实际光束只需一次乘法，损伤阈值正是与它比较的。这是默认选项。
- **平方，占入射比例**：`|E|²` 占入射 `|E|²` 的百分比，是便于比较设计的纯比值。
- **平方，绝对值**，单位 (V/m)²，对应 1 W/m²：吸收估算所需的形式，因为吸收功率与电场的平方成正比。

绝对形式取决于入射介质：同样辐照度的光束在折射率更高的介质中电场更弱。水平点线是入射光束自身的水平，高于它的电场是被镀膜聚集起来的。

## 控件与设置

**偏振**：**平均**、**s** 或 **p**。**平均**画出 s 与 p 的平均，并把两者画在其后。

**面**：**正面**或**背面**镀膜，各自从其外侧介质看。切换设计时会转到带有镀膜的那一面。

**设置**：**波长 (nm)** 跟随设计的参考波长，切换设计时重新设为该值，设计没有参考波长时为 550 nm。**入射角 (°)** 范围为 0 到 89。**物理量**是上述三者之一。**分量**为**总场**、**沿膜层方向**的部分或**垂直于膜层**的部分；对 s 偏振和正入射，最后一项为零。**深度坐标轴**为从外表面算起的物理深度，或光学厚度 `Σ n·d`，以 nm、四分之一波 (QWOT) 或全波 (FWOT) 计。**λ₀** 是度量光学厚度所用的波长；**取自设计**采用设计的参考波长，使坐标轴与设计编辑器的厚度列一致。λ₀ 只移动深度坐标轴，从不改变电场。

**范围警告**：当波长落在某种材料的数据范围之外时出现 ⚠ 徽标，其中的按钮把 λ 移到所有材料都覆盖的最近波长。

**环境**：在有多个[环境](/zh/design/environments/)的设计上，**当前**跟随设计编辑器显示的环境，按编号选中的环境即使已关闭也让窗口停留在它上面，**全部**用各自的颜色绘制每个开启的环境，表格每行以其所在环境开头。层的条带取自第一个环境。这一选择不随设计保存。

**结果**：电场对应于图中所用深度坐标的数值，每列标题带有单位。

## 驻波

峰是驻波的波腹，谷是波节。正入射时，外表面处的电场等于入射电场乘以 `|1 + r|`，r 为振幅反射系数：外层为高折射率的反射镜（r 接近 −1）在表面处为 0，r 接近 +1 时可达入射电场的两倍。

在四分之一波反射镜自己的波长上，波腹和波节都落在膜层边界上，并逐层向膜系内部减弱，因此最外面几层承受了几乎全部电场。在光学坐标轴上波节相隔半个全波，比在物理坐标轴上更便于目视检查。

决定本征损伤水平的是电场的平方，而高折射率材料通常是较弱的一方。减薄外侧的高折射率层、加厚低折射率层，并保持每一对仍为半波，就能把峰值移到低折射率材料中。

斜入射时应看总场，而不是某一个分量：p 偏振切向分量的波节处，垂直分量可能承载很大的电场。

## 理论

电场从基底一侧向外求得。在基底处取 `[E, H] = [1, η_s]`，乘以各层的特征矩阵（整层，或某一深度以下剩余的部分），就得到该深度处的切向 `[E, H]`，所用的导纳和相位厚度与[导纳图](/zh/analysis/admittance/)相同。同一比例下入射的切向电场为 `(η₀B + C)/(2η₀)`，其中 `[B, C]` 为整个膜系的乘积，因此

```
|E(z)|² / |E_inc|² = |E(z)|² · |2η₀ / (η₀B + C)|² · c_p
c_p = |cos θ₀|²   p 偏振，   s 偏振为 1
```

c_p 把 p 偏振光的切向入射电场换算为其整个电场，因此每条曲线都是相对于整个入射 `|E|²` 的比例。

对 p 偏振，电场还有垂直分量，由自由空间单位下的切向磁场 H 得到：

```
Eₙ = (n₀ sin θ₀ / N²) · H
|E_total|² = ½ ( |Eₜ|² + |Eₙ|² + |Eₜ² + Eₙ²| )
```

Eₜ 与 Eₙ 振荡时有相位差，因此电场矢量在每个周期内画出一个椭圆。总场是其半长轴的平方，即材料所承受的最大电场；对 s 偏振和正入射，它等于 `|Eₜ|²`。**平均**为 `(|E_s|² + |E_p|²) / 2`，因为非偏振光在两个偏振中各有一半辐照度，其幅值是它的平方根。

绝对比例来自折射率为 n₀ 的介质中的入射辐照度 I：

```
|E_inc| = √( 2I / (ε₀ c n₀) ) = 27.4492 / √n₀  V/m   对应 I = 1 W/m²
```

在无吸收的膜系中，净辐照度 T·I 在每个深度都相同，因此电场由该处的导纳 Y 决定，`|E|² = 2T·I / Re(Y)`，Y 以西门子为单位（Macleod，式 3.6）：导纳低，电场就高。这就是四分之一波反射镜的峰值位于导纳最低的边界上的原因。

光学厚度使用 λ₀ 处折射率的实部：`OT = Σ n(λ₀)·d`，`QWOT = 4·OT/λ₀`，`FWOT = OT/λ₀`。
