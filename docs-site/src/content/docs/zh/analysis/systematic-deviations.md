系统偏差回答每一层同时朝同一方向漂移时的假设问题：所有膜层都厚 2 %，镀膜机每层都多镀 5 nm，或某种材料的折射率高了 0.05。与[蒙特卡洛](/zh/analysis/error-analysis/)不同，这里的误差是相关的：在整个设计上施加同一个偏移，而不是对每层独立随机抽取。设计本身从不改变。

## 计算的量

- **单一**：偏差后的 T、R 或 A，以百分比表示，实线画在未改动光谱（**基线**，点线）之上。两者之间的差距就是偏差的代价。在带有[规格](/zh/design/specification/)的设计上，判定显示偏差后的设计是否仍然通过。
- **扫描**：一个偏差参数（纵轴）对波长的热图，颜色为该通道的百分比；**T+R+A** 叠放三张图。宽而变化缓慢的带表示设计能容忍该误差；窄而变化快的带表示设计处在刀刃上。

在[设计编辑器](/zh/design/design-editor/)中设置的面模式决定哪些镀膜被施加偏差，并显示为徽标。

## 控件与设置

**单一 / 扫描**、通道（**T+R+A**、**T**、**R**、**A**）和**基线**位于这一行上；**设置**中是 **λ** 范围与步长、**入射角**和偏振。

**偏差**条，单一模式下：**d × 比例**、带单位（**nm**、**OT**、**QW**、**FW**）的 **d + 偏移**、**Δn** 和 **Δk**，在**全局偏差**下出现一次，在**逐材料**下按每种材料再出现一次。全局值只作用于镀膜层；入射介质、基底和出射介质保持各自的折射率，因为偏离标称的工艺改变的是它所生长的薄膜。逐材料行列出该材料出现的每个位置，包括各介质，因此逐材料 Δn 是有意改变基底玻璃折射率的方法；它也会改变同一材料的任何膜层。**重置偏差**使一切回到无变化。

扫描模式下：**参数**是上述控件之一，带有**从**、**到**和**步数**；切换参数类型时范围会重新设定。**运行扫描**计算该图，只从未改动的设计开始改变这一个参数。要把固定偏差与扫描结合，请先在单一模式下设置固定部分。

**环境**：在有多个[环境](/zh/design/environments/)的设计上，**当前**跟随设计编辑器显示的环境，按编号选中的环境即使已关闭也让窗口停留在它上面。偏差作用于膜层列表，并通过各材料在该环境中的厚度系数体现在该环境中。扫描画在其运行时所在的环境中。这一选择不随设计保存。

## 理论

对厚度为 d、折射率为 n、消光系数为 k 的膜层，每种偏差都有全局部分 (g) 和逐材料部分 (m)：

```
d′ = max(0, d · s_g · s_m + o_g + o_m)
n′ = n + Δn_g + Δn_m
k′ = max(0, k + Δk_g + Δk_m)
```

以光学单位输入的偏移逐层换算为纳米，n 为该层在设计参考波长 λ₀ 处的折射率：

```
o[nm] = OT / n(λ₀) = QW · λ₀ / (4 n(λ₀)) = FW · λ₀ / n(λ₀)
```

因此 0.01 QW 的偏移在低折射率层中比在高折射率层中厚。介质只取其逐材料的 Δn 和 Δk。偏差后的膜系随后按[光学评价](/zh/analysis/optical-evaluation/)中的方式计算。
