镀膜会拉扯它所沉积的工件。基底足够薄时工件就会弯曲；薄膜储存的能量足够大时就会开裂，或者与下面的材料分离。应力窗口依据材料上的常数和关于工艺的四个数值来预测这三件事。

**没有任何应力模型能达到光学模型的水准。** 薄膜应力取决于沉积工艺，而不只取决于材料，因此这些常数需要你自己测量，这些数字用于比较不同设计，而不是绝对地预测某个工件。

## 计算的量

每一个常数都来自[材料编辑器](/zh/design/material-editor/)的「力学」选项卡。没有填写的常数会让需要它的行留空，提示徽标会指出是哪种材料缺了哪个字段。

| 物理量 | 含义 | 需要 |
| --- | --- | --- |
| 薄膜应力 | 每层膜中的双轴应力，张应力为正 | 本征应力；设置了温度时还需要模量、泊松比、膨胀系数和参考温度，缺少某项常数时略去相应的热应力项 |
| 应变能 | 单层膜单位面积储存的弹性能 | 应力、模量、泊松比 |
| 脱层因子 | 一层膜及其外侧全部膜层的能量，与其下方界面表面能之比；等于 1 时具备分离的能量 | 各应变能，界面两侧材料的表面能 |
| 总应变能 | 各层膜之和 | 每层膜的应变能 |
| 开裂参数 | Σ U/2γ；等于 1 时膜系能支付裂纹两个新表面的能量 | 每层膜的应变能和表面能 |
| 薄膜合力 | Σ σ·d，Stoney 公式把它转换为弯曲，也是 `STR` 评价函数行的目标 | 每层膜的应力（未给出的按零计） |
| 边缘剪切 | 镀膜边缘处的峰值剪切 | 镀膜与基底的应力、模量和泊松比，基底厚度 |
| 曲率半径 | 压应力镀膜留下凸面时为正 | 薄膜合力，基底的模量、泊松比和厚度 |
| 中心挠度 | 中心相对边缘的弯曲，凸面为正 | 曲率半径和基底直径 |

图表为每层膜画一根柱，取其材料的颜色，张应力向上、压应力向下；膜层从基底起编号为 1。脱层因子通常在基底界面处最大，镀膜也确实是在那里脱落的。在均匀应力下，镀膜内部剪切为零，只有边缘才升高，这正是镀膜从边缘开始失效的原因。

## 控件与设置

**T**：读取应力时工件所处的温度。**沉积 T**：薄膜生长时基底的温度，即行星夹具上的热电偶或高温计读到的数值，而不是蒸发源的温度。两者都留空，则每层膜只承担本征应力；设置其中任意一个，两者都会生效，未填的那个按 20 °C 计。

**基底 d**：厚度，与[设计编辑器](/zh/design/design-editor/)中的数值相同。弯曲量与其平方成反比，因此它是本窗口中最有力的杠杆。**基底 ⌀**：直径，只有中心挠度需要它。这四个值都随设计一起保存。

哪些镀膜参与计算取决于设计的计算方式。两面都有镀膜时，两个弯矩方向相反，因此合力为 F_正 − F_背，镜像的背面镀膜会精确抵消弯曲。只有一面有镀膜时，它在背面的读数与在正面相同。

**环境**：在有多个[环境](/zh/design/environments/)的设计上，**当前**跟随设计编辑器显示的环境，按编号选中的环境即使已关闭也让窗口停留在它上面。薄膜和基底取该环境计算所用的，设置了温度时，**T** 按该环境温度与环境 1 温度之差移动。该环境改变的字段显示它计算所用的值，在这里不能编辑。这一选择不随设计保存。

## 消除弯曲

薄膜合力为零就是零挠度条件。在[评价函数编辑器](/zh/design/merit-function-editor/)中加入一行目标为 0 的 `STR`，优化器会替你平衡膜系；权重的设置见[操作数](/zh/design/operands/)。

## 理论

薄膜在自身的沉积温度下无应变地凝结，随后在横向尺寸不变的情况下取得基底的温度，这就是本征应变；σ_ref 是在材料参考温度 T_ref 下沉积的薄膜所具有的应力。从那里到 T，薄膜跟随基底，膨胀失配继续叠加：

```
σ = σ_ref + E/(1 − ν) · [ α_f (T_ref − T_dep) + (α_s − α_f) (T − T_dep) ]
```

合力、曲率（Stoney，Klein 2001 式 26）以及半径为 r₀ 的圆片的中心挠度：

```
F  = Σ σ_l d_l
K  = 6F / (E′_s t_s²),        E′_s = E_s / (1 − ν_s),    R = −1/K
ω₀ = −(1 − cos K r₀) / K  ≈  −r₀² K / 2
```

各能量（Klokholm 1987，式 1、2 和 6），γ 为表面能，第 j 层膜下方的界面与第 j − 1 层膜或基底共有：

```
U_l      = σ_l² d_l (1 − ν_l) / E_l
cracking = Σ_l U_l / (2 γ_l)
delam_j  = Σ_{l ≥ j} U_l / (γ_j + γ_{j−1})
```

第 j 层膜下方界面处的边缘剪切（Klein 2001 式 8 和 25），F_j 为第 j 层膜及其外侧全部膜层的合力：

```
k     = √[ (3/2) E_s / ((1 + ν_s) t_s)  /  Σ_l E_l d_l / (1 − ν_l²) ]
τ_max = k · |F_j|
```

1/k 是边缘处承担剪切的条带宽度。
