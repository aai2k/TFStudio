颜色评估（Color Evaluation）将镀膜的光谱转换为人感知到的颜色。它取可见光范围内的反射率或透射率，用标准观察者（standard observer）与照明体（illuminant）加权，并报告结果在 CIE 色度图上的位置，同时给出一块色样以及一整套色彩空间数值。用它来预测镀膜的可见外观：增透膜的色调、装饰镜的色相，或滤光片随视角产生的颜色偏移。

光谱在 380–780 nm 范围内采样，并送入标准色度积分，因此颜色与[光学评估](/zh/analysis/optical-evaluation/)中显示的曲线一致。

## 设置

**特性（Characteristic）**：计算反射光（R）还是透射光（T）的颜色。

**偏振（Polarization）**：平均、s 或 p。平均是非偏振照明的通常选择。

**AOI**：观察角，单位为度。扫描此值可观察虹彩镀膜随入射产生的颜色变化。

**观察者（Observer）**：CIE 颜色匹配函数：1931 年 2° 观察者用于小视场，或 1964 年 10° 观察者用于较大视场。

**照明体（Illuminant）**：计算颜色所用的光源：日光（D65、D50）、白炽光（A）和等能光（E）。

**步长（Step）**：颜色积分所用的波长采样间隔，单位为 nm。对于具有尖锐光谱特征的镀膜，更细的步长可提高精度。

**曝光（Exposure）**：仅作用于色样的亮度。默认情况下，色样以理想白色反射体为基准缩放，因此非常暗的反射（例如强增透膜残留的颜色）即使色相高度饱和，也会渲染得近乎黑色。提高曝光（×10 至 ×1000）或选择**拟合色相（Fit hue）**可重新缩放色样，以全亮度显示色相。数值读数不会改变，只有色样被重新曝光。这模拟了当镀膜反射明亮光源而非暗淡场景时人眼所见的情形。

评估面（前、后或整体）在[设计编辑器](/zh/design/design-editor/)中设置，并显示为窗口上的徽标。

## 如何解读

色度图显示了光谱轨迹（纯色的马蹄形，由紫线封闭，在 460 至 620 nm 之间每隔 20 nm 标注波长）、所选照明体的白点，以及你的镀膜的标记点。靠近白点的标记意味着接近中性、无色的镀膜；被拉向轨迹边缘的标记意味着强烈、饱和的色调。图的一角有两块色样：一块以近似的屏幕颜色显示镀膜的颜色及其 Y 值，旁边一块是该照明体的参考白。

由于色样以理想白色反射体为基准，暗淡的反射看起来会偏暗或发黑，即使色度标记点已远离白点朝向轨迹：颜色确实在那里，但承载它的反射光太少。使用**曝光（Exposure）**设置将该色相提升到可见亮度，而不改变报告数值。

数值面板报告三刺激值 X、Y、Z；xy、u′v′ 与 CIE 1960 uv 色度；CIE L\*a\*b\* 与 L\*u\*v\* 及其彩度与色相角；Hunter Lab；主波长，紫色没有主波长时则为补色波长，均附纯度；以及相关色温（CCT）及其相对普朗克轨迹的偏移（Duv）。颜色离普朗克轨迹太远、没有相关色温时，CCT 显示为短横线。
