颜色评估（Color Evaluation）将镀膜的光谱转换为人感知到的颜色。它取一个或多个角度下可见光范围内的反射率或透射率，用标准观察者（standard observer）与照明体（illuminant）加权，并显示结果在 CIE 颜色图上的位置，同时给出该颜色的色样以及一整套色彩空间数值。用它来预测镀膜的可见外观：增透膜的色调、装饰镜的色相，或滤光片随视角产生的颜色偏移。

光谱在 380–780 nm 范围内采样，并送入标准色度积分，因此颜色与[光学评估](/zh/analysis/optical-evaluation/)中显示的曲线一致。

## 颜色如何计算

人眼通过三种视锥细胞感知颜色。色度学用三条颜色匹配函数 x̄、ȳ、z̄ 代替它们，这些函数由 CIE 在观察者身上测得：1931 年 2° 观察者对应正视的小色块，1964 年 10° 观察者对应较大的色块。到达人眼的光是照明体的光谱乘以镀膜的 R 或 T。将它分别按每条匹配函数加权，并在 380–780 nm 上求和，得到三个数 X、Y、Z。ȳ 是人眼对亮度的感受曲线，因此 Y 表示颜色看起来有多亮。

两个光谱只要 X、Y、Z 相同，在该照明体下看起来就是同一种颜色，无论它们的曲线差别多大。因此三个数就完全确定了一个颜色，本窗口中的每个数值和每张颜色图都由它们算出。换一种照明体，同一镀膜看起来可能是另一种颜色，所以照明体是一项设置。

## 设置

**T / R**：膜层透射或反射的光的颜色。

**偏振（Polarization）**：平均、s 或 p。平均是非偏振照明的通常选择。

**AOI**：观察角，单位为度，以**列表（List）**或**范围（Range）**输入。列表的输入方式与[光学评估](/zh/analysis/optical-evaluation/)相同：点击 **+** 添加角度，点击某个角度修改它，点击它的 × 删除它。范围取起始角、终止角和二者之间的步长，例如 0 到 60、步长 10 得到七个角度。两种方式下窗口最多取 91 个角度：每个角度都要多算一条光谱，91 个角度已会让几十层的设计在每次改动时停顿。更长的范围只计算前 91 个，并以提示说明。每个角度在图上是一个点，各点按顺序连线，因此镀膜随角度的颜色偏移呈现为一条路径。

**观察者（Observer）**：CIE 颜色匹配函数：1931 年 2° 观察者用于小视场，或 1964 年 10° 观察者用于较大视场。

**照明体（Illuminant）**：计算颜色所用的光源：日光（D65、D50）、白炽光（A）和等能光（E）。

**步长（Step）**：颜色积分所用的波长采样间隔，单位为 nm。对于具有尖锐光谱特征的镀膜，更细的步长可提高精度。

**曝光（Exposure）**（在设置中）：镀膜颜色在屏幕上如何显示，即图上的点、图下方各行的色块和色样视图。默认的**匹配色调（Fit hue）**以全亮度显示色相。**原样（As is）**以理想白色反射体为基准缩放该颜色，因此非常暗的反射（例如强增透膜残留的颜色）即使色相高度饱和，也会渲染得近乎黑色。数值不会改变，只有屏幕上的颜色改变。

**显示（Show）**（在设置中）：图上除镀膜之外还绘制的内容：光谱轨迹上的波长、照明体的白点、普朗克轨迹（1000 K 起黑体的颜色，并标注几个温度），以及 sRGB 显示器三原色构成的三角形，屏幕能如实显示的颜色都在三角形内。

评估面（前、后或整体）在[设计编辑器](/zh/design/design-editor/)中设置，并显示为窗口上的徽标。

**环境**：在有多个[环境](/zh/design/environments/)的设计上，颜色图下方一行中的**环境**下拉列表决定颜色在哪个环境中计算。**当前**跟随设计编辑器和功能区显示的环境。按编号和名称选中的环境会让窗口停留在该环境上，即使它已关闭。**全部**显示每个开启的环境：每个环境的点以本窗口在首选项“分析”中调色板里该环境的颜色描边并连线，颜色图上方的图例标出各个环境；图下方的各行、表格、色块和 CSV 都会标明每一行所在的环境。材料范围提示读取所显示的每个环境的材料。这一选择属于本窗口，不随设计保存。

## 颜色图

图上方的标签页选择颜色图：

- **x, y**：CIE 1931 色度图。人眼能看到的每种颜色都落在马蹄形之内。弯曲的边是光谱轨迹，即单一波长的纯色；平直的底边是紫线，即深蓝与深红的混合色，没有单一波长能产生它们。照明体的白点是 ×。点靠近白点表示颜色淡、接近中性，靠近边缘表示颜色浓，它相对白点的方向就是色调。图中不含亮度：同一色调的暗反射与亮反射落在同一点上。
- **u′, v′**：CIE 1976 均匀色度图（UCS），即经过拉伸的同一马蹄形，使相等的距离更接近人眼所见的相等色差。在 x, y 上，绿色区域中人眼几乎察觉不到的一步，与蓝色区域中一眼就能看出的一步一样长；在这里两者长度更为接近。
- **a\*, b\***：某一明度下的 CIE L\*a\*b\* 平面，白点位于中心。a\* 从左边的绿到右边的红，b\* 从下方的蓝到上方的黄。到中心的距离表示色调有多浓，方向表示是哪种色调。相等的距离大致对应人眼所见的相等差别，因此两点之间的距离就是它们的 ΔE\*ab。
- **C\*uv, huv**：围绕白点绘制的 CIE L\*u\*v\* 平面：圆环是彩度 C\*uv，表示色调有多浓，辐射线是色调角 huv。
- **C\*ab, hab**：以同样方式围绕白点绘制的 a\*, b\* 平面：彩度 C\*ab 的圆环与色调角 hab 的辐射线，0° 为红，90° 为黄，180° 为绿，270° 为蓝。

在 x, y 与 u′, v′ 图上，光谱轨迹（纯色的马蹄形，由紫线封闭）内部按每一点的颜色填充，并在轨迹上从 420 到 680 nm 标注波长。每一点都以 sRGB 屏幕所显示的颜色、以全亮度呈现，与照明体无关。屏幕无法显示的颜色沿直线移向屏幕的 D65 白点直到可以显示为止，因此保持其相对该白点的主波长，只损失饱和度。

三个 L\*a\*b\* 与 L\*u\*v\* 标签页按镀膜的明度绘制光谱轨迹及其填充：取各角度中最高的 L\*，向上取整。同一色度的 a\*, b\* 与 u\*, v\* 随明度增大，因此按镀膜自身的 L\* 绘制时，填充包含所有点，每个点位于它自己的 a\*, b\* 或 u\*, v\* 处。这些平面以照明体的白点为基准，因此其填充显示每种颜色在该照明体下的样子，并像镀膜的点一样换算到屏幕的白点：中心 a\* = b\* = 0 在任何照明体下都是白色，在 D65 下填充的颜色与 x, y 图相同。这些标签页的显示范围按你的镀膜确定：以白点为中心，略超出离白点最远的点，因此即使是增透膜微弱的反射，其随角度的颜色偏移也能铺满整个图。显示范围最小为 ±5，因此几乎不变的颜色不会被放大到让人眼看不出的差异铺满整个图。完整的光谱轨迹保留在 x, y 与 u′, v′ 图上。

## 目标

控制栏上的**目标**按钮把评价函数中的颜色行画在颜色图上，与[光学评估](/zh/analysis/optical-evaluation/)把目标画在曲线图上相同。显示 R 时画 `RCOL` 行，显示 T 时画 `TCOL` 行，只画在窗口的偏振、照明体与观察者下评分的行。每一行画在它自身坐标所在的颜色图上：同一角度的一行 x 和一行 y 合成一个空心菱形，标注该角度，位于镀膜在该角度的点旁边。u′ 与 v′ 行以同样方式画在 u′, v′ 图上；a\* 与 b\* 行或 C\*ab 与 hab 行画在两个 L\*a\*b\* 标签页上；u\* 与 v\* 行或 C\*uv 与 huv 行画在 C\*uv, huv 图上。在其角度上没有配对的行，以及 Y、L\* 和任何颜色图都不含的量，不会画出。选择**全部**时画出每个环境的行。所显示的颜色图上没有这样的行时，按钮变灰。

**目标**旁边的**编辑**按钮让你直接在颜色图上建立目标，而不必在[评价函数编辑器](/zh/design/merit-function-editor/)中输入。它在控制栏下方打开一行，含两个工具和 **AOI (°)**，即绘制的目标所写入的角度：

- **绘制**：单击颜色图，在该处添加目标。目标写成该颜色图所用坐标的两行：在 x, y 图上为一行 x 和一行 y；在 u′, v′ 图上为 u′ 与 v′；在 a\*, b\* 图上为 a\* 与 b\*；在两个色相与彩度标签页上为 C\*ab 与 hab，或 C\*uv 与 huv。这两行采用窗口显示的 R 或 T、偏振、照明体与观察者，权重为 1，接在评价函数最后一行之后。它们的角度由 **AOI (°)** 选择：**最近**，即离单击处最近的镀膜点的角度，因此请在想要拉动的那个点旁边单击；或窗口显示的某个角度。在有多个环境的设计上，这两行在该角度下离单击处最近的点所属的环境中评分：即所显示的环境，或在**全部**下离单击处最近的点所属的环境。
- **删除**：单击目标即移除它的两行。

两种工具下都可以拖动目标：它两行的目标值移到放下的位置，x、y、u′ 和 v′ 保留三位小数，其余保留两位。编辑期间，三个 L\*a\*b\* 与 L\*u\*v\* 标签页的图框保持不动：单击、拖动或删除都不会改变它的大小，因此目标停在放下的位置。在评价函数编辑器中键入超出边缘的数值，或镀膜的点移出边缘，仍会使图框扩大。不论**目标**按钮如何设置，目标都会显示。每次编辑都直接修改评价函数，因此评价函数编辑器会立即显示，Ctrl+Z 可以撤销。也可以用向导的[颜色预设](/zh/design/merit-function-editor/#颜色目标)设置目标。

## 图下方

图下方每个角度一行，显示镀膜在该角度下颜色的色块（按窗口的曝光），以及它的 x、y、Y、L\*、a\*、b\*、主波长 λd（紫色则为补色波长 λc）和纯度。数值按列对齐，因此随角度的变化沿每一列读出；超过六个角度时这些行可以滚动。其他色彩空间见结果（Results）栏；结果栏打开时这些行会让出位置，使颜色图保持其大小。

## 各数值的含义

所有数值都来自同样三个数 X、Y、Z：镀膜的光谱按照明体以及观察者的三条颜色匹配函数加权后的结果。

| 数值 | 含义 |
|---|---|
| X, Y, Z | 三刺激值：光对观察者三条颜色匹配函数各自的刺激强度。Y 只反映人眼对亮度的感受。 |
| Y (%) | 光度反射率或透射率：人眼所见的被反射或透过的光所占的份额，以 % 计。 |
| x, y | 色度：去掉亮度后颜色在 x, y 色度图上的位置，x = X / (X + Y + Z)，y = Y / (X + Y + Z)。 |
| u′, v′ | 同一色度在 CIE 1976 均匀色度图上的位置；该图经过拉伸，使相等的距离更接近人眼所见的相等色差。 |
| u, v | 较早的 CIE 1960 色度，相关色温在其上测量。 |
| L\* | 明度，0 为黑，100 为白。 |
| a\*, b\* | 颜色相对白点的位置：a\* 小于 0 偏绿、大于 0 偏红，b\* 小于 0 偏蓝、大于 0 偏黄。0, 0 为中性色。 |
| C\*ab, hab | 把同一 a\*, b\* 写成距离与角度：彩度 C\*ab 表示色调有多浓，色调角 hab 表示是哪种色调，0° 为红，90° 为黄，180° 为绿，270° 为蓝。 |
| L\*, u\*, v\*, C\*uv, huv | CIE L\*u\*v\* 中的同类数值，该空间建立在 u′, v′ 之上。 |
| suv | 饱和度：每单位明度 L\* 的彩度 C\*uv。 |
| Hunter L, a, b | 较早的明度与对立色标尺，部分规格中仍在使用。 |
| λd | 主波长：与照明体白光混合后能匹配镀膜颜色的光谱色，用来称呼色调。 |
| λc | 补色波长：紫色没有单一波长能匹配，此时取白点另一侧的光谱色。 |
| 纯度 | 颜色从白点朝其光谱色偏离的程度，白点处为 0 %，光谱轨迹上为 100 %。 |
| CCT | 相关色温：颜色最接近的黑体的温度，单位 K。只有靠近普朗克轨迹的颜色才有相关色温。 |
| Duv | 颜色在 u, v 色度图上偏离普朗克轨迹的距离：在其上方为正，下方为负。 |
| ΔE\*ab, ΔE00 | 两个颜色之间的差别：ΔE\*ab 是 L\*a\*b\* 中的直线距离，ΔE00 是 CIEDE2000 公式，更贴近人眼的感受。通常取约 1 为并排比较时能看出的最小差别。 |

## 如何解读

靠近白点的点意味着接近中性、无色的镀膜；被拉向轨迹边缘的点意味着强烈、饱和的色调。每个点都以近似的屏幕颜色填充为镀膜在该角度下的颜色。

默认的**匹配色调（Fit hue）**以全亮度显示该颜色，因此即使非常暗的反射，其色相也能看清。**原样（As is）**则以理想白色反射体为基准显示它：暗淡的反射看起来偏暗或发黑，即使其点已远离白点朝向轨迹，这正反映了它承载的光有多少。

## 结果

图下方的**结果（Results）**栏有三个视图，每个角度一行或一块色样：

- **表格（Table）**：一次显示一个色彩空间中的颜色，在其右侧的列表中选择：x, y, Y；X, Y, Z；CIE L\*a\*b\*；L\*、C\*ab、hab；CIE L\*u\*v\*；L\*、C\*uv、huv、suv；u′, v′；CIE 1960 u, v；Hunter Lab；主波长，紫色没有主波长时则为补色波长，附纯度；以及相关色温（CCT）及其相对普朗克轨迹的偏移（Duv）。颜色离普朗克轨迹太远、没有相关色温时，CCT 显示为短横线。只有一个角度且只显示一个环境时，表格改为一次列出所有色彩空间，每行一个色彩空间，每个量的名称紧挨其数值。
- **色差（Differences）**：每个角度的颜色与第一个角度的颜色相差多少：ΔL\*、Δa\*、Δb\*、CIE 1976 色差 ΔE\*ab 和 CIEDE2000 色差 ΔE00。在**全部**下且开启的环境多于一个时，改为将每个环境的颜色与第一个环境在同一角度下的颜色比较，因此每一行读出的是该环境造成的偏移，第一个环境的各行为零。
- **色样（Color Patch）**：镀膜在每个角度下颜色的色样及其 Y 值，旁边是该照明体的参考白，排成一行，角度多于一行能容纳的数量时换行。

将鼠标悬停在某个数值、它的表头或图下方各行的数值上，即可看到它的含义，说法与[各数值的含义](#各数值的含义)相同。

**导出（Export）**将所有色彩空间和色差写入一个 CSV，与当前打开的视图无关。
