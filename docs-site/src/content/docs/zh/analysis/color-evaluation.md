颜色评价把镀膜的光谱转换为人眼看到的颜色：增透膜的色调、装饰镜的色相，或滤光片的颜色如何随视角偏移。它在 380–780 nm 上用照明体和标准观察者对 R 或 T 加权，把结果画在 CIE 颜色图上，每个角度一个点并按顺序连线，同时给出所有常用的颜色数值。

## 计算的量

所有数值都来自三个数 X、Y、Z：到达人眼的光按观察者的三条颜色匹配函数加权后的结果。两个光谱只要 X、Y、Z 相同，在该照明体下看起来就是同一种颜色，无论它们的曲线差别多大。在窗口中悬停在某个数值上可看到它的含义。

| 数值 | 含义 |
|---|---|
| X, Y, Z | 三刺激值。Y 只反映人眼对亮度的感受。 |
| Y (%) | 光度反射率或透射率：人眼所见的光所占的份额。 |
| x, y | 去掉亮度后的色度。 |
| u′, v′ | CIE 1976 均匀色度图上的同一色度，相等的距离更接近人眼所见的相等色差。 |
| u, v | CIE 1960 色度，相关色温在其上测量。 |
| L\*, a\*, b\* | 明度 0 到 100；a\* 由绿到红，b\* 由蓝到黄，0, 0 为中性色。 |
| C\*ab, hab | 把 a\*, b\* 写成彩度（色调浓度）和色调角，0° 为红，90° 为黄，180° 为绿，270° 为蓝。 |
| L\*, u\*, v\*, C\*uv, huv, suv | 建立在 u′, v′ 之上的 CIE L\*u\*v\* 中的同类数值；suv 为每单位明度的彩度。 |
| Hunter L, a, b | 较早的对立色标尺，部分规格中仍在使用。 |
| λd, λc | 主波长，即与白光混合后能匹配镀膜颜色的光谱色；紫色没有主波长，此时为补色波长。 |
| 纯度 | 从白点朝光谱轨迹偏离的程度，0 % 到 100 %。 |
| CCT, Duv | 相关色温，即最接近的黑体的温度（K），以及偏离普朗克轨迹的距离。只有靠近该轨迹的颜色才有相关色温。 |
| ΔE\*ab, ΔE00 | 两个颜色之间的差别；通常取约 1 为并排比较时能看出的最小差别。 |

## 控件与设置

**T / R**、**偏振**，以及以**列表**或**范围**（起点、终点、步长）给出的**入射角**，最多 91 个角度。

**观察者**：CIE 1931 2° 用于小视场，CIE 1964 10° 用于较大视场。**照明体**：D65、D50、A 或 E；同一镀膜在另一种光下看起来可能是另一种颜色。**步长**：积分的波长采样间隔；光谱特征尖锐时用更细的步长。

**曝光**：默认的**匹配色调**以全亮度显示每种颜色，使暗反射的色调也能看清。**原样**以理想白色反射体为基准缩放，因此强增透膜的反射显示得近乎黑色，这正反映了它承载的光有多少。数值不变。**显示**：波长标记、照明体的白点、普朗克轨迹和 sRGB 三角形。

**目标**把评价函数的 `RCOL` 或 `TCOL` 行画在其自身坐标所在的颜色图上，一对行相交处画为空心菱形。**编辑**通过单击颜色图建立目标：一个目标是该颜色图坐标下的两行，角度由 **AOI (°)** 选择（**最近**取离单击处最近的点的角度）；拖动可移动目标，也可以删除它。目标也可以来自向导的[颜色预设](/zh/design/merit-function-editor/#颜色目标)。

**结果**：**表格**每次显示一个色彩空间（只有一个角度时同时显示所有空间），**差值**给出每个角度相对第一个角度的差（ΔL\*、Δa\*、Δb\*、ΔE\*ab、ΔE00），**色块**在照明体白点旁显示各色块。**导出**把全部内容写入一个 CSV。

计算面取自[设计编辑器](/zh/design/design-editor/)。

**环境**：在有多个[环境](/zh/design/environments/)的设计上，**当前**跟随设计编辑器显示的环境，按编号选中的环境即使已关闭也让窗口停留在它上面，**全部**用各自的颜色为每个环境的点描边并连线；此时**差值**把每个环境与第一个环境在同一角度下比较。这一选择不随设计保存。

## 色度图

- **x, y**：CIE 1931 色度图。弯曲的边是单一波长的纯色，平直的底边是紫色。点靠近白点 × 表示颜色淡，靠近边缘表示颜色浓，它相对白点的方向就是色调。图中不含亮度。
- **u′, v′**：同一马蹄形经过拉伸，使相等的距离更接近相等的可见色差。
- **a\*, b\***：某一明度下的 L\*a\*b\* 平面，白点位于中心；两点之间的距离就是它们的 ΔE\*ab。
- **C\*uv, huv** 和 **C\*ab, hab**：围绕白点绘制的 L\*u\*v\* 与 L\*a\*b\* 平面，环表示彩度，辐线表示色调。

填充按 sRGB 屏幕以全亮度显示的颜色呈现每个色度；屏幕无法显示的颜色沿直线移向其白点，保持主波长不变。三个明度平面标签页按镀膜的最高 L\* 绘制，显示范围按镀膜确定，最小为 ±5，使增透膜随角度的微弱偏移也能铺满整个图。

## 理论

S 为照明体，R 为镀膜的反射率（或 T），x̄、ȳ、z̄ 为观察者的颜色匹配函数（Macleod，式 12.1–12.5）：

```
X = 100 ∫ S R x̄ dλ / ∫ S ȳ dλ
Y = 100 ∫ S R ȳ dλ / ∫ S ȳ dλ
Z = 100 ∫ S R z̄ dλ / ∫ S ȳ dλ
x = X / (X + Y + Z),    y = Y / (X + Y + Z)
```

在窗口的网格上按梯形法计算。相对照明体白点 X_n、Y_n、Z_n（CIE 15:2004）：

```
L* = 116 f(Y/Y_n) − 16
a* = 500 [ f(X/X_n) − f(Y/Y_n) ]
b* = 200 [ f(Y/Y_n) − f(Z/Z_n) ]
f(t) = t^(1/3)  t > (6/29)³ 时，   低于时为 t / (3 (6/29)²) + 4/29
ΔE*ab = √(ΔL*² + Δa*² + Δb*²)
```

主波长是从白点经镀膜颜色点的直线与光谱轨迹的交点，纯度是镀膜点到白点的距离与轨迹到白点距离之比。相关色温是 CIE 1960 u, v 平面上普朗克轨迹最近点的温度，Duv 是到它的距离。ΔE00 是按 Sharma、Wu 和 Dalal 的实现给出的 CIEDE2000 公式。
