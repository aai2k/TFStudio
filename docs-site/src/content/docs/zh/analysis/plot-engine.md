绘图引擎（Plot Engine）是一个灵活的绘图工作台。在 **2D** 模式下，你可以在一张图上叠加任意多条曲线，每条各有设置：例如 0° s 偏振的 T 旁、45° p 偏振的 T 旁、整体系统的 R。在 **3D** 模式下，你将一个量在两个扫描变量上映射为可旋转曲面或热图，包括你的设计所处的评价函数（merit function）地形。控制行上的 2D / 3D 开关切换模式，且每个设计的图在你切换窗口时被记住。

## 设置

### 2D 曲线

添加一条曲线并配置它：

**X 轴**：波长（nm）或 AOI（°），带从/到范围与步长。

**Y**：要绘制的通道：T、R 或 A。

**偏振（Polarization）**：s、p 或平均。

**面（Surface）**：前、后或整体。

**AOI 固定 / λ 固定**：对于非 x 轴的 AOI 或波长所保持的常数值。

**虚线 / 宽度 / 颜色**：线外观，以及每条曲线的可见性复选框。

### 3D 曲面

**量（Z）**：要映射什么：**T**、**R**、**A** 或 **评价函数（Merit Function）**。对于光学量你还要选择偏振与面模式。评价函数正是优化器最小化的量，因此曲面显示你的设计所处的盆地。

**X 轴 / Y 轴**：每个轴分两步构建：选择目标（波长、AOI 或特定层，每层列出一个），然后对于层，选择要变化的属性（厚度、n 或 k）。设置从/到范围与步数。扫描层的 n 或 k 会临时用恒定折射率材料替换该层。评价函数轴必须是层参数，因为波长与 AOI 已从评价函数中积分掉而被拒绝。

**固定 λ / AOI**：仅对不在轴上的波长或 AOI 显示。

**渲染（Render）**：3D 曲面或平面热图。

**颜色（Colors）**：颜色刻度（Viridis、Cividis、Jet 等）。

**计算曲面（Compute surface）**：运行网格。点计数显示在按钮下方，计数器报告进度；大网格在计算时保持响应。每轴步数与总网格大小有上限以保持运行可控。

## 如何解读

在 2D 中，每条可见曲线绘制在共享的 T / R / A 轴（分数）上，因此叠加不同角度、偏振或面模式的曲线可让你直接比较。用于入射角扫描（每角度一条曲线）或偏振比较。

在 3D 中，波长 × AOI 上的 T/R 曲面是角度稳健性图，而两层厚度上的评价函数是优化地形，便于确认精炼后的设计位于真正的盆地中，或发现附近更好的一个。你可以从图的内置工具栏将任何图导出为 PNG 或 SVG。
