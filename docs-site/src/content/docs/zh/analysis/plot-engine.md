绘图引擎把其他分析窗口计算的数值对你改变的任意参数作图。**2D** 叠加任意多条曲线，每条各有自己的设置：0° s 偏振的 T 旁边放 45° p 偏振的 T，啁啾镜的 GDD 对某一膜层的厚度，或 Ψ 对 Δ 随膜层增厚的变化。**热图**和 **3D** 把一个物理量绘制在两个变量上，其中包括评价函数在两层厚度上的分布。每个设计保留自己的图。

## 计算的量

每个物理量都与其所属窗口的计算完全相同，因此这里的一个点就是该窗口在相同设置下显示的数值。

| 物理量 | 计算方式同 | 单位 |
| --- | --- | --- |
| T、R、A | [光学评价](/zh/analysis/optical-evaluation/) | % |
| R 或 T 的相位 φ、GD、GDD、TOD | [群延迟 / GDD](/zh/analysis/gd-gdd/) | °、fs、fs²、fs³ |
| Ψ、Δ | [椭偏仪评估](/zh/analysis/ellipsometry/) | ° |
| MF | [评价函数编辑器](/zh/design/merit-function-editor/) | 无 |

设计带有入射锥角时，T、R 和 A 在锥角上取平均；相位、各延迟量以及 Ψ 和 Δ 按单一角度计算，与它们各自的窗口相同。Δ 采用 Azzam–Bashara 约定。图中不包含相位本身，因为相位沿一条线展开，在网格上没有唯一的展开方式。

## 控件与设置

**2D / 热图 / 3D**：在 2D 中，这一行上是**曲线**，即顶部带有**添加曲线**的列表；在热图和 3D 中，这一行上是该图的**设置**。

每条 2D 曲线包含：

- **扫描**：沿曲线变化的量，**波长 (nm)**、**入射角 (°)** 或某一膜层的厚度（L1 紧贴基底；只有背面镀膜的设计则为背面膜层，B1 紧贴基底），以及**范围**和**步长**。
- **固定**：读取曲线所用的 λ 和入射角，曲线不读取的项显示为灰色。
- **X** 和 **Y**：扫描值或表中的任意物理量，以及其偏振和面（**正面**、**背面**或**整体**）。两轴都选物理量时，曲线描出一者对另一者的关系：X 取 Ψ、Y 取 Δ，外层逐渐增厚，就是原位椭偏仪所走的路径。Ψ、Δ 和反射相位属于单个表面，只提供正面和背面；透射相位或延迟选**整体**时为整个零件，与[脉冲分析](/zh/analysis/pulse-analysis/)相同。
- **线型**和**线宽**。

设计或曲线改变时，曲线会自动重新计算。没有入射锥角时，T、R、A、Ψ 和 Δ 立即给出；其余在后台计算，计算期间这一行上显示**停止**，用**计算**重新开始。热图或曲面只在你按下**计算**时才计算，更改设置会清除它。

图的**设置**：**物理量 (Z)** 及其偏振和表面，**X 轴**和 **Y 轴**（波长、入射角或某一膜层厚度，各带范围和**步数**），不在轴上的固定 λ 或入射角，以及**颜色**。网格大小显示在底部；先用粗网格。

**环境**：在带有[环境](/zh/design/environments/)的设计上，每条曲线和图都有自己的**环境**字段。**当前**在设计编辑器显示的环境中计算；按编号选中的环境在该环境中计算，无论开启与否，因此球罩中心的 T 可以与边缘的 T 并列。图与其计算时所在的环境绑定，当其设置会在另一个环境中计算时被清除。

## 解读曲线与图

在 2D 中每类物理量有自己的 Y 轴：T、R 和 A 共用一根，Ψ 和 Δ 共用一根，相位、GD、GDD 和 TOD 各用一根。X 轴为物理量的曲线可能折回自身，例如 Ψ–Δ 路径，需要逐点读取。

评价函数沿某一厚度的剖面显示设计是否位于谷底；评价函数在两个厚度上的分布就是优化器搜索的景观，显示优化后的设计是在真正的盆地中，还是附近另有更好的盆地。T 或 R 在波长与入射角上的图，就是[波长–角度图](/zh/analysis/wavelength-angle-map/)所画的图。

## 理论

评价函数是整个设计的一个数值，即[评价函数编辑器](/zh/design/merit-function-editor/)中的评价函数：

```
MF   = √( Σ w_i Δ_i² / Σ w_i )
MF²  = (1/N) Σ_k MF_k²          当前，对 N 个开启的环境
```

因此在曲线上它只沿某一膜层的厚度变化，它的图需要两根轴都是膜层厚度。选某一环境时，它是该环境自身的 MF_k。波段行在每个环境中都按环境 1 的网格采样。

轴上的膜层厚度就是设计编辑器显示的厚度。每个环境把该层沉积为 `f·d`，f 是其材料在该环境中的厚度系数乘以该环境温度带来的变化，因此每条曲线都在设计厚度处经过其环境自己的值。
