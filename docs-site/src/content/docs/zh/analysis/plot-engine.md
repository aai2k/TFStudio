绘图引擎（Plot Engine）把其他分析窗口计算的数值对你改变的任意参数作图。在 **2D** 中，你可以叠加任意多条曲线，每条曲线各有自己的设置：0° s 偏振的 T 旁边放 45° p 偏振的 T，啁啾镜的 GDD 对某一膜层的厚度，或 Ψ 对 Δ 随膜层增厚的变化。**热图（Heatmap）**和 **3D** 把一个物理量同时在两个变量上绘出，其中包括评价函数在两层厚度上的分布。在窗口之间切换时，每个设计保留自己的图。

每个物理量都由它所属窗口的同一套代码计算，因此图上的一个点就是该窗口在相同设置下显示的数值。

| 物理量 | 计算方式同 | 单位 |
| --- | --- | --- |
| T、R、A | [光学评估](/zh/analysis/optical-evaluation/) | % |
| R 或 T 的相位 φ、GD、GDD、TOD | [群延迟 / GDD](/zh/analysis/gd-gdd/) | °、fs、fs²、fs³ |
| Ψ、Δ | [椭偏仪评估](/zh/analysis/ellipsometry/) | ° |
| MF | [评价函数编辑器](/zh/design/merit-function-editor/) | 无 |

设计带有入射锥时，T、R 和 A 在入射锥上取平均；在其他环境中，则在该环境的入射锥上取平均。相位、各延迟量以及 Ψ 和 Δ 按单一角度计算，与它们各自的窗口相同。

## 控制行

**2D**、**热图（Heatmap）**和 **3D** 选择窗口绘制的内容。在 2D 中，控制行上是**曲线（Curves）**，即曲线列表，顶部有**添加曲线（Add curve）**。在热图和 3D 中，控制行上是**设置（Settings）**，即该图的物理量和两条轴。

设计或曲线改变时，曲线会自动重新计算。设计没有入射锥时，T、R、A、Ψ 和 Δ 的曲线立即给出。相位、各延迟量和 MF 耗时更长，入射锥下的任何曲线也是如此，它们在后台计算：计算期间控制行上显示**停止（Stop）**，停止之后用**计算（Compute）**重新开始。曲线在新线算好之前保留旧线，重命名、改色或隐藏曲线不会触发任何计算。

按下**计算（Compute）**时才计算图。控制行下方的进度条和图上的计数显示进度，**停止（Stop）**结束计算。更改任何设置都会清除该图，直到你再次计算。

## 2D 曲线

每条曲线开头是显示或隐藏它的复选框、它的颜色、它的名称和删除它的按钮，之后是以下设置：

**扫描（Sweep）**：沿曲线变化的量：**波长 (nm)**、**入射角 (°)**，或某一正面膜层的厚度，膜层按编号和材料列出，L1 为基底上的那一层。

**范围（Range）**：起点、终点和**步长（Step）**。新的**扫描（Sweep）**从适合它的范围开始，例如入射角为 0 到 60°，膜层厚度为该层自身厚度附近的一段。

**固定（Fixed）**：读取曲线时所用的 λ 和入射角。曲线改变的那一个变灰；曲线上没有任何量读取它们时两者都变灰，例如 MF，它使用每个操作数自己的值。

**X** 和 **Y**：每条轴显示什么。可以是曲线改变的那个值，以它自己的名称列出（λ、入射角，或膜层的 d），也可以是上表中的任意物理量。两条轴都选物理量时，曲线描出一个量对另一个量的关系：X 取 Ψ、Y 取 Δ，改变最外层的厚度，就是原位椭偏仪在沉积该层时所走的轨迹。物理量旁边是它的偏振（**平均**、**s** 或 **p**）和它的面（**正面（Front）**、**背面（Back）**或**整体（Total）**）。Ψ 和 Δ 同时取 s 和 p，因此其偏振变灰。Ψ、Δ 以及反射的相位或延迟属于单一表面，只提供正面和背面。透射相位或延迟的**整体（Total）**是整个零件，包括背面膜层和穿过一次基底，与[脉冲分析](/zh/analysis/pulse-analysis/)相同。

**线型（Dash）**和**线宽（Width）**：线的画法。

MF 是整个设计的一个数值，因此在曲线上只随膜层的厚度变化。为某条轴选择 MF 时，以波长或入射角为变量的曲线会改为以某一膜层的厚度为变量。它需要评价函数编辑器中至少有一个启用的操作数；在带有环境的设计上，还需要有一行在开启的环境中评分，或在曲线所指的环境中评分。

## 热图与 3D

**设置（Settings）**中是一张图：

**物理量 (Z)**：T、R、A，R 或 T 的 GD、GDD 和 TOD，Ψ、Δ，或**评价函数（Merit Function）**。相位本身不在其中：它沿一条线展开，而在网格上没有唯一的展开方式。**偏振（Polarization）**和**表面（Surface）**随物理量而定，与曲线上相同。

**X 轴**和 **Y 轴**：**波长 (nm)**、**入射角 (°)**，或某一正面膜层的厚度，列法与曲线相同，每条轴都有范围和**步数（steps）**。评价函数的两条轴都必须是膜层厚度，因此只有两层及以上的设计才能绘制它。

**固定 λ** 和**固定入射角**：两者中不在任何一条轴上的那个才显示；评价函数不显示它们，因为它使用每个操作数自己的值。

**颜色（Colors）**：颜色刻度。

网格点数显示在面板底部。厚膜系上的细网格需要一些时间，因此先用粗网格。

## 环境

在带有[环境](/zh/design/environments/)的设计上，每条曲线名称下方有一个**环境（Environment）**字段，**设置（Settings）**中也有一个用于图的字段。**当前（Current）**在设计编辑器和功能区显示的环境中计算；按编号和名称选择某一环境时，就在该环境中计算，无论它是否开启。不同环境的曲线画在一起，因此圆顶中心的 T 可以放在圆顶边缘的 T 旁边。曲线或图所指的环境若已不在设计中，就在当前环境中计算。图与计算它时所用的环境一起保留：一旦其设置改在另一个环境中计算（当前环境改变，或其所指的环境被删除），绘图区保持为空，直到你再次计算；回到原来的环境时，该图会重新显示。

轴上的膜层厚度是设计编辑器显示的厚度。每个环境按 f 倍的厚度沉积该层，f 是该环境中其材料的厚度系数乘以其温度引起的变化，与运行和其他窗口的读取方式相同，因此每条曲线在设计厚度处都经过其环境自身的值。

选**当前（Current）**时，MF 是所有开启的环境上的评价函数，MF² = (1/N) Σ MF_k²，即评价函数编辑器显示、[精炼](/zh/synthesis/refinement/)所最小化的值。选某一环境时，它是该环境自身的 MF_k，即在该环境中评分的各行的评价函数。在每个环境中，波段行都在环境 1 的网格上采样，与评价函数表的采样方式相同。

## 如何解读

在 2D 中，每类物理量有自己的 Y 轴：T、R 和 A 共用一条 0 到 100% 的轴，Ψ 和 Δ 共用一条以度为单位的轴，相位、GD、GDD 和 TOD 各占一条。第一条在左侧，其余在右侧。当每条曲线的 X 都是它改变的那个值时，鼠标悬停会在指针处读出所有曲线；X 为物理量的曲线可能折返，例如 Ψ-Δ 轨迹，因此逐点读取。

GDD 对某一膜层厚度的曲线显示该层的误差使色散移动多少，MF 沿一个厚度的截线显示设计是否位于谷底。T 或 R 在波长与入射角上的图就是[波长与角度](/zh/analysis/wavelength-angle-map/)绘制的图；GD 在同样两个变量上的图显示光倾斜时延迟波纹移向何处；两层厚度上的 MF 是优化器搜索的地形，可显示精炼后的设计是否位于真正的盆地中，或附近是否有更好的盆地。

绘图下方的**结果（Results）**条以数值形式给出每个点，**导出（Export）**将其写入 CSV。图表自带的工具栏可将图片保存为 PNG，无论使用何种主题，图片均为浅色。
