GD/GDD 窗口计算镀膜在反射或透射中的光谱相位，以及它对角频率的各阶导数。这些量说明镀膜如何延迟和展宽光脉冲的各个部分，啁啾镜和其他超快镀膜正是据此设计的。

## 计算的量

- **相位 φ**，单位为度：反射或透射的相移，沿波长展开，并在参考波长处归零。
- **GD**，群延迟，单位为 fs：镀膜把脉冲保持多久。
- **GDD**，群延迟色散，单位为 fs²：该延迟在光谱上的变化，它使短脉冲展宽。
- **CDC**，色散系数，单位为 fs/nm：按每 nm 波长而非每 rad/fs 表示的 GDD，符号与 GDD 相同。数据表中按每千米给出的光纤色散 D = dτ/dλ 符号相反；镀膜没有长度。
- **TOD**，三阶色散，单位为 fs³：GDD 之外残留的不对称性，会在脉冲一侧形成结构。

## 控件与设置

**物理量**、**T / R**、**偏振**和**面**选择所画的曲线。**平均**是 s 与 p 数值的平均。

**目标**叠加显示与当前曲线匹配的、已启用的 GD、GDD 和 TOD 评价函数行：点目标画为标记，平坦度目标画为其波段上的一条水平线。相位行不画，因为所显示的相位带有任意偏移；CDC 没有自己的行，请写成 GDD 目标。

**编辑**直接在图上绘制目标，代替在[评价函数编辑器](/zh/design/merit-function-editor/)中输入：单击在一个波长处添加目标，拖过一段波段在松开处的水平添加平坦度目标，拖动目标线或其端点可移动它，也可使用删除工具。绘制的目标采用当前显示的物理量、响应、偏振和入射角。对相位、CDC 以及评价函数不评分的那一面，编辑不可用。

**设置**：**入射角 (°)**、**λ** 范围、纵轴范围（**自动**或固定），以及**参考 λ (nm)**，即相位归零的波长；勾选框显示或隐藏它的标线。参考波长只移动相位曲线，不改变其导数。下方说明曲线如何采样，以及每种材料所用的色散模型。

**范围警告**：在超出某种材料数据范围的波长上，曲线画在一条标有该材料名称的阴影带上，表格也会标出这些行。表格材料在那里保持其端点值，因此该材料在此波段内不贡献色散；公式材料则被外推。徽标提供把范围缩小到所有材料都覆盖的波段的操作。

**环境**：在有多个[环境](/zh/design/environments/)的设计上，**当前**跟随设计编辑器显示的环境，按编号选中的环境即使已关闭也让窗口停留在它上面，**全部**用各自的颜色绘制每个开启的环境，并一并显示每个环境的目标。这一选择不随设计保存。

## 采样与表格节点

没有需要设置的步长。窗口自行选取波长，并在尖锐特征附近加密采样，例如反射极小旁的 GD 尖峰。当这类尖峰会把其余曲线压平时，**自动**会把它们排除在纵轴范围之外，徽标给出被排除在外的采样点数。

表格材料用保形三次插值（PCHIP），数值和斜率连续而曲率不连续，因此 GDD 和 TOD 在每个表格点处有台阶。逐点线性读取的表格在 GD 上也有台阶。恰好位于表格点上时，窗口显示两侧的平均，与对称差分一致，表格把该波长写成 λ− 和 λ+ 两行，每侧一行。拟合的色散公式可以消除这些台阶。

深反射极小旁的 GD 特征是真实存在的，但在反射中携带的能量很少；当镀膜用于透射时它才重要。

## 理论

记 φ(ω) 为 Macleod 约定下的反射或透射相移：

```
GD  = −dφ/dω       [fs]
GDD = −d²φ/dω²     [fs²]
TOD = −d³φ/dω³     [fs³]
CDC = GDD · 2πc / λ²   [fs/nm]
```

按这样的符号，把脉冲保持得更久的镀膜 GD 为正，镀膜的 GDD 与介质的 `L·d²κ/dω²` 相加，如 Macleod 式 11.19 所示。这些导数是精确值而不是差分：每层的折射率和相位厚度连同其对 ω 的前三阶导数一起，经由[导纳图](/zh/analysis/admittance/)中的特征矩阵传递，GD、GDD 和 TOD 由 r 或 t 的对数导数得到。公式材料被精确求导；表格材料给出其插值曲线的导数。相位展开只用于绘制相位曲线。
