脉冲分析让一个短激光脉冲在镀膜上反射或穿过镀膜，并画出输出，旁边是**傅里叶变换极限脉冲（FLP）**：同一光谱所能形成的最短脉冲，所有频率同时到达。色散镜好坏就看其输出与这个脉冲有多接近。仅凭 GDD 曲线看不出这一点：曲线上看似很小的纹波，正是在短脉冲一侧形成结构的原因。

## 计算的量

- 时间视图中，强度按 FLP 峰值为 1 缩放：输出的峰值即为它达到理想峰值的比例，损耗计算在内。虚线是啁啾输入，仅当其啁啾改变了形状时才画出。
- 光谱视图中，输入和输出光谱使用同一刻度，右轴是全部反射次数的 GDD。输入带啁啾时，一条虚线表示抵消该啁啾所需的 GDD；两条曲线重合处，脉冲被压缩输出。
- 图下方：FLP 和输出的脉宽、输出峰值相对 FLP 的比例、延迟以及残余 GDD。**结果**另外给出 RMS 宽度、输出峰值相对其自身变换极限的比例、输出能量、残余 TOD、光谱宽度和时间带宽积。

相对变换极限的峰值把输出与其自身光谱所能形成的最短脉冲比较，因此它显示的是还剩多少可以压缩，而不是镀膜从光谱中去掉了什么。

## 控件与设置

**时间 / 光谱**、**T / R** 和**偏振**选择视图；**平均**是非偏振脉冲，其 s 与 p 两半分别通过，强度相加。**去除延迟**把输出叠在输入上；**绝对**把它放在实际离开镀膜的时刻。

**设置**中的脉冲参数：

- **光谱**：**模型**由形状生成，**表格**使用设计中保存的光谱。
- **形状**：高斯或 sech²，由变换极限脉冲的**脉宽**设定；或超高斯，由其光谱**半高全宽**和**阶数**设定（2 即高斯；阶数越高顶部越平，时间上出现旁瓣）。
- **表格**：**载入文件…** 把文本表格读入[曲线编辑器](/zh/data-exchange/measured-spectra/#输入曲线或修改其数据点)，**编辑…** 打开设计的光谱或一个空表。光谱随设计保存。
- **中心 λ**：载波波长。模型光谱以它为中心；表格光谱不随它移动，其重心显示在旁边。
- **GDD、TOD**：输入自身的啁啾。正 GDD 就是玻璃产生的啁啾，长波先到达。**取自目标**把 GDD 设为每次反射的设计 GDD 目标乘以反射次数再取负：即镀膜设计用来消除的啁啾。

**设置**中的几何参数：**面**为单独的**正面**或**背面**镀膜，或在透射中选**整体**，加入一次穿过基底和背面镀膜，基底的色散通常远大于镀膜。**入射角**在入射介质中量度。**反射次数**：脉冲遇到镀膜或穿过零件的次数。

**环境**：在有多个[环境](/zh/design/environments/)的设计上，**当前**跟随设计编辑器显示的环境，按编号选中的环境即使已关闭也让窗口停留在它上面。脉冲遇到的是该环境的镀膜；脉冲本身在每个环境中都相同。这一选择不随设计保存。

**提示**：当输出超出计算所能容纳的最长时间跨度时，提示说明这些数值不可靠。选**整体**时只画出零件出射的第一个脉冲，提示给出光在基底内往返的时间。

## 脉冲形状与表格文件

每种模型形状在频率上关于中心对称，本身没有相位。Δω 为角频率减去载波频率，强度按单位频率计，时间带宽积为时间上的半高全宽乘以 ν = ω/2π 上的半高全宽。

| 形状 | 设定参数 | 光谱强度 | 变换极限强度 | 时间带宽积 |
|---|---|---|---|---|
| **高斯** | 脉宽 τ | `exp(−τ²·Δω² / (4 ln2))` | `exp(−4 ln2 · t²/τ²)` | 0.441 |
| **sech²** | 脉宽 τ | `sech²(π·T₀·Δω / 2)` | `sech²(t/T₀)`，τ = 1.763·T₀ | 0.315 |
| **超高斯** | 半高全宽 W，阶数 p | `exp(−ln2 · (2·\|Δω\|/W)^p)` | 无解析形式 | p = 2 时为 0.441，随 p 增大 |

表格文件包含波长（nm、µm、cm⁻¹ 或 eV，由表头或数值判断）、相对强度，以及可选的以弧度表示的相位，读取方式见[光谱文件格式](/zh/data-exchange/spectrum-file-formats/#分隔文本)：

```
Wavelength (nm)	Intensity	Phase (rad)
760	34.8	2.938
780	462.5	0.620
800	1000	0
820	452.6	0.432
840	53.3	1.416
```

以 nm 或 µm 为横坐标的强度按单位波长计，会换算为按单位频率计。行与行之间在频率上无过冲插值，首行和末行之外没有光，因此请删除光谱仪的暗底行。相位与 GDD 同号；折叠的相位会被展开，其在中心处的值和斜率被略去，因为它们只移动脉冲在时间上的位置。**应用**把中心 λ 设为光谱的重心。

## 理论

输出光谱等于输入光谱乘以镀膜的完整复响应，每次反射乘一次，不简化为 GD 和 GDD：

```
Ẽ_out(ω) = Ẽ_in(ω) · H(ω)^N
Φ_out(ω) = Φ_in(ω) + N · arg H(ω)
I(t)     = | ∫ Ẽ(ω) e^{−iΔω·t} dω |²
```

H 在反射中为 r，在透射中为缩放后使 `|H|² = T` 的 t；**整体**时它是正面镀膜、一次穿过基底和背面镀膜的乘积。arg H 的符号使其导数等于镀膜的群延迟，与 [GD / GDD 窗口](/zh/analysis/gd-gdd/)相同。FLP 是相同的 |Ẽ_in| 配以平坦相位。

```
delay   = ∫ |Ẽ_out|² · dΦ_out/dω dω  /  ∫ |Ẽ_out|² dω
GDD_res = ∫ |Ẽ_out|² · d²Φ_out/dω² dω  /  ∫ |Ẽ_out|² dω
```

延迟是强度重心的移动，由帕塞瓦尔定理，它等于按光谱加权的群延迟。延迟、GDD 和 TOD 来自相位的精确导数。脉宽是最外侧两个半峰点之间的半高全宽，因此高于峰值一半的卫星脉冲也计算在内。
