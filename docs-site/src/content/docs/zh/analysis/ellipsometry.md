椭偏窗口计算当前设计的椭偏角 Ψ 和 Δ，也就是椭偏仪报告的两个数。用它可以**预测仪器应当看到的结果**，或与测量结果比较。只模拟各向同性样品的反射；透射、广义椭偏和穆勒矩阵椭偏不在其范围内。

## 计算的量

- **Ψ**，单位为度，位于左轴，0 到 90°：`tan Ψ` 是 p 与 s 反射振幅之比。
- **Δ**，单位为度，位于右轴，0 到 360°：p 与 s 反射之间的相位差。

在[实测椭偏](/zh/data-exchange/measured-ellipsometry/)中加入的实测 Ψ 和 Δ 会叠加在光谱扫描上，画为带空心点的点线，只画在其测量的那一面，Δ 换算到窗口所显示的约定。

## 控件与设置

**Ψ / Δ**：显示或隐藏各条曲线；最后一条显示的曲线不能关闭。

**设置**：**模式**为在固定**入射角 (°)**（默认 65°）下扫描波长（**光谱**），或在固定 **λ (nm)** 下扫描入射角（**角度**），该波长跟随设计的参考波长。**面**选择正面或背面镀膜；每一面都是其自身表面上的一次相干反射。**Δ 约定**为 **Azzam–Bashara**（椭偏仪写入文件所用的符号，默认值），或用于另一种时间约定数据的 **360° − Δ**。两者的 Ψ 相同。

**范围警告**：当扫描超出某种材料的数据范围时出现 ⚠ 徽标。

**环境**：在有多个[环境](/zh/design/environments/)的设计上，**当前**跟随设计编辑器显示的环境，按编号选中的环境即使已关闭也让窗口停留在它上面，**全部**用各自的颜色绘制每个开启的环境，Ψ 为实线、Δ 为虚线，表格为每个环境给出各自的 Ψ 和 Δ 列。这一选择不随设计保存。

**结果**：Ψ 和 Δ 对扫描变量的数值。

## 镀膜的 Ψ 与 Δ

裸介质在布儒斯特角以下 Δ = 180°，以上为 0°，Ψ 在布儒斯特角处降到 0；裸吸收表面在 Azzam–Bashara 约定下，于其主入射角处 Δ = 90°。这些都是检查测量符号的有用参照。薄膜会使 Ψ 和 Δ 随波长振荡。

本窗口只做正向计算。若要从测量中求出厚度或光学常数，请在[实测椭偏](/zh/data-exchange/measured-ellipsometry/)中拟合。

## 理论

r_s 和 r_p 是膜系对 s 光和 p 光的振幅反射系数，`r = (η₀ − Y) / (η₀ + Y)`，倾斜导纳与表面导纳 Y 与[导纳图](/zh/analysis/admittance/)相同。于是（Macleod，式 14.17）：

```
ρ = tan Ψ · e^{iΔ}
tan Ψ = |r_p| / |r_s|
Δ = φ_p − φ_s + 180°
```

φ_s 和 φ_p 是 Macleod 约定 `N = n − ik` 下的反射相移。180° 把由 `η_p = N / cos θ` 构成的 p 反射系数换成椭偏所用的符号，所得即 Azzam–Bashara 的 Δ。**360° − Δ** 是它的复共轭，即同一样品在另一种时间约定下的值。Δ 归入 0 到 360°，因此实测值 −12° 画在 348° 处。
