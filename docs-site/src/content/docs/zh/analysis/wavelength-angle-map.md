波长与角度（Wavelength vs Angle）回答**当光不再垂直入射时，膜系偏移了多少**。它在一个波长范围与一个角度范围上同时计算某个物理量，并把结果画成色图，于是一条在 0° 与 45° 之间移动 30 nm 的通带边缘就是一张图，而不是十条叠加的光谱曲线。

设计一改变，色图就重新计算。无需按任何按钮。

## 设置

**物理量（Quantity）**：控制行上的 **T**、**R** 或 **A**。

**偏振（Polarization）**：**平均（avg）**、**s** 或 **p**。垂直入射时三者一致；随角度增大而分离，而 s / p 的分离往往正是要找的东西。

**绘制方式（Render）**：**热图（Heatmap）**把色图画成平面，更便于读出数值。**3D** 把同一网格画成可旋转的曲面，比色带更能显示峰的形状。

设置面板中：

**λ**：波长范围与列间步长。

**角度（Angle）**：入射角范围与行间步长。窗口以 0 到 60° 打开，最大可取到 89°。

**配色（Colors）**：色阶。默认 Turbo，另有 Jet、Viridis、Cividis 等可选。

网格大小显示在范围下方。两个步长都由你设定，厚膜系上的细网格耗时更长，因此建议先粗后细，等关注区域明确后再加密。

色图按[设计编辑器](/zh/design/design-editor/)中设置的面模式计算，并在结果旁显示为徽标。

## 如何解读

横向读一行，是某一角度下的光谱；纵向读一列，是某一波长随倾斜的变化。斜向延伸的都是随角度移动的特征；竖直的则是不随角度移动的特征。

角度增大时，特征向短波移动。膜层在斜入射下的相位厚度为 2π·*nd*·cos θ/λ，其中 θ 是膜层内部的传播角，而非入射角。由此得到的等效光学厚度为 *nd*·cos θ，倾斜越大，膜系看起来越薄，其中所有与波长有关的特征都随之下移。这就是为什么按垂直入射指定的截止滤光片在会聚光束中会落在目标短侧，也是为什么带通滤光片常被设计得略长，以便倾斜后正好落到波长上。

绘图下方的**结果（Results）**条以数值形式给出网格，每个波长与角度组合一行，**导出（Export）**将其写入 CSV。图表自带的工具栏可将图片导出为 PNG 或 SVG。

若需要单一角度下的完整光谱细节，请用[光学评价](/zh/analysis/optical-evaluation/)；若要映射角度以外的量（例如某层厚度），请用本窗口所基于的[绘图引擎](/zh/analysis/plot-engine/)曲面模式。
