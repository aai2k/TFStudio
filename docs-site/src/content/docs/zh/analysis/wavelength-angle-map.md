波长与角度回答**当光不再垂直入射时，膜系偏移了多少**。它在一个波长范围与一个角度范围上同时计算某个物理量并画成色图，于是一条在 0° 与 45° 之间移动 30 nm 的通带边缘就是一张图，而不是十条叠加的光谱曲线。设计一改变，色图就重新计算。

## 计算的量

- 网格上每个波长和角度处的 **T**、**R** 或 **A**，以百分比表示，可选**平均**、**s** 或 **p**，按在[设计编辑器](/zh/design/design-editor/)中设置的面模式及其入射锥角计算。
- **结果**以数值列出网格，每个波长与角度组合一行。

沿一行读，是某一角度下的光谱；沿一列读，是某一波长随光线倾斜的变化。斜向的特征随角度移动；竖直的特征保持不动。s 和 p 的图在正入射时一致，随角度增大而分离。

## 控件与设置

**物理量**、**偏振**和**绘制方式**：**热图**是平面图，更便于读出数值；**3D** 是可旋转的曲面，更能显示峰的形状。

**设置**：**λ** 范围与步长、**角度**范围（最初为 0 到 60°，最大 89°）与步长，以及**配色**。网格大小显示在范围下方；膜系较厚时先用粗网格。

**环境**：在有多个[环境](/zh/design/environments/)的设计上，**当前**跟随设计编辑器显示的环境，按编号选中的环境即使已关闭也让窗口停留在它上面。色图使用该环境的镀膜、介质和入射锥角。这一选择不随设计保存。

若要对角度以外的变量作图，例如某一膜层的厚度，请使用[绘图引擎](/zh/analysis/plot-engine/)。

## 理论

斜入射时膜层的相位厚度为（Macleod，式 9.2）

```
δ = 2π n d cos θ / λ
```

θ 为膜层内部的角度。膜层看起来薄了 cos θ 倍，因此光线倾斜时光谱的每个特征都移向短波。对窄带滤光片，峰值满足

```
λ_θ = λ₀ · √( 1 − (n₀ sin θ₀ / n*)² )
```

n* 为滤光片的有效折射率，一级腔为 `√(n_H n_L)`（Macleod，第 8.2 节，式 8.36）。n* 越高，偏移越小。这就是按正入射指定的截止滤光片在会聚光中会偏短，以及带通滤光片常常做得略长、让倾斜把它带到目标波长上的原因。导纳也随角度变化，使 s 与 p 分开；色图对两者都精确计算，与[光学评价](/zh/analysis/optical-evaluation/)相同。
