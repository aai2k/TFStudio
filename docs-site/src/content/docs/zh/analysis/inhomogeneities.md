沉积永远不会在两种材料之间形成完全突变的边界。不均匀性窗口在你选定的任意界面处插入一个渐变过渡层，并把带过渡层的光谱与设计原样的光谱叠加比较。设计本身不会被改变。

## 计算的量

- **T、R、A**，以百分比表示，每条画两次：设计原样画为淡色点线（**基准**），带过渡层的设计画为实线（**渐变**）。两者都遵循在[设计编辑器](/zh/design/design-editor/)中设置的计算方式及其入射锥角。
- **规格**判定：在带有[规格](/zh/design/specification/)的设计上，渐变后的设计是否仍然通过，在每个开启的环境中判定。
- **界面**条的标题统计有效过渡层的数量，并累加它们的厚度。

## 控件与设置

**T / R / A**：画哪些曲线，每项中包含**平均**、**s** 和 **p**。所有偏振一起计算，因此添加一条不增加任何开销。

**设置**：**λ** 范围、其**步长**以及**入射角 (°)**。

**界面**：每个界面一行，以其连接的两侧命名（L3 → L4，L1 → 基底），计算方式所包含的每一面各列一组。勾选一行或编辑其中任意字段，即对该界面进行渐变：

- **厚度**，单位 nm：过渡区的深度。它加在界面处，两侧的膜层保持各自的厚度。
- **剖面**：折射率从一种材料变到另一种材料的方式。
- **切片数**：代替渐变的均匀子层数，默认为 10。

**全部清除**移除所有过渡层。过渡层在本次会话中随设计保留，但不随设计保存。

**环境**：在有多个[环境](/zh/design/environments/)的设计上，**当前**跟随设计编辑器显示的环境，按编号选中的环境即使已关闭也让窗口停留在它上面。过渡层对所有环境是同一份列表；在所显示的环境中，每个过渡层在该处相接的两种材料之间渐变。这一选择不随设计保存。

## 渐变界面的作用

几纳米厚的过渡区，其光学厚度远小于半个波长，因此界面的反射几乎与阶跃界面相同。它主要增加的是一段中间折射率的光学厚度，这会使光谱移动，并使截止带边缘和通带纹波变得平缓。只有光学厚度与波长相当的渐变才会削弱界面本身的反射，渐变折射率增透膜正是这样工作的：Macleod 表明，光学厚度为 T 的平滑渐变在波长短于 2T 时不反射，在约 4T 处失效。

## 理论

厚度为 t、位于材料 A 与 B 之间的过渡层被切成 N 个子层，第 i 片厚度为 t/N，折射率取该片中点处的值：

```
s_i = (i + ½) / N                      i = 0 … N−1
N_i = (1 − f(s_i)) · N_A + f(s_i) · N_B
```

n 和 k 以同样方式混合，k 保持不小于 0。取每片的中点，使阶梯近似的误差按 1/N² 减小。剖面函数 f 在 A 处为 0，在 B 处为 1：

```
线性               f = s
抛物线             f = s²
反抛物线           f = 1 − (1 − s)²
指数               f = (e^{3s} − 1) / (e³ − 1)
S 形               f = (σ(s) − σ(0)) / (σ(1) − σ(0))，σ(s) = 1 / (1 + e^{−12(s − ½)})
```

这些切片在膜系中就是普通的均匀膜层，因此光谱的计算方式与[光学评价](/zh/analysis/optical-evaluation/)完全相同。
