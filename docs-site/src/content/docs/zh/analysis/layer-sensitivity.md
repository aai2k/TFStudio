膜层灵敏度显示**哪些层最需要精确制造**。它每次只把一层增厚和减薄一个小步长，测量光学评价函数变化多少，并按该变化对各层排序。所用的评价函数就是[评价函数编辑器](/zh/design/merit-function-editor/)中的那一个，因此排序针对的是你所设的目标。

## 计算的量

- **Δd**：施加到每层上的厚度步长，单位为 nm。
- **|ΔOMF|**：仅该层增厚和减薄 Δd 时光学评价函数的平均变化量。OMF 不含可制造性行 `MNT`、`MXT`、`TT` 和 `STR`，因此一层不会仅因接近厚度界限而排名靠前。
- **灵敏度 (%)**：|ΔOMF| 占本设计中最大 |ΔOMF| 的百分比。
- **排名**：|ΔOMF| 最大的层为 1，即最需要严格监控的层。
- **规格 @ ±Δd**：在带有[规格](/zh/design/specification/)的设计上，所有层同时增厚 Δd 以及同时减薄 Δd 时，每项要求是否仍然通过。

## 控件与设置

**归一化 % / 绝对 |ΔOMF|**：图表的纵轴，最高的条为 100%，或在对数轴上显示评价函数的原始变化。

**设置**：**扰动**为**相对**时填写 **Δd / d**，即每层自身厚度的百分比（默认 1%，因为真实的厚度误差随厚度成比例），为**绝对**时对所有层填写同一个以 nm 计的 **Δd**。**包含锁定**把在设计编辑器中锁定的层也纳入，否则它们被排除。

这一行上的徽标显示在[设计编辑器](/zh/design/design-editor/)中设置的面模式；被探测的层就是该模式所计算的层。

**环境**：在有多个[环境](/zh/design/environments/)的设计上，**当前**探测设计编辑器显示的环境的评价函数，按编号选中的环境即使已关闭也让窗口停留在它上面。**全部**探测每个开启的环境上的光学评价函数，合并为 OMF² = (1/N) Σ OMF_k²，N 为含有光学行的环境数。每次探测改变的是膜层列表中的厚度，在一个环境中表现为 f·(d ± Δd)，f 是该材料在该环境中的厚度系数。这一选择不随设计保存。

当某个评价函数行有自己的步长时，排序先按默认步长显示，颜色变淡并带 ≈ 标记，待按各行自己的步长算出后再替换。

## 排序

条形高表示该层的小厚度误差会使性能损失很多；条形矮表示该层宽容。条形高度都差不多的设计，没有哪一层能单独毁掉它。膜层编号与设计编辑器相同，F1 和 B1 分别是正面和背面紧贴基底的层。

## 理论

对厚度为 d_j 的第 j 层：

```
Δd_j = p · d_j / 100                  相对，p = Δd / d，单位 %
Δd_j = Δd                             绝对
|ΔOMF|_j = ( |OMF(d_j + Δd_j) − OMF₀| + |OMF(d_j − Δd_j) − OMF₀| ) / 2
Sens_j = 100 · |ΔOMF|_j / max_k |ΔOMF|_k
```

OMF₀ 是设计原样的评价函数；减薄的层最薄到 0 nm 为止，其余各层保持原厚度。OMF 是各光学行残差 Δ_i 的加权均方根，`OMF = √(Σ w_i Δ_i² / Σ w_i)`，每个残差的定义见[操作数参考](/zh/design/operands/)。每次评价时，波段行都在未改动设计的波长网格上采样，因此评价函数的变化来自厚度，而不是来自网格。

之所以把两个单侧变化量平均而不取导数，是因为设计通常所处的位置。在设计点附近：

```
OMF(d_j ± Δd) − OMF₀ ≈ ± g_j Δd + ½ H_jj Δd²
```

g_j 是沿第 j 层的斜率，H_jj 是曲率。优化过的设计位于极小点，各 g_j 都接近零，中心差分只会按优化器收敛的残余来排序。两个变化量绝对值的平均保留了 ½ H_jj Δd²，这正是极小点处沉积误差造成的代价；对于未经优化的设计，它退化为 |g_j| Δd。

在对称模式下，探测正面某层时，背面与之对应的镜像层也随之改变。

这就是 Baumeister 为滤光片公差分析提出的单膜层灵敏度（Macleod，第 13.7 节），只是作用于评价函数而不是单条光谱曲线。若要看所有层同时出现随机误差的影响，请使用[蒙特卡洛](/zh/analysis/error-analysis/)。
