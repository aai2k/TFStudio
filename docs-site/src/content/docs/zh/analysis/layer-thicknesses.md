膜层厚度（Layer Thicknesses）窗口把所选镀膜画成柱状图：每层一根柱，横轴为层号，纵轴为厚度，每根柱使用其材料的颜色。它是把握设计厚度序列形状最快的方式：啁啾镜的渐变、针法插入的薄间隔层，或精炼后比相邻层厚得多的某一层。设计编辑器列出同样的数字，但列表不显示形状。

层号从基底开始计数，与设计编辑器一致。当堆栈使用多种材料时，图上方的图例标出每种材料的颜色。

## 设置

**单位（Units）**：柱的读数单位。

- **nm**：物理厚度 `d`。
- **OT**：光学厚度 `n·d`，单位 nm。
- **QW**：四分之一波长光学厚度 `4·n·d/λ₀`。经典四分之一波层恰好读 1。
- **FW**：全波长光学厚度 `n·d/λ₀`。

光学单位在设置面板中的波长 `λ₀` 处读取每种材料的折射率。它默认取设计的参考波长，因此数值与设计编辑器的 QW 列一致。

**面（Side）**：**前（front）**镀膜或**后（back）**镀膜。

**环境**：在有多个[环境](/zh/design/environments/)的设计上，图下方一行中的**环境**下拉列表决定膜层按哪个环境绘制。**当前**跟随设计编辑器和功能区显示的环境；按编号和名称选中的环境会让窗口停留在该环境上，即使它已关闭。每根柱是该环境沉积出的那一层：其厚度乘以该层材料在该环境中的厚度系数和该环境温度带来的变化，材料取该环境为它沉积的材料，光学单位读取该材料在该环境温度下的折射率。膜层保持设计编辑器中的编号。材料范围提示读取所显示的环境。这一选择属于本窗口，不随设计保存。

## 如何解读

在 QW 单位下，四分之一波堆栈是一排高度为 1 的柱，任何偏离都一眼可见：半波腔读 2，宽带设计两端的渐变层从 1 落下。在物理单位下，同一张图显示沉积时间花在哪里。

数据表并排列出每层的全部四种读数，并可导出为 CSV。
