蒙特卡洛回答一个实际问题：如果你的镀膜机以现实的随机误差沉积每一层，光谱会偏移多少，结果又有多大概率仍通过你的规格？每次试验都是设计的一个副本，每层带有新抽取的随机误差；窗口画出各次试验的分散，并在有规格时给出良率。

## 计算的量

- 未改动设计的**理论**光谱（实线）、各次试验的**均值**（点线），以及包络带**均值 ± k·σ**（阴影），以百分比表示；可选所有试验的**最小/最大**包络。
- **良率**，在带有[规格](/zh/design/specification/)的设计上：通过全部要求的试验所占比例，附其 95% 区间，并为每项失败的要求显示带失败率的红色标记。
- **查看试验…**：各环境的良率、最常导致失败的要求和膜层，以及每次试验及其 Δd、Δn 和 Δk。**将厚度载入设计**把某次试验复制到设计上，作为一个撤销步骤。

包络带宽表示设计对制造误差敏感。在光谱弯曲处，均值可能偏离理论曲线：增透极小处的反射率均值向上漂移，因为那里的每个误差都使 R 升高。

## 控件与设置

**T / R / A**，以及**设置**中的 **λ** 范围与步长、**入射角**和偏振。试验在窗口线程之外运行；**停止**结束运行并保留已完成的试验。在[设计编辑器](/zh/design/design-editor/)中设置的面模式决定哪些镀膜带有误差。

**误差**条：

- **试验数**，默认 200。包络带的噪声按 1/√N 下降。
- **随机种子**：留空则重新抽样，**运行**会把种子填入，因此相同的种子和设置会重复相同的试验。不随设计保存。
- **分布**：**高斯**（数值为 σ）、**均匀**（硬性边界 ±B）或**截断**（在 ±B 处裁剪的钟形）。两种有界分布会把字段改标为 ± 并开启包络。
- **σ 绝对 / σ 相对**：以 nm 和每层厚度的 % 表示的厚度误差。二者相加。
- **σ Re(n) / σ Im(n)**：折射率误差。k 不能小于零，因此在 k = 0 的层上，Im(n) 误差只会增加吸收。
- **逐材料**：每种材料一个折射率误差，而不是每层一个，模拟材料漂移而非监控散布。
- **保持 n·d**：把厚度误差与折射率误差关联，使参考波长处的光学厚度保持不变。只有厚度误差时，它会抵消这些误差。
- **包络带**：均值 ± k·σ 中的 k，即包络带的宽度，仅影响显示。

**环境**：在有多个[环境](/zh/design/environments/)的设计上，**当前**跟随设计编辑器显示的环境，按编号选中的环境即使已关闭也让窗口停留在它上面。一次试验抽取一组误差，每个环境看到的是带有同一组误差的自身镀膜，因此切换时会显示同一批试验在另一个环境中的分散。一次试验在其判定的每个环境中都通过才算通过。这一选择不随设计保存。

## 理论

对厚度为 d_j 的第 j 层，每次试验抽取（Macleod，第 13.7 节）：

```
Δd_j ~ D(σ_d,j),     σ_d,j = σ_abs + (σ_rel / 100) · d_j
Δn_j ~ D(σ_n),       Δk_j ~ D(σ_k),       k + Δk ≥ 0
keep n·d:            d_j′ = d_j · n_j / (n_j + Δn_j)      n_j 取 λ₀ 处的值
```

D 为所选分布：标准差为 σ 的正态分布；[−B, B] 上的均匀分布，其 RMS 为 B/√3；或 σ = B/3、在 ±B 处裁剪的正态分布，其 RMS 为 0.987·B/3。对 N 次试验的 C_i(λ)：

```
C̄(λ)  = (1/N) Σ C_i(λ)
σ²(λ) = 1/(N − 1) Σ (C_i(λ) − C̄(λ))²
```

当 C 对误差的曲率为 C″ 时，均值偏离理论值约 `½ C″ σ²`，这就是极小处向上漂移的原因。

良率 p̂ = 通过次数 / N，附 Wilson 得分区间，95% 时 z = 1.96：

```
( p̂ + z²/2N  ±  z √( p̂(1 − p̂)/N + z²/4N² ) ) / (1 + z²/N)
```

两次运行的区间若有重叠，其差异可能只是偶然；增加试验次数可使区间变窄。
