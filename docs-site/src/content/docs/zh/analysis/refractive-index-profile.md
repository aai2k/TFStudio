折射率分布（Refractive Index Profile）将折射率 `n(z)` 与消光系数 `k(z)` 绘制为穿过前镀膜的深度的阶跃函数。它是设计的结构视图而非光学视图：它让层间实际的折射率对比一眼可见，这是确认堆栈由你预期的材料构建、以及查看高低折射率交替有多强的快捷方式。

每层的色散 `n` 与 `k` 在所选波长处评估，并从入射介质穿过各层布局到基底。

## 设置

**波长（Wavelength）**：采样每种材料折射率的波长，单位为 nm。默认取设计的参考波长。因为材料有色散，改变它会移动折射率值。

**量（Quantity）**：绘制折射率 `n`、消光系数 `k`，或二者在双轴上一起。

**面（Side）**：绘制**前（front）**镀膜、**后（back）**镀膜或**整体（total）**结构。前与后各自从入射介质穿过到基底布局其层。**整体**是整个零件的结构视图：前镀膜、基底与后镀膜端到端排成一条连续分布；因为基底远厚于镀膜，它被绘制为压缩的中间段，两侧有断口，以便镀膜层保持可读。

**环境**：在有多个[环境](/zh/design/environments/)的设计上，图下方一行中的**环境**下拉列表决定分布在哪个环境中计算。**当前**跟随设计编辑器和功能区显示的环境。按编号和名称选中的环境会让窗口停留在该环境上，即使它已关闭。**全部**绘制每个开启的环境，其 `n` 与 `k` 用本窗口在首选项“分析”中调色板里该环境的颜色，二者一起绘制时 `k` 仍为虚线，图上方的图例标出各个环境。层的条带与边界取自第一个环境，因为厚度系数会在其他环境中移动它们。深度坐标轴延伸到最厚的堆栈；在**整体**视图中，每一部分都按其最厚的环境留出空间，因此基底在所有环境中从同一位置开始。读数标明每条曲线所在的环境，表格和 CSV 每一行以其所在环境开头，依次列出每个环境的各行。材料范围提示读取所显示的每个环境的材料。这一选择属于本窗口，不随设计保存。

## 如何解读

横轴为物理深度，单位为纳米；彩色条带与虚线标出层边界与材料。每个台阶的高度是该层的折射率，因此相邻台阶间的高对比意味着强光学界面。非零 `k` 台阶标记吸收层。

读数报告折射率范围、层数与物理及光学总厚度，数据表列出 `n` 与 `k` 相对深度。将此与[电场](/zh/analysis/efield/)分布对照阅读，可看出哪一层承载驻波峰值。
