折射率剖面在单一波长下，把折射率 n 和消光系数 k 画成随深度变化的阶梯函数。它一眼就能看出层间的折射率差，并确认膜系使用的是你想要的材料。

<!-- shot: ri-profiler | protected silver mirror, n and k both drawn, the silver's k standing out against the oxide overcoat -->
![折射率分布](/screenshots/ri-profiler-zh.png)

## 计算的量

- 每层在选定波长下的 **n(z)** 和 **k(z)**，对从外表面算起、以 nm 计的物理深度。台阶高度就是该层的折射率；相邻层之间台阶高表示界面强，k 的台阶表示吸收层。
- **结果**列出 z、n 和 k，可导出为 CSV。

把剖面与[电场](/zh/analysis/efield/)分布对照，可看出驻波峰值落在哪一层。

## 控件与设置

**物理量**：**n**、**k**，或在双轴上同时显示两者，k 为虚线。

**面**：**正面**或**背面**镀膜，各自从其外侧介质画到基底；或**整体**：正面镀膜、基底和背面镀膜首尾相接，基底画成两个断口之间缩短的中段，使各层仍清晰可读。

**设置**：**波长 (nm)**，跟随设计的参考波长。材料有色散，因此它会移动台阶。

**环境**：在有多个[环境](/zh/design/environments/)的设计上，**当前**跟随设计编辑器显示的环境，按编号选中的环境即使已关闭也让窗口停留在它上面，**全部**用各自的颜色绘制每个开启的环境。层的条带取自第一个环境，因为厚度系数会在其他环境中移动边界。这一选择不随设计保存。

## 理论

在第 j 层内复折射率为常数：

```
N(z) = n_j(λ) − i·k_j(λ)        z 位于第 j 层内
```

n_j 和 k_j 由材料的数据或公式在 λ 处读取，按 Macleod 约定吸收材料的 k ≥ 0。各层按其物理厚度 d_j 画出；其光学厚度为 n_j·d_j。
