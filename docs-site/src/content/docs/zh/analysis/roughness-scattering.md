真实界面从不完美光滑，残留粗糙度会将少量光散射出镜面光束。粗糙度 / 散射（Roughness / Scattering）将该损耗估计为总积分散射（TIS, Total Integrated Scatter），并显示散射后幸存的镜面 R 与 T。你给每个界面一个 RMS 粗糙度 σ；工具将界面视为不相关，将它们组合为有效粗糙度 σ_eff（其中 σ_eff² 为各 σ² 之和），并在每个波长处计算散射比例。

分析针对在[设计编辑器](/zh/design/design-editor/)中设置的面模式运行。前使用前堆栈界面，后使用后堆栈界面，整体对两堆栈的粗糙度求和。

## 设置

**λ 范围 / 步长**：波长网格，单位为纳米。

**AOI**：入射角。

**T / R**：要绘制哪些曲线，每种内部含 **avg**、**s** 与 **p**。每个都绘制两次，理想与镜面。每种偏振一起计算，因此开启一个会添加一对而非替换平均曲线。

**ppm / frac**：TIS 轴的单位：百万分比或分数。

## 粗糙度

图表下方的**粗糙度（Roughness）**条是设置 σ 值的地方。选择**均匀 σ（Uniform σ）**将相同粗糙度应用于每个界面，或**逐界面（Per-interface）**单独设置每个。在均匀模式下，单个 σ 字段驱动每个界面；在逐界面模式下，每个界面按所分隔的两个介质命名列出，各有自己的 σ。

**重置（Reset）**将所有粗糙度清除回零。

## 如何解读

图表在不同轴上叠加两样东西。左轴为**百分比**，显示散射损耗后的镜面 R 与 T 为实线，其后是理想（零粗糙度）R 与 T 的浅色虚线，以便你看出粗糙度代价多少。右轴在自身的 ppm 或分数刻度上显示 TIS(λ)。

散射损耗向短波长急剧上升（TIS 按 1/λ² 缩放），因此在红外无害的粗糙度在紫外可能很严重。结果条报告有效粗糙度 σ_eff 与贡献于它的界面数，并逐波长打开光谱。
