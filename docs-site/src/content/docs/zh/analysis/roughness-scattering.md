真实界面从不完美光滑。粗糙度 / 散射（Roughness / Scattering）把设计中每个粗糙界面替换为一个薄的过渡层，将由此得到的镜面 R 与 T 与光滑设计的 R 与 T 并排显示，并给出镜面光束中损失的光。

## 两种粗糙度

每个界面有一个 RMS 粗糙度 σ，以及两种类型之一。

**小尺度（Short range）**：比波长细得多的粗糙度。光把它看作折射率从一种材料到另一种材料的逐渐变化，因此界面变为一个厚 2σ 的渐变层，其 n 和 k 从一种材料线性过渡到另一种材料。它的作用像一层弱的增透层：R 和 T 会改变，但没有光损失。

**大尺度（Long range）**：起伏比波长更宽的粗糙度。它把光散射出镜面光束。界面变为一个厚 2σ 的单层，其折射率介于两种材料之间，并带有一个代表散射光的小消光系数。于是损耗像吸收一样随每个界面处的电场变化：反射镜在高反射带内损耗很小，因为光到达不了内部界面；在高反射带两侧的凹陷处损耗则大得多。

两种过渡层的厚度都取自界面下方的那一层，即先沉积的那一层，因此设计的其余部分位置不变。基底从不被减薄，因此紧贴基底的过渡层会使镀膜增加 2σ。若某层比从它扣除的过渡层还薄，该层厚度被设为零，窗口会给出提示。厚度本来为零的层不在镀膜中，因此它两侧的层在同一个界面相接，该界面采用下方那一层顶面界面所设的 σ 与类型。

## 大尺度模型的适用范围

大尺度层来自针对以下条件的计算：

- 两种非吸收材料之间的单个表面；
- 光以正入射到达；
- 起伏的宽度远大于波长；
- 粗糙度足够小，(σ/λ)² 以上的项可以忽略。

在这些条件下，无论光从哪一侧入射，它给出的 R 与 T 下降都与标量散射理论相同。窗口还把它用于多层膜的每个界面和任意入射角，这些情况不在该计算的范围内，因此请把这些结果当作估算。紧邻吸收材料（例如金属）时，只有该材料折射率的实部进入过渡层。当入射角不为零且设置了大尺度界面时，窗口会显示一条提示，说明结果只是估算。

## 设置

**λ 范围 / 步长**：波长网格，单位为纳米。

**AOI**：入射角。

**T / R**：要绘制哪些曲线，每种内部含 **avg**、**s** 与 **p**。每个都绘制两次，光滑与粗糙。每种偏振一起计算，因此开启一个会添加一对而非替换平均曲线。

**ppm / frac**：损耗轴的单位：百万分比或分数。

分析针对在[设计编辑器](/zh/design/design-editor/)中设置的面模式运行。选择前时，正面镀膜的界面变粗糙；选择后时，背面镀膜的界面变粗糙；选择整体时两者都变粗糙，中间隔着基底。

## 粗糙度

图表下方的**粗糙度（Roughness）**条是设置 σ 与类型的地方。选择**均匀 σ（Uniform σ）**让每个界面使用相同的 σ 与类型，或选择**逐界面（Per-interface）**逐个设置。在逐界面模式下，每个界面按其分隔的两种介质列出，各有自己的 σ 以及小尺度 / 大尺度选项。未编辑过的界面沿用均匀设置的值。

**重置（Reset）**把每个界面恢复为 σ = 1 nm、大尺度。

## 如何解读

左轴为**百分比**，以实线显示粗糙时的 R 与 T，其后以浅色虚线绘出光滑时的 R 与 T。右轴以 ppm 或分数显示镜面损耗，即光滑的 R + T 减去粗糙的 R + T。

在非吸收设计上，小尺度粗糙度没有损耗，因此其损耗曲线保持为零；它的影响体现在虚线与实线之间的差距上。对单个表面，大尺度损耗按 (σ/λ)² 增长，因此在红外无害的粗糙度在紫外可能变得重要。在吸收设计中，过渡层也会改变吸收，损耗曲线包含了这一变化。当过渡层替换了吸收层的一部分时，损耗甚至可能低于零。

结果条逐波长打开同一光谱：每条已开启曲线的光滑值与粗糙值，以及损耗。
