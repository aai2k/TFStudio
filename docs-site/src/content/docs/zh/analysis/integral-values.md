积分值把光谱浓缩为规格书中引用的加权平均值：可见光透射率、太阳光反射率等。每一行在一个波段上对 T、R 或 A 求平均，每个波长按光源乘以探测器响应加权。这些数值遵循设计的[计算方式](/zh/design/evaluation-modes/)；对于常见的整件数值，请按整体系统计算设计。

## 计算的量

| 行 | 加权 | 波段 |
| --- | --- | --- |
| Tvis、Rvis、Avis | D65 × 明视觉 V(λ) | 380–780 nm |
| Tsol、Rsol、Asol | AM1.5G 太阳光谱 | 300–2500 nm |
| TUV、RUV | 均匀 | 300–380 nm |
| TNIR、RNIR | 均匀 | 780–2500 nm |

每一行以小数和百分比给出平均值，并给出该通道在波段内未加权的最小值和最大值及其所在波长，用于"整个波段内 T ≥ 99 %"这类最坏情况检查。图中显示所选行的通道及其归一化的权重，便于看出平均值主要来自光谱的哪一部分。

## 控件与设置

**λ 范围 / 步长**：光谱采样的网格。每一行都在其完整波段上积分，绝不只在网格恰好覆盖的部分上积分：网格未覆盖其波段的行显示**不可用**，并在旁边给出已覆盖的范围。默认的 300–2500 nm 覆盖所有内置行。

**入射角 / 偏振**：入射角，以及 s、p 或两者的平均。

**+ 自定义积分…** 定义你自己的一行：**名称**、**通道**（T、R 或 A）、**光源**（D65、D50、A、AM1.5G、等能光源 E、可设温度的黑体，或表格）、**探测器**（V(λ)、均匀或表格）以及**波段**。在你输入名称之前，名称会跟随所选内容，例如 T·D65·V(λ)。表格光源或探测器会打开[曲线编辑器](/zh/data-exchange/measured-spectra/#输入曲线或修改其数据点)，波长可用 nm、µm、cm⁻¹ 或 eV。自定义行上的铅笔用于编辑，垃圾桶用于删除。自定义行会自动保存和恢复；在[评价函数编辑器](/zh/design/merit-function-editor/)中已由它生成的操作数保留生成时的数值。

**环境**：在有多个[环境](/zh/design/environments/)的设计上，**当前**跟随设计编辑器显示的环境，按编号选中的环境即使已关闭也让窗口停留在它上面，**全部**在每个开启的环境中列出每一项积分，并用各环境的颜色绘制所选行的通道。这一选择不随设计保存。

## 明视觉行与网格

使用 D65 和 CIE 1931 2° 观察者时，Tvis 就是亮度因数：理想白色读数为 100 %。明视觉行与其他行一样在 λ 网格上积分，CIE 表格插值到该网格上，因此比步长更窄的特征会被漏掉。要得到窄陷波的 Tvis，请把步长设得远小于陷波宽度。

## 理论

对通道 C（T、R 或 A）、光源 S 和探测器 D，在波段 λ₁ 到 λ₂ 上：

```
C̄ = ∫ C(λ) S(λ) D(λ) dλ  /  ∫ S(λ) D(λ) dλ
```

两个积分都在窗口的 λ 网格上用梯形法计算，S 和 D 由其表格线性插值。网格总是终止于终点波长，步长不能整除范围时，最后多出一个较短的区间。当 S = D65、D = ȳ(λ) 时，C̄ 就是 Macleod 式 12.2 中的亮度因数 Y/100。
