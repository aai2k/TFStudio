积分值（Integral Values）将整条光谱浓缩为规格表所引用的单一加权平均值：可见光透射率、太阳反射率等。对于每个权重，它在波长带上对 T(λ)、R(λ) 或 A(λ) 取平均，每个波长由光源乘以探测器响应加权。除内置标准外，你还可以用任意光源、探测器与波段构建自己的积分。这些数值描述滤光片整体，因此遵循设计的[评估模式](/zh/design/evaluation-modes/)，无论是前表面、后表面，还是完整的前–基底–后系统。窗口中的 `Eval` 徽标。对于通常的整体数值（如太阳或光度透射率），将设计评估为整体系统。

## 设置

**λ 范围 / 步长**：光谱采样的波长网格，单位为纳米。它应足够宽以覆盖你想读取的每个积分的波段。

**AOI / pol**：入射角与偏振（s、p 或平均）。

**自定义积分构建器（custom-integral builder）**允许你添加自己的加权平均值：

**通道（Channel）**：平均 T、R 还是 A。

**光源（Source）**：照明体：D65、D50、照明体 A、AM1.5G 太阳光谱、等能 E、你设定温度的黑体，或自定义表格。黑体暴露一个温度字段；自定义光源打开一个小表格编辑器，你可键入或粘贴光源光谱。

**探测器（Detector）**：观察者或传感器响应：光度曲线 V(λ)、平坦响应，或自定义表格。

**波段（Band）**：取平均的波长范围（单位为 nm）。

**添加（Add）**将该积分注册为新行。自定义行可就地编辑（你可在表格中直接重命名并调整通道与波段）并可移除。自定义积分自动保存与恢复。

自定义表格编辑器接受粘贴或导入的 CSV/TSV（两列：λ 单位为 nm 与权重值）；标题行、空行与 `#` 注释行被忽略。

## 如何解读

每行以分数与**百分比**两种形式显示加权平均值，外加波段内通道的未加权最小值与最大值（及其出现波长），便于最坏情况检查，如"T ≥ 99% 跨带"。选择一行会在右侧绘制叠加图：所选通道（百分比）连同归一化权重曲线，因此你可看出光谱的哪一部分主导了平均值。最小值与最大值在图上标出。

关于可见光数值的说明：仅当光源为 D65 且探测器为 CIE 1931 2° 观察者时，Tvis 才与光度亮度匹配；理想白色读数为 100%。
