积分值（Integral Values）将整条光谱浓缩为规格表所引用的单一加权平均值：可见光透射率、太阳反射率等。对于每个权重，它在波长带上对 T(λ)、R(λ) 或 A(λ) 取平均，每个波长由光源乘以探测器响应加权。除内置标准外，你还可以用任意光源、探测器与波段构建自己的积分。这些数值描述滤光片整体，因此遵循设计的[评估模式](/zh/design/evaluation-modes/)，无论是前表面、后表面，还是完整的前–基底–后系统，如图下方的 `Eval` 徽标所示。对于通常的整体数值（如太阳或光度透射率），将设计评估为整体系统。

## 设置

**λ 范围 / 步长**：光谱采样的波长网格，单位为纳米。每一行都在自己的完整波段上积分，因此网格必须覆盖你想读取的每个积分的波段。若光谱没有覆盖某一行的波段，该行读数为**不可用**，波段旁会显示光谱实际覆盖的范围，CSV 导出中该行的单元格留空；程序从不只在碰巧覆盖到的那部分波段上取平均。网格必须到达波段的两端，因此请选择能把范围等分的步长。默认网格 300-2500 nm 覆盖所有内置行：光度 380-780 nm、太阳 300-2500 nm、UV 300-380 nm 与 NIR 780-2500 nm。

**AOI / pol**：入射角与偏振（s、p 或平均）。

**+ 自定义积分…（Custom integral…）**打开一个对话框，在其中定义你自己的加权平均值：

**名称（Name）**：该行的名称。它起初是由通道、光源与探测器组成的短名称，如 T·D65·V(λ)，并处于选中状态，直接输入即可替换；在你输入之前，它随这些选择而变化。若建议的名称已被另一个自定义积分使用，则加上 #2、#3。没有名称的积分无法添加。

**通道（Channel）**：平均 T、R 还是 A。

**光源（Source）**：照明体：D65、D50、照明体 A、AM1.5G 太阳光谱、等能 E、你设定温度的黑体，或自定义表格。黑体暴露一个温度字段；自定义光源提供 **Edit table…（编辑表格）**，它以随波长变化的权重打开光源光谱的[曲线编辑器](/zh/data-exchange/measured-spectra/#输入曲线或修改其数据点)。

**探测器（Detector）**：观察者或传感器响应：光度曲线 V(λ)、平坦响应，或自定义表格。

**波段（Band）**：取平均的波长范围（单位为 nm）。

**添加（Add）**将该积分作为新行放入表格。自定义行与内置行显示方式相同，其名称后以浅色显示它积分的内容：通道，然后是 光源 × 探测器，如 R · 黑体 3000 K × 均匀（权重 1）。点击该行旁的铅笔按钮或双击该行，会在同一对话框中打开它，可修改其中任何一项，包括光源与探测器；**确定（OK）**应用修改，该行保持原位。垃圾桶按钮将其移除。自定义积分自动保存与恢复。[评价函数编辑器](/zh/design/merit-function-editor/)中已由某个自定义积分建立的操作数保留其建立时的值。

自定义表格在曲线编辑器中键入、粘贴或从文件读取，读取文本的方式与光谱导入器相同：保留小数逗号，标题行、空行与 `#` 注释行被忽略。波长列可用 nm、µm、cm⁻¹ 或 eV。**Apply（应用）** 至少需要两行同时有波长和权重，并按波长排序。

## 如何解读

每行以分数与**百分比**两种形式显示加权平均值，外加波段内通道的未加权最小值与最大值（及其出现波长），便于最坏情况检查，如"T ≥ 99% 跨带"。选择一行会在右侧绘制叠加图：所选通道（百分比）连同归一化权重曲线，因此你可看出光谱的哪一部分主导了平均值。最小值与最大值在图上标出。

关于可见光数值的说明：仅当光源为 D65 且探测器为 CIE 1931 2° 观察者时，Tvis 才与光度亮度匹配；理想白色读数为 100%。光度各行与其他行一样在 λ 网格上积分，CIE 表格插值到该网格上，因此比这些表格的 5 nm 间隔更窄的光谱特征，只要步长能分辨它，就会被计入。要读取窄陷波的 Tvis，请把步长设得远小于陷波宽度。
