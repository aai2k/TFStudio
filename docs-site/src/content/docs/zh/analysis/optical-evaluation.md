光学评价绘制**你的镀膜在一段波长范围内如何透射、反射和吸收光**。每次修改设计后都应查看这个窗口；它还会把评价函数目标画在光谱上，让你看到设计正朝着什么优化。

## 计算的量

- **T**、**R** 以及 **A** = 1 − R − T，各有 **s**、**p** 和两者的**平均**。对透明材料，A 保持为零。
- 以 **%**、分数 **0-1**、**dB**（`10·log₁₀`）读取，透射率还可用光密度 **OD**（`−log₁₀ T`）读取。
- 计算内容遵循在[设计编辑器](/zh/design/design-editor/)中设置的计算方式，显示为图下方的徽标：**正面**为基底上的正面镀膜，**背面**为背面镀膜，**整体**为穿过基底的整个零件，即分光光度计对双面镀膜零件所测的结果。当曲线在入射锥角上平均时，会出现第二个徽标。

## 控件与设置

**T / R / A** 开关各条曲线，每项包含**平均**、**s** 和 **p**。

**目标**把评价函数行画在光谱上：点目标画为 X 标记，波段与斜坡目标画为带浅色区域的点线。**编辑**直接在图上绘制目标，代替在[评价函数编辑器](/zh/design/merit-function-editor/)中输入：拖出一条线即为一个目标，水平线成为波段平均，倾斜线成为斜坡；拖动目标可移动它；删除工具可移除目标。端点吸附到网格和其他目标的端点。每次编辑都立即写入评价函数，并且是一个撤销步骤。

**设置**：

- **入射角**：一个或多个角度。每个角度是一组独立的曲线，后面的角度画得更淡。点击某个角度可编辑它。
- **范围与步长**，以轴单位表示，默认 400–800 nm，步长 0.5 nm。粗网格可能跨过窄的谷。
- **轴单位**：nm、µm、cm⁻¹、THz 或 eV，作用于坐标轴、读数、表格和 CSV。在 nm 和 µm 下各点按波长等间距，在其他单位下按该单位等间距，正如傅里叶变换红外光谱按波数等间距。在两组单位之间切换时点数保持不变。计算始终以真空波长进行。
- **Y**：**自动**，或最小值与最大值，以及单位。

**环境**：在有多个[环境](/zh/design/environments/)的设计上，**当前**跟随设计编辑器显示的环境，按编号选中的环境即使已关闭也让图停留在它上面，**全部**用各自的颜色绘制每个开启的环境。所画的目标是在所显示环境中评分的行，在**全部**下则是每一行。这一选择不随设计保存。

**结果**：屏幕上的各条曲线在相同各点的数值，第一列使用轴单位。CSV 的列名带有单位，`T_dB` 或 `T_OD`，以后打开文件时不会被当作百分比。通过[实测光谱](/zh/data-exchange/measured-spectra/)导入的光谱以带空心圆的点线叠加在预测曲线上。

## 分贝与光密度轴

dB 和 OD 以对数方式绘制纵轴，这正是阻带指标所需要的：0.1 % 的阻带在百分比轴上是贴着底边的一条平线，在 dB 轴上则是清楚的 −30 dB。10 dB 的损耗等于一个光密度单位。

分贝同样适用于 T、R 和 A，因为三者都是入射光通量的分数；吸收率获益最多，10 ppm 的损耗读作 −50 dB。光密度只是透射率的量，因此选择 OD 时只画 T 曲线。这些只是显示选择：计算值和目标不变。

网格线随屏幕上的跨度而定，两种轴都止于 OD 12（−120 dB）。曲线在到达零处断开：透明膜系的吸收率只是 `1 − R − T` 的舍入残余，不予绘制。写为零的目标，例如 R = 0，在对数轴上没有位置，回到线性单位之前不会被绘制。

## 理论

对一个镀膜，由膜系在基底导纳 η_m 上的特征矩阵 `[B, C]` 得到（Macleod，式 2.123 与 2.125）：

```
R = |(η₀B − C) / (η₀B + C)|²
T = 4 η₀ Re(η_m) / |η₀B + C|²
A = 1 − R − T
```

所用的倾斜导纳和相位厚度与[导纳图](/zh/analysis/admittance/)相同。**平均**对每个量取 `(X_s + X_p) / 2`。

**整体**以非相干方式加入基底，把它当作厚平板，其多次反射按强度而不是振幅相加：

```
P = exp(−4π k_s d_s / (λ cos θ_s))
T = T_f · P · T_b / (1 − R_f′ · R_b · P²)
R = R_f + T_f · T_f′ · P² · R_b / (1 − R_f′ · R_b · P²)
```

T_f、R_f 是从入射介质看的正面镀膜，T_f′、R_f′ 是从基底内部看的正面镀膜，R_b、T_b 是从基底看的背面镀膜，P 是厚度为 d_s 的基底单次通过的内部透射率，两个偏振分别求和（Macleod，第 2.14 节）。

```
T(dB) = 10 · log₁₀ T
OD    = −log₁₀ T
```
